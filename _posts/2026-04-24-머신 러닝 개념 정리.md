# 1. Decision Tree와 Supervised Learning

## Decision Tree는 Supervised Learning인가?

Decision Tree는 기본적으로 **Supervised Learning**에 사용하는 알고리즘이다.

Supervised Learning은 학습 데이터에 정답 label이 포함되어 있는 학습 방식이다.

예를 들어 다음과 같은 데이터가 있다고 하자.

| Weather | Humidity | Wind | Play |
|---|---|---|---|
| Sunny | High | Weak | No |
| Sunny | Normal | Weak | Yes |
| Rainy | High | Strong | No |
| Cloudy | High | Weak | Yes |

여기서 구분은 다음과 같다.

| 구분 | 예시 | 의미 |
|---|---|---|
| Feature, 독립변수 | Weather, Humidity, Wind | 예측에 사용하는 입력값 |
| Label, Target, 종속변수 | Play | 맞춰야 하는 정답 |

Decision Tree는 Feature를 기준으로 데이터를 나누면서 Label을 잘 예측하는 규칙을 학습한다.

## Decision Tree가 사용되는 문제 유형

Decision Tree는 크게 두 가지 문제에 사용할 수 있다.

| 문제 유형 | 설명 | 예시 |
|---|---|---|
| Classification | 범주형 값을 예측 | 스팸 여부, 합격 여부, 질병 여부 |
| Regression | 연속형 숫자 값을 예측 | 집값, 매출, 온도, 전류값 |

## Classification 예시

| 공부시간 | 출석률 | 결과 |
|---:|---:|---|
| 8 | 95% | Pass |
| 2 | 60% | Fail |
| 6 | 80% | Pass |

결과가 Pass 또는 Fail처럼 범주형 값이면 Classification 문제이다.

## Regression 예시

| 면적 | 위치점수 | 집값 |
|---:|---:|---:|
| 84 | 8 | 7억 |
| 59 | 6 | 5억 |
| 110 | 9 | 10억 |

집값처럼 숫자를 예측하면 Regression 문제이다.

## Supervised Learning과 Unsupervised Learning 비교

| 구분 | 정답 label 필요 여부 | 대표 알고리즘 |
|---|---|---|
| Supervised Learning | 필요 | Decision Tree, Linear Regression, Logistic Regression, SVM |
| Unsupervised Learning | 필요 없음 | K-means Clustering, PCA, Association Rule |

핵심은 다음이다.

**Decision Tree는 정답 label을 기준으로 좋은 분기 조건을 학습하는 Supervised Learning 알고리즘이다.**

# 2. Entropy와 Information Gain

## Entropy 개념

**Entropy**는 데이터가 얼마나 섞여 있는지를 나타내는 불순도 지표이다.

Decision Tree에서는 특정 노드 안에 여러 class가 얼마나 섞여 있는지 계산할 때 사용한다.

\[
Entropy(S) = - \sum_{i=1}^{k} p_i \log_2(p_i)
\]

| 기호 | 의미 |
|---|---|
| \(k\) | class 개수 |
| \(p_i\) | i번째 class가 차지하는 비율 |
| \(\log_2\) | 밑이 2인 로그 |
| \(Entropy(S)\) | 데이터가 섞여 있는 정도 |

이진 분류에서는 다음처럼 쓸 수 있다.

\[
Entropy(S) = -p_+ \log_2(p_+) - p_- \log_2(p_-)
\]

| 데이터 상태 | Entropy | 의미 |
|---|---:|---|
| 한 class만 존재 | 0 | 완전히 순수함 |
| class가 반반 섞임 | 최대 | 가장 많이 섞임 |
| 한쪽 class가 더 많음 | 중간 | 일부 섞임 |

## Entropy 계산 예시

전체 데이터 10개 중 Yes가 8개, No가 2개라고 하자.

| Class | 개수 | 비율 |
|---|---:|---:|
| Yes | 8 | 0.8 |
| No | 2 | 0.2 |

\[
Entropy(S) = -0.8\log_2(0.8)-0.2\log_2(0.2)
\]

\[
Entropy(S) \approx 0.722
\]

Yes와 No가 5개씩 반반이면 Entropy는 1이고, 한쪽 class만 있으면 Entropy는 0이다.

## Information Gain 개념

**Information Gain**은 Decision Tree에서 어떤 Feature로 데이터를 나누었을 때 불확실성 또는 impurity가 얼마나 줄어드는지를 나타내는 값이다.

즉, 어떤 Feature로 나누면 데이터가 더 깔끔하게 분리되는지를 수치로 표현한 것이다.

Decision Tree는 보통 Information Gain이 큰 Feature를 먼저 선택한다.

## Information Gain 공식

\[
Information\ Gain = Entropy(parent) - Entropy(after\ split)
\]

더 자세히 쓰면 다음과 같다.

\[
IG(S,A) = Entropy(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|}Entropy(S_v)
\]

| 기호 | 의미 |
|---|---|
| \(S\) | 분리 전 전체 데이터 |
| \(A\) | 분리에 사용할 Feature |
| \(v\) | Feature \(A\)가 가질 수 있는 값 |
| \(S_v\) | Feature 값이 \(v\)인 데이터 그룹 |
| \(|S|\) | 전체 데이터 개수 |
| \(|S_v|\) | 분리된 그룹의 데이터 개수 |

말로 풀면 다음과 같다.

**Information Gain = 나누기 전 불순도 - 나눈 후 불순도**

## 특정 Feature의 Information Gain 계산 순서

| 순서 | 계산 내용 |
|---:|---|
| 1 | 전체 데이터의 Entropy를 계산한다 |
| 2 | 특정 Feature 값 기준으로 데이터를 나눈다 |
| 3 | 나눠진 각 그룹의 Entropy를 계산한다 |
| 4 | 각 그룹 Entropy에 데이터 비율을 곱한다 |
| 5 | 그룹별 가중 Entropy를 모두 더한다 |
| 6 | 전체 Entropy에서 분리 후 가중 Entropy를 뺀다 |

## Information Gain 계산 예시

목표는 구매 여부를 예측하는 문제라고 하자.

| 번호 | 날씨 | 구매 여부 |
|---:|---|---|
| 1 | 맑음 | 구매 |
| 2 | 맑음 | 구매 |
| 3 | 맑음 | 미구매 |
| 4 | 흐림 | 구매 |
| 5 | 흐림 | 구매 |
| 6 | 비 | 미구매 |
| 7 | 비 | 미구매 |
| 8 | 비 | 구매 |

전체 데이터는 8개이고, 구매 5개, 미구매 3개이다.

\[
Entropy(S) = -\frac{5}{8}\log_2\left(\frac{5}{8}\right) - \frac{3}{8}\log_2\left(\frac{3}{8}\right)
\]

\[
Entropy(S) \approx 0.954
\]

날씨 Feature로 나누면 다음과 같다.

| 날씨 | 데이터 개수 | 구매 | 미구매 | Entropy |
|---|---:|---:|---:|---:|
| 맑음 | 3 | 2 | 1 | 0.918 |
| 흐림 | 2 | 2 | 0 | 0 |
| 비 | 3 | 1 | 2 | 0.918 |

분리 후 가중 Entropy는 다음과 같다.

\[
Entropy(after\ split) = \frac{3}{8}(0.918) + \frac{2}{8}(0) + \frac{3}{8}(0.918)
\]

\[
Entropy(after\ split) \approx 0.689
\]

따라서 Information Gain은 다음과 같다.

\[
Information\ Gain = 0.954 - 0.689 = 0.265
\]

즉, 날씨 Feature로 분리했을 때 Information Gain은 약 0.265이다.

# 3. Gain Ratio

## Gain Ratio 개념

**Gain Ratio**는 Decision Tree에서 분할 기준을 정할 때 사용하는 지표이다.

특히 C4.5 알고리즘에서 사용한다.

핵심은 다음이다.

**Information Gain이 너무 많은 값을 가진 Feature를 과도하게 선호하는 문제를 보정한 지표이다.**

예를 들어 고객 ID, 전화번호, 제품 Serial Number 같은 Feature는 거의 모든 값이 고유하다. 이런 Feature로 나누면 각 그룹이 아주 작아지고, 훈련 데이터에서는 Entropy가 크게 줄어든 것처럼 보인다.

하지만 이런 분할은 일반화에 도움이 되지 않는다.

## Gain Ratio 공식

\[
Gain\ Ratio = \frac{Information\ Gain}{Split\ Information}
\]

여기서 **Split Information**은 Feature가 데이터를 얼마나 잘게 쪼개는지를 나타낸다.

\[
Split\ Information = - \sum_{i=1}^{k} \frac{n_i}{n} \log_2\left(\frac{n_i}{n}\right)
\]

| 기호 | 의미 |
|---|---|
| \(n\) | 전체 데이터 개수 |
| \(n_i\) | i번째 분할 그룹의 데이터 개수 |
| \(k\) | 분할된 그룹 개수 |

## Information Gain과 Gain Ratio 비교

| 구분 | Information Gain | Gain Ratio |
|---|---|---|
| 대표 알고리즘 | ID3 | C4.5 |
| 기준 | Entropy 감소량 | Entropy 감소량을 분할 복잡도로 보정 |
| 장점 | 계산이 직관적 | 고유값 많은 Feature 편향을 줄임 |
| 단점 | 고유값 많은 Feature를 선호 | Split Information이 너무 작은 경우 불안정 가능 |

정리하면 Gain Ratio는 다음 질문에 답한다.

**분할 복잡도 대비 정보 이득이 얼마나 큰가?**

# 4. K-means Clustering

## K-means Clustering 개념

**K-means Clustering**은 데이터를 K개의 cluster로 나누는 Unsupervised Learning 알고리즘이다.

정답 label 없이 데이터의 위치, 거리, 유사도만 보고 비슷한 것끼리 묶는다.

## K-means에서 K의 의미

K-means의 K는 만들고 싶은 cluster 개수이다.

| K 값 | 의미 |
|---:|---|
| K = 2 | 데이터를 2개 그룹으로 나눔 |
| K = 3 | 데이터를 3개 그룹으로 나눔 |
| K = 5 | 데이터를 5개 그룹으로 나눔 |

## K-means 동작 과정

| 순서 | 과정 |
|---:|---|
| 1 | K개의 centroid를 초기화한다 |
| 2 | 각 데이터를 가장 가까운 centroid에 할당한다 |
| 3 | 각 cluster에 속한 데이터들의 평균으로 centroid를 갱신한다 |
| 4 | 데이터 할당과 centroid 갱신을 반복한다 |
| 5 | centroid 변화가 작아지면 종료한다 |

## K-means 목적 함수

K-means는 각 데이터가 자기 cluster 중심점에서 최대한 가깝도록 cluster를 만든다.

\[
J = \sum_{i=1}^{K} \sum_{x \in C_i} ||x-\mu_i||^2
\]

| 기호 | 의미 |
|---|---|
| \(K\) | cluster 개수 |
| \(C_i\) | i번째 cluster |
| \(x\) | 데이터 포인트 |
| \(\mu_i\) | i번째 cluster의 centroid |

즉, K-means는 cluster 내부 거리는 작게, cluster 간 거리는 크게 만드는 것을 목표로 한다.

## K-means 거리 계산

가장 많이 쓰는 거리는 Euclidean Distance이다.

\[
d(x,y)=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2}
\]

예를 들어 A(1, 1), B(4, 5)의 거리는 다음과 같다.

\[
d(A,B)=\sqrt{(4-1)^2+(5-1)^2}=5
\]

## K-means 초기화 방식

K-means에서 중요한 것은 초기 centroid를 어디에 두는가이다.

초기값이 좋지 않으면 local optimum에 빠지거나 수렴이 느려질 수 있다.

| 초기화 방식 | 핵심 아이디어 | 장점 | 단점 |
|---|---|---|---|
| Forgy Method | 데이터 중 K개를 랜덤 선택 | 단순하고 빠름 | 초기값에 민감 |
| Random Partition | 데이터를 랜덤 cluster에 배정 후 평균 계산 | 구현 쉬움 | 실제 구조 반영 약함 |
| K-means++ | 멀리 떨어진 점을 확률적으로 선택 | 안정적이고 수렴 빠름 | 초기화 비용 증가 |
| Maximin | 가장 멀리 떨어진 점 선택 | centroid 분산 좋음 | outlier에 취약 |
| PCA 기반 초기화 | 주성분 방향에 centroid 배치 | 분산 구조 반영 | 비선형 구조에 약함 |
| Multiple Random Starts | 여러 번 실행 후 최선 선택 | 안정성 높음 | 계산 비용 증가 |

실무에서는 보통 K-means++와 Multiple Random Starts 조합을 많이 사용한다.

## K-means 장점과 단점

| 구분 | 내용 |
|---|---|
| 장점 | 계산이 빠르고 이해하기 쉽다 |
| 장점 | 구현이 단순하고 대용량 데이터에 사용 가능하다 |
| 단점 | K를 미리 정해야 한다 |
| 단점 | 초기 centroid에 민감하다 |
| 단점 | 이상치에 약하다 |
| 단점 | Feature scale에 민감하다 |
| 단점 | 복잡한 모양의 cluster를 잘 못 잡을 수 있다 |

## K를 정하는 방법

### Elbow Method

K를 바꿔가며 WCSS(Within-Cluster Sum of Squares)를 계산한다. K가 증가하면 WCSS는 감소하지만, 어느 순간부터 감소 폭이 작아진다. 그 꺾이는 지점을 elbow point라고 한다.

### Silhouette Score

Silhouette Score는 cluster가 얼마나 잘 나뉘었는지 평가하는 지표이다.

| 값 | 해석 |
|---:|---|
| 1에 가까움 | cluster가 잘 분리됨 |
| 0 근처 | cluster 경계가 애매함 |
| 음수 | 잘못된 cluster에 배정되었을 가능성 있음 |

# 5. K-NN

## K-NN 개념

**K-NN(K-Nearest Neighbors)**은 새로운 데이터가 들어왔을 때 주변의 가장 가까운 K개 데이터를 보고 예측하는 알고리즘이다.

K-NN은 기본적으로 Supervised Learning이다. 즉, 학습 데이터에 정답 label이 있어야 한다.

## K-NN에서 K의 의미

K-NN의 K는 **몇 개의 가까운 이웃을 볼 것인가**이다.

| K 값 | 의미 |
|---:|---|
| K = 1 | 가장 가까운 1개 데이터만 보고 판단 |
| K = 3 | 가장 가까운 3개 데이터를 보고 다수결 |
| K = 5 | 가장 가까운 5개 데이터를 보고 다수결 |

## K-NN Classification

K-NN을 classification에 쓰면 가까운 K개 이웃의 다수결로 class를 정한다.

예를 들어 K = 5일 때 가까운 이웃이 다음과 같다고 하자.

| 이웃 | label |
|---:|---|
| 1 | 스팸 |
| 2 | 스팸 |
| 3 | 정상 |
| 4 | 스팸 |
| 5 | 정상 |

스팸 3개, 정상 2개이므로 새 이메일은 스팸으로 분류된다.

## K-NN Regression

K-NN은 regression에도 사용할 수 있다.

이 경우 가까운 K개 데이터의 평균값을 예측값으로 사용한다.

| 가까운 집 | 가격 |
|---|---:|
| 1 | 5억 |
| 2 | 5.5억 |
| 3 | 6억 |

\[
예측값 = \frac{5+5.5+6}{3}=5.5
\]

따라서 새 집의 예측 가격은 5.5억이다.

## K-means와 K-NN 차이

| 구분 | K-means | K-NN |
|---|---|---|
| 전체 이름 | K-means Clustering | K-Nearest Neighbors |
| 학습 방식 | Unsupervised Learning | Supervised Learning |
| 목적 | 비슷한 데이터끼리 군집화 | 새 데이터의 class 또는 값을 예측 |
| 정답 label 필요 여부 | 필요 없음 | 필요함 |
| 대표 사용 | Clustering | Classification, Regression |
| K의 의미 | 만들 cluster 개수 | 참고할 이웃 개수 |

일반적인 머신러닝 기본 개념에서는 K-NN은 clustering 알고리즘이 아니다. 다만 KNN graph를 만든 뒤 graph clustering, spectral clustering, community detection 등으로 확장할 수 있다.

# 6. Bayes’ Theorem

## Bayes’ Theorem 개념

**Bayes’ Theorem**은 어떤 증거가 관측되었을 때 원인이 무엇일 가능성이 높은지를 계산하는 방법이다.

쉽게 말하면 새로운 증거를 보고 기존 확률을 업데이트하는 공식이다.

## Bayes’ Theorem 공식

\[
P(A|B)=\frac{P(B|A)P(A)}{P(B)}
\]

각 항의 의미는 다음과 같다.

| 기호 | 의미 |
|---|---|
| \(P(A)\) | A가 원래 일어날 확률, Prior Probability |
| \(P(B)\) | B가 일어날 전체 확률, Evidence |
| \(P(A|B)\) | B가 일어났을 때 A가 일어날 확률, Posterior Probability |
| \(P(B|A)\) | A가 일어났을 때 B가 일어날 확률, Likelihood |

즉, Bayes’ Theorem은 다음 구조로 이해할 수 있다.

\[
Posterior = \frac{Likelihood \times Prior}{Evidence}
\]

## 질병 검사 예제

어떤 질병 검사에 대해 다음 정보가 있다고 하자.

| 항목 | 값 |
|---|---:|
| 질병 보유 확률 | 1% |
| 질병이 있을 때 양성 확률 | 99% |
| 질병이 없을 때 양성으로 잘못 나올 확률 | 5% |

검사 결과가 양성일 때 실제로 질병이 있을 확률을 구하라.

\[
P(D|+) = \frac{P(+|D)P(D)}{P(+)}
\]

전체 양성 확률은 다음과 같다.

\[
P(+)=P(+|D)P(D)+P(+|\neg D)P(\neg D)
\]

\[
P(+)=0.99 \times 0.01 + 0.05 \times 0.99 = 0.0594
\]

따라서

\[
P(D|+)=\frac{0.99 \times 0.01}{0.0594}=0.1667
\]

정답은 약 16.67%이다.

## P(A|B)와 P(B|A)의 차이

| 확률 | 의미 |
|---|---|
| \(P(양성|질병)\) | 질병이 있을 때 검사 결과가 양성일 확률 |
| \(P(질병|양성)\) | 검사 결과가 양성일 때 실제로 질병이 있을 확률 |

검사 정확도가 높아 보여도 질병 자체가 드물면 \(P(질병|양성)\)은 생각보다 낮을 수 있다. 이를 Base Rate Problem이라고 한다.

# 7. Association Rule

## Association Rule 개념

**Association Rule**은 item 간의 동시 등장 관계를 찾는 방법이다.

대표적인 형태는 다음과 같다.

\[
A \rightarrow B
\]

이 의미는 A를 가진 transaction에서 B도 같이 나타나는 경향이 있다는 뜻이다.

예를 들어 우유를 산 사람이 빵도 같이 사는 경향이 있는지 분석할 수 있다.

## Support 개념

Support는 어떤 itemset이 전체 transaction 중에서 얼마나 자주 등장하는지를 나타낸다.

규칙 A → B의 Support는 A와 B가 동시에 등장한 transaction 비율이다.

\[
Support(A \rightarrow B)=Support(A \cup B)
\]

\[
Support(A \rightarrow B)=\frac{A와\ B를\ 모두\ 포함한\ transaction\ 수}{전체\ transaction\ 수}
\]

Support는 A만 등장한 비율도 아니고, B만 등장한 비율도 아니다. 반드시 A와 B가 동시에 등장한 비율이다.

## Support 예제

| Transaction | 구매 item |
|---|---|
| T1 | 우유, 빵 |
| T2 | 우유, 기저귀, 맥주 |
| T3 | 빵, 기저귀 |
| T4 | 우유, 빵, 기저귀 |
| T5 | 우유, 빵, 맥주 |

규칙 우유 → 빵의 Support를 구해보자.

우유와 빵이 동시에 등장한 transaction은 T1, T4, T5이다.

\[
Support(우유 \rightarrow 빵)=\frac{3}{5}=0.6
\]

정답은 60%이다.

## Support, Confidence, Lift

| 지표 | 공식 | 의미 |
|---|---|---|
| Support | A와 B 동시 등장 수 / 전체 transaction 수 | 전체 데이터에서 규칙이 얼마나 자주 나타나는가 |
| Confidence | A와 B 동시 등장 수 / A 등장 수 | A가 있을 때 B도 있을 확률 |
| Lift | Confidence(A → B) / Support(B) | A와 B가 우연보다 얼마나 강하게 연결되는가 |

# 8. Logistic Regression과 Cross Entropy

## Logistic Regression 개념

**Logistic Regression**은 분류 문제에서 class에 속할 확률을 예측하는 모델이다.

먼저 선형식을 만든다.

\[
z=w_1x_1+w_2x_2+\cdots+w_kx_k+b
\]

벡터 형태로 쓰면 다음과 같다.

\[
z=w^Tx+b
\]

그리고 이 값을 Sigmoid Function에 넣어서 확률로 변환한다.

\[
\hat{p}=\frac{1}{1+e^{-z}}
\]

여기서 \(\hat{p}\)는 class 1일 예측 확률이다.

## Odds와 Log Odds

확률 \(p\)가 있을 때 Odds는 다음과 같다.

\[
Odds=\frac{p}{1-p}
\]

예를 들어 \(p=0.8\)이면

\[
Odds=\frac{0.8}{1-0.8}=\frac{0.8}{0.2}=4
\]

즉, 성공할 가능성이 실패할 가능성보다 4배 크다는 뜻이다.

Logistic Regression은 Log Odds를 선형식으로 둔다.

\[
\log\left(\frac{p}{1-p}\right)=w^Tx+b
\]

## Cross Entropy Loss

이진 분류에서 Cross Entropy Loss는 다음과 같다.

\[
Loss=-[y\log(\hat{p})+(1-y)\log(1-\hat{p})]
\]

전체 데이터에 대해서는 평균을 낸다.

\[
J(w,b)=-\frac{1}{n}\sum_{i=1}^{n}[y_i\log(\hat{p_i})+(1-y_i)\log(1-\hat{p_i})]
\]

Cross Entropy는 정답 class에 낮은 확률을 주거나 오답 class에 높은 확률을 주면 큰 벌점을 준다.

## 경계면 Decision Boundary

보통 threshold를 0.5로 둔다.

| 조건 | 예측 class |
|---|---|
| \(\hat{p} \ge 0.5\) | class 1 |
| \(\hat{p} < 0.5\) | class 0 |

Sigmoid Function에서 \(\hat{p}=0.5\)가 되는 지점은 \(z=0\)이다.

따라서 Logistic Regression의 decision boundary는 다음과 같다.

\[
w^Tx+b=0
\]

정확히 표현하면 다음과 같다.

**Logistic Regression은 Cross Entropy Loss를 최소화하도록 \(w\), \(b\)를 학습하고, 학습된 \(w\), \(b\)에 의해 \(w^Tx+b=0\)인 decision boundary가 정해진다.**

# 9. Linear Regression, 절편, 회귀계수

## 단순선형회귀 회귀선

단순선형회귀는 다음처럼 표현한다.

\[
\hat{y}=b_0+b_1x
\]

| 기호 | 의미 |
|---|---|
| \(\hat{y}\) | 예측값 |
| \(x\) | 독립변수 |
| \(b_0\) | 절편, intercept |
| \(b_1\) | 회귀계수, slope coefficient |

## 회귀계수 공식

\[
b_1=\frac{\sum(x_i-\bar{x})(y_i-\bar{y})}{\sum(x_i-\bar{x})^2}
\]

또는 공분산과 분산으로 쓰면 다음과 같다.

\[
b_1=\frac{Cov(x,y)}{Var(x)}
\]

회귀계수 \(b_1\)은 \(x\)가 1 증가할 때 \(y\)가 평균적으로 얼마나 변하는지 나타낸다.

## 절편 공식

\[
b_0=\bar{y}-b_1\bar{x}
\]

절편 \(b_0\)는 \(x=0\)일 때의 예측값이다.

## 계산 예시

| x | y |
|---:|---:|
| 1 | 2 |
| 2 | 4 |
| 3 | 5 |

\[
\bar{x}=2
\]

\[
\bar{y}=\frac{11}{3}=3.667
\]

\[
\sum(x_i-\bar{x})(y_i-\bar{y})=3
\]

\[
\sum(x_i-\bar{x})^2=2
\]

\[
b_1=\frac{3}{2}=1.5
\]

\[
b_0=3.667-1.5(2)=0.667
\]

따라서 회귀식은 다음과 같다.

\[
\hat{y}=0.667+1.5x
\]

## 다중선형회귀

독립변수가 여러 개인 경우 다음처럼 쓴다.

\[
\hat{y}=b_0+b_1x_1+b_2x_2+\cdots+b_kx_k
\]

행렬식으로는 다음과 같다.

\[
\boldsymbol{b}=(X^TX)^{-1}X^Ty
\]

# 10. R²와 회귀 평가

## R² 개념

**R²(R-squared, 결정계수)**는 기본적으로 종속변수 \(y\)가 연속형 데이터일 때 쓰는 회귀 평가 지표이다.

\[
R^2=1-\frac{SSE}{SST}
\]

| 기호 | 의미 |
|---|---|
| SSE(Sum of Squared Errors) | 모델 예측값과 실제값의 오차 제곱합 |
| SST(Total Sum of Squares) | 실제값이 평균으로부터 떨어진 정도의 제곱합 |

R²는 다음 질문에 답한다.

**그냥 평균으로 예측하는 것보다 모델이 얼마나 더 잘 설명했는가?**

예를 들어 R² = 0.8이면 종속변수 \(y\)의 변동 중 약 80%를 모델이 설명한다는 의미이다.

## R² 사용처

| 문제 | 종속변수 y | R² 사용 |
|---|---|---|
| 집값 예측 | 가격 | 사용 가능 |
| 키 예측 | cm 단위 키 | 사용 가능 |
| 매출 예측 | 금액 | 사용 가능 |
| 온도 예측 | ℃ | 사용 가능 |
| 합격/불합격 예측 | 0 또는 1 | 일반 R² 부적절 |
| 스팸/정상 분류 | class label | 일반 R² 부적절 |

중요한 것은 독립변수 \(x\)가 아니라 종속변수 \(y\)이다. 일반적인 R² 해석은 종속변수가 연속형일 때 자연스럽다.

Logistic Regression에서는 일반 R² 대신 Pseudo R²를 쓰기도 하지만, 선형회귀의 R²와 해석이 완전히 같지는 않다.

# 11. 분산 계산 공식

## 데이터 개수, 합, 제곱합으로 모집단 분산 계산

데이터 개수 \(n\), \(\sum x\), \(\sum x^2\)를 알고 있으면 분산을 빠르게 계산할 수 있다.

모집단 분산은 다음과 같다.

\[
\sigma^2=\frac{\sum x^2}{n}-\left(\frac{\sum x}{n}\right)^2
\]

즉,

\[
분산 = x^2의\ 평균 - x평균의\ 제곱
\]

## 표본 분산 공식

전체 모집단이 아니라 일부 표본 데이터라면 표본 분산을 사용한다.

\[
s^2=\frac{\sum x^2-\frac{(\sum x)^2}{n}}{n-1}
\]

표본 분산은 \(n\)이 아니라 \(n-1\)로 나눈다.

## 예시

데이터가 2, 4, 6, 8이라고 하자.

| 항목 | 값 |
|---|---:|
| \(n\) | 4 |
| \(\sum x\) | 20 |
| \(\sum x^2\) | 120 |

모집단 분산은 다음과 같다.

\[
\sigma^2=\frac{120}{4}-\left(\frac{20}{4}\right)^2
\]

\[
\sigma^2=30-25=5
\]

표본 분산은 다음과 같다.

\[
s^2=\frac{120-\frac{20^2}{4}}{4-1}
\]

\[
s^2=\frac{120-100}{3}=\frac{20}{3}=6.67
\]

## 주의할 점

\[
\sum x^2
\]

와

\[
(\sum x)^2
\]

는 다르다.

예를 들어 데이터가 2, 4, 6, 8이면

\[
\sum x^2=2^2+4^2+6^2+8^2=120
\]

하지만

\[
(\sum x)^2=(2+4+6+8)^2=20^2=400
\]

이다.

# 12. t 통계량과 F 통계량

## t 통계량

**t 통계량**은 어떤 추정값이 기준값에서 얼마나 떨어져 있는지를 표준오차 단위로 나타낸 값이다.

\[
t=\frac{estimate-hypothesized\ value}{SE}
\]

즉,

\[
t=\frac{추정값-가설에서의\ 기준값}{표준오차}
\]

t 값의 절댓값이 클수록 우연히 이렇게 나왔을 가능성이 작다고 본다.

## t 통계량 대표 사용처

| 사용처 | 설명 |
|---|---|
| 단일표본 t-test | 하나의 표본 평균이 기준값과 다른지 검정 |
| 독립표본 t-test | 서로 다른 두 집단의 평균 차이 검정 |
| 대응표본 t-test | 같은 대상의 전후 평균 차이 검정 |
| 회귀계수 검정 | 특정 독립변수의 회귀계수가 유의한지 검정 |

## F 통계량

**F 통계량**은 두 종류의 변동을 비교하는 통계량이다.

\[
F=\frac{between-group\ variance}{within-group\ variance}
\]

ANOVA에서는 다음처럼 해석한다.

\[
F=\frac{집단\ 간\ 변동}{집단\ 내\ 변동}
\]

회귀분석에서는 다음처럼 볼 수 있다.

\[
F=\frac{모델이\ 설명한\ 변동}{모델이\ 설명하지\ 못한\ 오차\ 변동}
\]

## F 통계량 대표 사용처

| 사용처 | 설명 |
|---|---|
| ANOVA | 세 개 이상 집단의 평균 차이 검정 |
| 회귀모델 전체 유의성 검정 | 회귀모델 전체가 유의한지 검정 |
| 여러 회귀계수 동시 검정 | 여러 계수가 동시에 0인지 검정 |
| 두 분산 비교 | 두 집단 분산이 같은지 비교 |

## t 통계량과 F 통계량 차이

| 구분 | t 통계량 | F 통계량 |
|---|---|---|
| 주 목적 | 평균 차이, 회귀계수 하나의 유의성 검정 | 여러 평균 비교, 모델 전체 유의성 검정 |
| 비교 대상 | 하나의 추정값 | 여러 집단 또는 전체 모델 |
| 대표 분포 | t-distribution | F-distribution |
| 값의 범위 | 음수, 0, 양수 가능 | 항상 0 이상 |

특별한 경우에는 다음 관계가 성립한다.

\[
F=t^2
\]

예를 들어 독립변수가 1개인 단순선형회귀에서는 회귀계수에 대한 t 검정과 모델 전체에 대한 F 검정이 같은 결론을 준다.

# 13. t분포

## t분포 개념

**t분포(t-distribution)**는 표본의 크기가 작고, 모집단의 표준편차를 모를 때 평균 검정에 사용하는 확률분포이다.

모집단 표준편차 \(\sigma\)를 모르고 표본 표준편차 \(s\)만 가지고 평균을 검정해야 할 때 사용한다.

## t통계량 공식

단일 표본 평균 검정에서 t통계량은 다음과 같다.

\[
t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}}
\]

| 기호 | 의미 |
|---|---|
| \(\bar{x}\) | 표본 평균 |
| \(\mu_0\) | 귀무가설에서 주장하는 모집단 평균 |
| \(s\) | 표본 표준편차 |
| \(n\) | 표본 개수 |
| \(s/\sqrt{n}\) | 표준오차 |

## t분포의 모양

t분포는 정규분포와 비슷하게 가운데가 높고 좌우 대칭이다. 하지만 정규분포보다 꼬리가 두껍다.

| 구분 | 정규분포 | t분포 |
|---|---|---|
| 모양 | 좌우 대칭 | 좌우 대칭 |
| 중심 | 0 | 0 |
| 꼬리 | 상대적으로 얇음 | 상대적으로 두꺼움 |
| 사용 조건 | 모집단 표준편차를 알 때 | 모집단 표준편차를 모를 때 |
| 표본 크기 영향 | 없음 | 자유도에 따라 모양 변화 |

## 자유도

단일 표본 t검정에서는 자유도가 다음과 같다.

\[
df=n-1
\]

자유도가 작으면 t분포의 꼬리가 더 두껍고, 자유도가 커질수록 t분포는 표준정규분포에 가까워진다.

## 정규분포와 카이제곱분포로 정의하는 t분포

t분포는 표준정규분포와 카이제곱분포로 정의할 수 있다.

\[
T=\frac{Z}{\sqrt{V/\nu}}\sim t_\nu
\]

조건은 다음과 같다.

| 기호 | 의미 |
|---|---|
| \(Z\) | 표준정규분포를 따르는 확률변수 |
| \(Z \sim N(0,1)\) | 평균 0, 분산 1인 정규분포 |
| \(V\) | 카이제곱분포를 따르는 확률변수 |
| \(V \sim \chi^2_\nu\) | 자유도 \(\nu\)인 카이제곱분포 |
| \(\nu\) | 자유도 |
| \(Z\)와 \(V\) | 서로 독립이어야 함 |

즉, 분자는 표준정규분포이고, 분모는 자유도로 나눈 카이제곱분포의 제곱근이다.

## 표본평균 t통계량과의 연결

모집단이 정규분포라고 하자.

\[
X_1,X_2,\cdots,X_n \sim N(\mu,\sigma^2)
\]

그러면

\[
Z=\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1)
\]

그리고

\[
V=\frac{(n-1)S^2}{\sigma^2}\sim \chi^2_{n-1}
\]

따라서

\[
\frac{\bar{X}-\mu}{S/\sqrt{n}}\sim t_{n-1}
\]

이 된다.

# 14. T검정별 자유도

T검정에서 자유도는 검정 종류마다 다르게 계산한다.

## 단일표본 t검정

하나의 표본 평균이 특정 기준값과 다른지 검정할 때 사용한다.

\[
df=n-1
\]

## 대응표본 t검정

같은 대상에서 전후 차이를 비교할 때 사용한다.

각 쌍의 차이값을 만든다.

\[
d_i=x_{after,i}-x_{before,i}
\]

자유도는 차이값 개수 기준으로 계산한다.

\[
df=n_d-1
\]

## 독립표본 t검정, 등분산 가정

서로 독립인 두 집단의 평균 차이를 검정할 때 사용한다. 두 집단의 분산이 같다고 가정한다.

\[
df=n_1+n_2-2
\]

## Welch t검정, 등분산 가정 안 함

두 집단 평균을 비교하지만 두 집단의 분산이 같다고 보기 어려울 때 사용한다.

\[
df=
\frac{
\left(\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}\right)^2
}{
\frac{\left(\frac{s_1^2}{n_1}\right)^2}{n_1-1}
+
\frac{\left(\frac{s_2^2}{n_2}\right)^2}{n_2-1}
}
\]

Welch 자유도는 보통 정수가 아닌 소수로 나온다.

## 상관계수 검정

상관계수 \(r\)이 0과 유의하게 다른지 검정할 때도 t검정을 사용한다.

\[
t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}}
\]

\[
df=n-2
\]

## 회귀계수 t검정

단순선형회귀에서는 절편과 기울기 두 개를 추정하므로 자유도는 다음과 같다.

\[
df=n-2
\]

다중선형회귀에서는 다음과 같다.

\[
df=n-k-1
\]

| 기호 | 의미 |
|---|---|
| \(n\) | 데이터 개수 |
| \(k\) | 독립변수 개수 |
| \(1\) | 절편 개수 |

## T검정별 자유도 요약

| 검정 종류 | 사용 상황 | 자유도 공식 |
|---|---|---|
| 단일표본 t검정 | 한 표본 평균 vs 기준값 | \(df=n-1\) |
| 대응표본 t검정 | 같은 대상의 전후 비교 | \(df=n_d-1\) |
| 독립표본 t검정, 등분산 | 두 독립 집단 평균 비교 | \(df=n_1+n_2-2\) |
| Welch t검정 | 두 독립 집단 평균 비교, 이분산 | Welch-Satterthwaite 공식 |
| 상관계수 t검정 | 상관계수 유의성 검정 | \(df=n-2\) |
| 단순회귀 계수 t검정 | 회귀계수 1개 유의성 검정 | \(df=n-2\) |
| 다중회귀 계수 t검정 | 여러 독립변수 중 특정 계수 검정 | \(df=n-k-1\) |

# 15. ANOVA 변동과 자유도

## ANOVA 변동의 구성

ANOVA(Analysis of Variance, 분산분석)에서 변동은 크게 3개로 나눈다.

| 변동 | 영어 | 의미 |
|---|---|---|
| 전체 변동 | Total Variation | 전체 데이터가 전체 평균에서 얼마나 흩어져 있는가 |
| 그룹간 변동 | Between-group Variation | 각 그룹 평균들이 전체 평균에서 얼마나 떨어져 있는가 |
| 그룹내 변동 | Within-group Variation | 각 데이터가 자기 그룹 평균에서 얼마나 떨어져 있는가 |

핵심 관계는 다음이다.

\[
SST=SSB+SSW
\]

| 기호 | 의미 |
|---|---|
| SST(Sum of Squares Total) | 전체 제곱합 |
| SSB(Sum of Squares Between) | 그룹간 제곱합 |
| SSW(Sum of Squares Within) | 그룹내 제곱합 |

## 자유도 공식

그룹 개수를 \(k\), 전체 데이터 개수를 \(N\)이라고 하면 다음과 같다.

| 구분 | 제곱합 | 자유도 |
|---|---|---:|
| 그룹간 변동 | SSB | \(k-1\) |
| 그룹내 변동 | SSW | \(N-k\) |
| 전체 변동 | SST | \(N-1\) |

즉,

\[
df_{between}=k-1
\]

\[
df_{within}=N-k
\]

\[
df_{total}=N-1
\]

자유도도 다음 관계를 가진다.

\[
df_{total}=df_{between}+df_{within}
\]

\[
N-1=(k-1)+(N-k)
\]

## 전체 변동

전체 변동은 모든 데이터가 전체 평균에서 얼마나 떨어져 있는지를 본다.

\[
SST=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(x_{ij}-\bar{x})^2
\]

전체 평균 \(\bar{x}\) 하나를 계산했기 때문에 자유도는 \(N-1\)이다.

## 그룹간 변동

그룹간 변동은 각 그룹 평균이 전체 평균에서 얼마나 떨어져 있는지를 본다.

\[
SSB=\sum_{i=1}^{k}n_i(\bar{x_i}-\bar{x})^2
\]

그룹 평균은 \(k\)개 있지만 전체 평균이 정해지면 마지막 하나는 독립적으로 마음대로 변할 수 없다. 그래서 자유도는 \(k-1\)이다.

## 그룹내 변동

그룹내 변동은 각 데이터가 자기 그룹 평균에서 얼마나 떨어져 있는지를 본다.

\[
SSW=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(x_{ij}-\bar{x_i})^2
\]

각 그룹마다 그룹 평균을 하나씩 계산하므로 전체 데이터 개수 \(N\)에서 그룹 개수 \(k\)를 뺀다.

\[
df_{within}=N-k
\]

또는 각 그룹별 자유도를 더해도 된다.

\[
df_{within}=(n_1-1)+(n_2-1)+\cdots+(n_k-1)
\]

## 평균제곱과 F 통계량

ANOVA에서는 제곱합을 자유도로 나눠서 평균제곱을 만든다.

\[
MSB=\frac{SSB}{k-1}
\]

\[
MSW=\frac{SSW}{N-k}
\]

F 통계량은 다음이다.

\[
F=\frac{MSB}{MSW}
\]

즉,

\[
F=\frac{SSB/(k-1)}{SSW/(N-k)}
\]

## ANOVA 표

| Source | Sum of Squares | df | Mean Square | F |
|---|---:|---:|---:|---:|
| Between Groups | SSB | \(k-1\) | \(MSB=\frac{SSB}{k-1}\) | \(\frac{MSB}{MSW}\) |
| Within Groups | SSW | \(N-k\) | \(MSW=\frac{SSW}{N-k}\) |  |
| Total | SST | \(N-1\) |  |  |

# 16. 왜도, 첨도, 분위수

## 왜도 Skewness

**왜도(Skewness)**는 데이터 분포가 좌우 대칭에서 얼마나 벗어났는지를 나타내는 값이다.

\[
Skewness=\frac{E[(X-\mu)^3]}{\sigma^3}
\]

| 왜도 값 | 분포 모양 | 해석 |
|---:|---|---|
| 0 근처 | 좌우 대칭 | 평균 주변으로 균형 잡힌 분포 |
| 양수 | 오른쪽 꼬리가 김 | 큰 값 쪽으로 일부 데이터가 길게 퍼짐 |
| 음수 | 왼쪽 꼬리가 김 | 작은 값 쪽으로 일부 데이터가 길게 퍼짐 |

양의 왜도에서는 보통 다음 관계가 자주 나타난다.

\[
평균 > 중앙값 > 최빈값
\]

음의 왜도에서는 보통 다음 관계가 자주 나타난다.

\[
평균 < 중앙값 < 최빈값
\]

## 첨도 Kurtosis

**첨도(Kurtosis)**는 분포의 꼬리가 얼마나 두껍고 극단값이 얼마나 자주 나타나는지를 설명하는 지표이다.

\[
Kurtosis=\frac{E[(X-\mu)^4]}{\sigma^4}
\]

정규분포의 첨도는 보통 3이다.

실제 분석에서는 Excess Kurtosis를 더 자주 사용한다.

\[
Excess\ Kurtosis=Kurtosis-3
\]

| 구분 | Kurtosis | Excess Kurtosis | 해석 |
|---|---:|---:|---|
| Mesokurtic | 3 | 0 | 정규분포와 비슷한 꼬리 |
| Leptokurtic | 3보다 큼 | 양수 | 꼬리가 두껍고 극단값이 많음 |
| Platykurtic | 3보다 작음 | 음수 | 꼬리가 얇고 극단값이 적음 |

첨도는 단순히 봉우리가 뾰족한 정도가 아니라 극단값 발생 가능성과 관련이 깊다.

## 분위수 Quantile

**분위수(Quantile)**는 데이터를 작은 값부터 큰 값까지 정렬했을 때 특정 비율 위치에 있는 값을 말한다.

| 위치 | 의미 |
|---|---|
| 하위 25% 지점 | 제1사분위수 Q1 |
| 하위 50% 지점 | 중앙값 Median, Q2 |
| 하위 75% 지점 | 제3사분위수 Q3 |
| 하위 90% 지점 | 90th Percentile |

## 사분위수 Quartile

| 분위수 | 영어 | 의미 |
|---|---|---|
| Q1 | First Quartile | 하위 25% 지점 |
| Q2 | Second Quartile, Median | 하위 50% 지점, 중앙값 |
| Q3 | Third Quartile | 하위 75% 지점 |

## IQR

IQR(Interquartile Range, 사분위 범위)은 다음과 같다.

\[
IQR=Q3-Q1
\]

IQR은 가운데 50% 데이터가 퍼져 있는 범위를 의미한다.

## IQR과 이상치

보통 다음 범위를 벗어나면 이상치 후보로 본다.

\[
Lower\ Bound=Q1-1.5 \times IQR
\]

\[
Upper\ Bound=Q3+1.5 \times IQR
\]

## 통신 데이터에서 분위수 활용

통신/RF 데이터에서는 평균만 보는 것보다 분위수를 같이 보는 것이 중요하다.

예를 들어 평균 Throughput이 높아도 5th percentile Throughput이 낮으면 하위 사용자 체감 품질은 나쁠 수 있다.

| 지표 | 평균만 볼 때 문제 |
|---|---|
| Throughput | 일부 고속 사용자 때문에 평균이 높게 보일 수 있음 |
| RSRP(Reference Signal Received Power) | 음영지역 사용자 품질을 놓칠 수 있음 |
| SINR(Signal to Interference plus Noise Ratio) | 간섭이 심한 하위 구간을 놓칠 수 있음 |
| Latency | 평균 지연은 양호해도 tail latency가 나쁠 수 있음 |

# 17. 점추정

## 점추정 개념

**점추정(Point Estimation)**은 모집단의 모수(Parameter)를 하나의 값으로 추정하는 방법이다.

즉, 모집단 전체를 다 조사할 수 없으니 표본 데이터를 이용해서 모집단의 평균, 분산, 비율 같은 값을 하나의 숫자로 추정하는 것이다.

## 모수, 추정량, 추정값

| 개념 | 의미 | 예시 |
|---|---|---|
| 모수 Parameter | 모집단의 실제 값 | 모집단 평균 \(\mu\) |
| 추정량 Estimator | 모수를 추정하기 위한 공식 | 표본평균 \(\bar{x}\) |
| 추정값 Estimate | 실제 표본으로 계산된 숫자 | \(\bar{x}=172.5\) |

## 모집단 평균의 점추정

\[
\hat{\mu}=\bar{x}
\]

\[
\bar{x}=\frac{x_1+x_2+\cdots+x_n}{n}
\]

## 모집단 비율의 점추정

\[
\hat{p}=\frac{x}{n}
\]

| 기호 | 의미 |
|---|---|
| \(p\) | 모집단 비율 |
| \(\hat{p}\) | 표본비율 |
| \(x\) | 특정 특성을 가진 표본 개수 |
| \(n\) | 전체 표본 개수 |

## 모집단 분산의 점추정

모집단 분산 \(\sigma^2\)은 보통 표본분산 \(s^2\)로 추정한다.

\[
s^2=\frac{\sum(x_i-\bar{x})^2}{n-1}
\]

## 점추정과 구간추정

| 구분 | 점추정 | 구간추정 |
|---|---|---|
| 의미 | 하나의 값으로 추정 | 범위로 추정 |
| 예시 | 평균은 80이다 | 평균은 75에서 85 사이일 것이다 |
| 장점 | 간단함 | 불확실성 표현 가능 |
| 단점 | 오차 범위를 알기 어려움 | 계산과 해석이 더 복잡함 |

## 좋은 점추정량의 조건

| 조건 | 영어 | 의미 |
|---|---|---|
| 불편성 | Unbiasedness | 평균적으로 실제 모수와 같아야 함 |
| 일치성 | Consistency | 표본 수가 커질수록 실제 모수에 가까워져야 함 |
| 효율성 | Efficiency | 추정량의 분산이 작아야 함 |
| 충분성 | Sufficiency | 표본 정보가 모수 추정에 충분히 반영되어야 함 |

# 18. 표본추출 방법

## 층화추출 Stratified Sampling

**층화추출**은 모집단을 성격이 비슷한 여러 층으로 나눈 뒤, 각 층에서 표본을 뽑는 방법이다.

예를 들어 학교 학생 1,000명을 조사한다고 하자.

| 학년 | 학생 수 | 비율 | 표본 수 |
|---|---:|---:|---:|
| 1학년 | 300 | 30% | 30 |
| 2학년 | 250 | 25% | 25 |
| 3학년 | 250 | 25% | 25 |
| 4학년 | 200 | 20% | 20 |

층화추출에서는 모든 층에서 표본을 뽑는다.

핵심은 다음이다.

**모집단 안에 중요한 하위집단이 있을 때, 그 하위집단이 표본에서 빠지지 않도록 하는 방법이다.**

## 집락추출 Cluster Sampling

**집락추출**은 모집단을 여러 집락으로 나눈 뒤, 몇 개의 집락을 선택하고 그 집락 안의 대상들을 조사하는 방법이다.

예를 들어 전국 초등학생의 스마트폰 사용 시간을 조사할 때 학교를 집락으로 볼 수 있다.

| 집락 | 의미 |
|---|---|
| A초등학교 | 하나의 cluster |
| B초등학교 | 하나의 cluster |
| C초등학교 | 하나의 cluster |

이 중 몇 개 학교를 무작위로 선택하고, 선택된 학교의 학생들을 조사한다.

## 층화추출과 집락추출 차이

| 구분 | 층화추출 | 집락추출 |
|---|---|---|
| 영어 | Stratified Sampling | Cluster Sampling |
| 그룹 이름 | 층, strata | 집락, cluster |
| 그룹 구성 | 그룹 내부는 비슷함 | 그룹 내부가 모집단과 비슷함 |
| 표본 추출 방식 | 각 층에서 일부를 뽑음 | 몇 개 집락을 뽑고 그 안을 조사 |
| 목적 | 대표성 향상 | 조사 비용 절감 |
| 핵심 | 모든 층이 표본에 포함됨 | 일부 집락만 선택됨 |

## 그룹 내부 구조 차이

| 구분 | 그룹 내부 | 그룹 간 |
|---|---|---|
| 층화추출 | 같은 층 내부는 서로 비슷함 | 층끼리는 서로 다름 |
| 집락추출 | 한 집락 내부가 모집단 축소판에 가까움 | 집락끼리는 서로 비슷한 것이 좋음 |

한 문장으로 구분하면 다음과 같다.

**층화추출은 각 그룹에서 조금씩 뽑는다.**

**집락추출은 그룹 몇 개를 통째로 뽑는다.**

# 19. 시계열분석의 4가지 특성

시계열 데이터의 대표적인 특성은 다음 4가지이다.

| 구분 | 영어 표현 | 의미 |
|---|---|---|
| 1 | Trend | 장기적인 증가 또는 감소 방향 |
| 2 | Seasonality | 일정한 주기로 반복되는 패턴 |
| 3 | Cycle | 불규칙하지만 장기적으로 반복되는 경기적 흐름 |
| 4 | Irregular 또는 Random | 예측하기 어려운 우연한 변동 |

## Trend

Trend는 시간이 지남에 따라 데이터가 장기적으로 증가하거나 감소하는 방향이다.

예를 들어 매년 스마트폰 사용량이 증가하거나, 오래된 제품의 판매량이 감소하는 경우이다.

## Seasonality

Seasonality는 일정한 시간 주기로 반복되는 패턴이다.

계절이라는 말이 꼭 봄, 여름, 가을, 겨울만 의미하는 것은 아니다. 일, 주, 월, 분기, 연 단위로 반복되는 패턴도 포함한다.

| 주기 | 예시 |
|---|---|
| 하루 단위 | 출근 시간대 트래픽 증가 |
| 주 단위 | 주말 쇼핑몰 방문자 증가 |
| 월 단위 | 월급날 이후 소비 증가 |
| 분기 단위 | 분기말 실적 정산 |
| 연 단위 | 여름철 에어컨 판매 증가 |

RF나 통신 데이터로 보면 특정 시간대마다 데이터 트래픽이 반복적으로 증가하는 것도 계절성으로 볼 수 있다.

## Cycle

Cycle은 일정한 고정 주기는 아니지만, 장기적으로 상승과 하락이 반복되는 흐름이다.

| 구분 | Seasonality | Cycle |
|---|---|---|
| 반복 주기 | 비교적 일정함 | 일정하지 않음 |
| 원인 | 계절, 요일, 시간대 등 | 경기 변동, 산업 흐름, 수요 변화 |
| 예측성 | 상대적으로 높음 | 상대적으로 낮음 |

예를 들어 반도체 시장은 몇 년 단위로 호황과 불황을 반복할 수 있지만, 주기가 정확히 고정되어 있지는 않다.

## Irregular 또는 Random

Irregular component는 Trend, Seasonality, Cycle로 설명되지 않는 예측하기 어려운 변동이다.

| 예시 | 설명 |
|---|---|
| 갑작스러운 장애 | 통신망 트래픽 급감 또는 급증 |
| 자연재해 | 물류, 매출, 수요 변화 |
| 이벤트성 이슈 | 특정 뉴스로 인한 검색량 급증 |
| 장비 이상 | 센서 데이터의 비정상 튐 |
| 측정 노이즈 | 실제 패턴과 무관한 작은 변동 |

## 시계열 데이터 표현

시계열 데이터는 다음 네 요소가 합쳐진 것으로 볼 수 있다.

\[
Y_t=Trend_t+Seasonality_t+Cycle_t+Irregular_t
\]

또는 곱셈 형태로도 표현한다.

\[
Y_t=Trend_t \times Seasonality_t \times Cycle_t \times Irregular_t
\]

| 방식 | 의미 | 사용 상황 |
|---|---|---|
| Additive Model | 요소들이 더해져서 전체 값을 만듦 | 변동 폭이 비교적 일정할 때 |
| Multiplicative Model | 요소들이 곱해져서 전체 값을 만듦 | 값이 커질수록 변동 폭도 커질 때 |
