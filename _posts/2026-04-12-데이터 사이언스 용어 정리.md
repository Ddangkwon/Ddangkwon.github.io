# 1. 데이터와 통계의 기본 관점

데이터 사이언스(Data Science)는 데이터를 이용해 현상을 이해하고, 관계를 찾고, 미래를 예측하고, 의사결정을 돕는 분야이다.

통계(Statistics)는 데이터 속에 있는 경향, 차이, 관계, 불확실성을 수치로 해석하는 방법이다. 머신러닝(Machine Learning)은 데이터에서 패턴을 학습해 예측이나 분류를 수행하는 방법이다.

두 영역은 분리된 것이 아니라 연결되어 있다. 평균, 분산, 확률분포, 가설검정, 회귀분석, 평가 지표 같은 통계 개념이 머신러닝 모델 해석과 성능 평가의 기반이 된다.

통계에서 자주 보는 질문은 다음과 같다.

| 질문 | 통계에서의 의미 |
|---|---|
| 평균적으로 얼마인가 | 중심 경향을 본다 |
| 얼마나 퍼져 있는가 | 산포 또는 변동성을 본다 |
| 두 값이 같이 움직이는가 | 공분산과 상관을 본다 |
| 한 변수가 다른 변수를 설명하는가 | 회귀분석을 본다 |
| 관측된 차이가 우연인가 | 가설검정을 본다 |
| 특정 사건이 일어날 가능성은 얼마인가 | 확률과 확률분포를 본다 |
| 모델 예측이 얼마나 맞는가 | 평가 지표를 본다 |

# 2. 모집단, 표본, 모수, 통계량

## 2.1 데이터의 대상

데이터 분석에서는 먼저 **무엇을 알고 싶은지**와 **어떤 데이터를 가지고 있는지**를 구분해야 한다.

| 용어 | 의미 | 예시 |
|---|---|---|
| 모집단(Population) | 관심 있는 전체 대상 | 전국 성인 남성 전체 |
| 표본(Sample) | 모집단에서 일부만 뽑은 데이터 | 성인 남성 1,000명 |
| 관측값(Observation) | 실제로 측정된 하나의 데이터 단위 | 한 사람의 키, 한 단말의 RSRP 측정값 |
| 변수(Variable) | 관측값에서 측정되는 속성 | 키, 나이, 소득, Throughput |

## 2.2 모집단(Population)

모집단(Population)은 분석자가 관심을 가지는 전체 대상이다.

예를 들어 전국 성인 남성의 평균 키를 알고 싶다면 전국 성인 남성 전체가 모집단이다. 단말 로그 분석에서 특정 모델의 평균 RSRP(Reference Signal Received Power)를 알고 싶다면, 해당 조건에서 수집 가능한 전체 RSRP 측정값이 모집단이 될 수 있다.

실제로 모집단 전체를 조사하기 어려운 경우가 많으므로 표본을 뽑아 분석한다.

## 2.3 표본(Sample)

표본(Sample)은 모집단에서 일부만 뽑은 데이터이다.

표본은 모집단을 추정하기 위한 대표 데이터이다. 표본이 모집단을 잘 대표하지 못하면 분석 결과가 왜곡된다. 예를 들어 특정 지역, 특정 시간대, 특정 단말 조건에서만 수집한 데이터로 전체 성능을 판단하면 편향이 생길 수 있다.

## 2.4 모수(Parameter)

모수(Parameter)는 모집단의 특성을 나타내는 값이다.

예시는 다음과 같다.

| 모수 | 의미 |
|---|---|
| 모집단 평균 | 모집단 전체의 평균 |
| 모집단 분산 | 모집단 전체의 퍼짐 정도 |
| 모집단 비율 | 모집단에서 특정 조건을 만족하는 비율 |
| 모집단 상관계수 | 모집단 전체에서 두 변수의 상관 정도 |

모수는 보통 정확히 알 수 없기 때문에 표본을 이용해 추정한다.

## 2.5 통계량(Statistic)

통계량(Statistic)은 표본으로부터 계산한 값이다.

| 구분 | 의미 | 예시 |
|---|---|---|
| 모수(Parameter) | 모집단의 특성값 | 모집단 평균 키 |
| 통계량(Statistic) | 표본에서 계산한 값 | 표본 평균 키 |

통계량은 모수를 추정하기 위해 사용된다. 예를 들어 표본 평균은 모집단 평균을 추정하는 데 사용된다.

## 2.6 통계량의 종류

통계량은 목적에 따라 여러 종류로 나눌 수 있다.

| 종류 | 대표 통계량 | 주된 목적 |
|---|---|---|
| 중심 경향 통계량 | 평균, 중앙값, 최빈값 | 데이터의 대표 중심 확인 |
| 산포 통계량 | 분산, 표준편차, 범위, 사분위 범위 | 데이터가 얼마나 퍼져 있는지 확인 |
| 위치 통계량 | 백분위수, 사분위수, z-score | 특정 값의 상대적 위치 확인 |
| 비율과 빈도 통계량 | 빈도, 상대도수, 표본비율 | 범주형 데이터의 구성 확인 |
| 관계 통계량 | 공분산, 상관계수 | 두 변수의 관계 방향과 강도 확인 |
| 회귀 관련 통계량 | 회귀계수, 잔차, R-squared, Adjusted R-squared | 독립변수와 종속변수의 설명 관계 확인 |
| 분류 성능 통계량 | Accuracy, Precision, Recall, F1-score, AUC | 분류 모델의 예측 성능 평가 |
| 검정 통계량 | Z 통계량, t 통계량, Chi-square 통계량, F 통계량 | 가설검정에서 귀무가설 기각 여부 판단 |

# 3. 데이터 요약 통계량

## 3.1 평균(Mean)

평균(Mean)은 모든 값을 더한 뒤 데이터 개수로 나눈 값이다.

평균은 데이터의 중심을 가장 직관적으로 보여준다. 하지만 모든 값을 사용하기 때문에 이상치(Outlier)에 민감하다.

| 장점 | 단점 |
|---|---|
| 계산이 쉽고 해석이 직관적이다 | 이상치에 민감하다 |
| 모든 값을 반영한다 | 비대칭 분포에서는 대표값으로 부적절할 수 있다 |
| 회귀, 분산, 표준편차 계산의 기반이다 | 극단값 하나가 평균을 크게 움직일 수 있다 |

## 3.2 중앙값(Median)

중앙값(Median)은 데이터를 정렬했을 때 가운데 위치한 값이다.

데이터 개수가 홀수이면 가운데 값이고, 짝수이면 가운데 두 값의 평균을 사용한다.

중앙값은 이상치에 강하다. 소득, 집값, 트래픽, 지연시간처럼 오른쪽으로 긴 꼬리를 가진 데이터에서는 평균보다 중앙값이 더 현실적인 대표값일 수 있다.

## 3.3 최빈값(Mode)

최빈값(Mode)은 가장 자주 등장하는 값이다.

범주형 데이터에서도 사용할 수 있다. 예를 들어 가장 많이 선택된 요금제, 가장 많이 발생한 장애 유형, 가장 많이 등장한 클래스 등을 확인할 때 유용하다.

## 3.4 분산(Variance)

분산(Variance)은 데이터가 평균으로부터 얼마나 떨어져 있는지를 제곱 기준으로 측정한 값이다.

값이 클수록 데이터가 넓게 퍼져 있다. 다만 단위가 원래 데이터 단위의 제곱이 되므로 직관적 해석은 표준편차보다 어렵다.

| 장점 | 단점 |
|---|---|
| 퍼짐의 크기를 수치화한다 | 단위가 제곱이라 직관성이 낮다 |
| 표준편차와 통계검정의 기반이 된다 | 이상치에 민감하다 |
| 분포 비교에 유용하다 | 데이터 스케일에 따라 값이 크게 달라진다 |

## 3.5 표준편차(Standard Deviation)

표준편차(Standard Deviation)는 분산에 제곱근을 취한 값이다.

데이터가 평균 주변에 얼마나 퍼져 있는지를 원래 단위로 해석할 수 있다.

정규분포에서는 표준편차가 분포의 폭을 결정한다.

| 범위 | 포함 비율 |
|---|---|
| 평균 ± 1표준편차 | 약 68% |
| 평균 ± 2표준편차 | 약 95% |
| 평균 ± 3표준편차 | 약 99.7% |

이것을 68-95-99.7 법칙이라고 한다.

## 3.6 범위(Range)

범위(Range)는 최댓값에서 최솟값을 뺀 값이다.

전체 데이터가 어느 정도 폭을 가지는지 빠르게 볼 수 있다. 하지만 최댓값과 최솟값만 사용하기 때문에 이상치에 매우 민감하다.

## 3.7 사분위수(Quartile)와 IQR(Interquartile Range)

사분위수(Quartile)는 데이터를 정렬한 뒤 4등분하는 위치 값이다.

| 용어 | 의미 |
|---|---|
| Q1 | 하위 25% 지점 |
| Q2 | 중앙값, 50% 지점 |
| Q3 | 하위 75% 지점 |
| IQR | Q3 - Q1 |

IQR(Interquartile Range)은 가운데 50% 데이터의 폭이다. 이상치에 덜 민감하므로 비대칭 분포에서 유용하다.

## 3.8 표준점수(Z-score)

표준점수 또는 z-score는 특정 값이 평균으로부터 표준편차 몇 배만큼 떨어져 있는지를 나타낸다.

z-score = (값 - 평균) / 표준편차

| z-score | 해석 |
|---|---|
| 0 | 평균과 같다 |
| 양수 | 평균보다 크다 |
| 음수 | 평균보다 작다 |
| 절댓값이 큼 | 평균에서 멀리 떨어져 있다 |

예를 들어 평균이 70점이고 표준편차가 10점인 시험에서 85점을 받았다면, 평균보다 1.5표준편차 높은 값이다.

## 3.9 비율(Proportion)과 상대도수(Relative Frequency)

비율(Proportion)은 전체 중 특정 조건을 만족하는 데이터의 비중이다.

상대도수(Relative Frequency)는 특정 범주가 전체에서 차지하는 비율이다.

예를 들어 전체 1,000개 샘플 중 불량이 20개라면 불량 비율은 2%이다.

# 4. 확률과 확률분포

## 4.1 확률(Probability)

확률(Probability)은 어떤 사건이 발생할 가능성을 0에서 1 사이 값으로 나타낸 것이다.

| 값 | 의미 |
|---|---|
| 0 | 절대 발생하지 않음 |
| 1 | 반드시 발생함 |
| 0.5 | 발생과 미발생 가능성이 같음 |

## 4.2 확률의 세 가지 공리

확률은 다음 세 가지 공리를 만족해야 한다.

| 공리 | 설명 |
|---|---|
| 비음수성 | 모든 사건의 확률은 0 이상이다 |
| 전체확률 1 | 표본공간 전체가 발생할 확률은 1이다 |
| 가산성 | 서로 겹치지 않는 사건들의 합집합 확률은 각 확률의 합이다 |

## 4.3 사건(Event)

사건(Event)은 표본공간 안에서 관심 있는 결과의 집합이다.

예를 들어 주사위를 던질 때 짝수가 나오는 사건은 2, 4, 6이다.

## 4.4 조건부확률(Conditional Probability)

조건부확률(Conditional Probability)은 어떤 사건이 이미 발생했다는 조건에서 다른 사건이 발생할 확률이다.

P(A given B)는 B가 발생했다는 조건에서 A가 발생할 확률이다.

조건부확률의 핵심은 기준 집단이 전체가 아니라 B가 발생한 집단으로 바뀐다는 점이다.

| 구분 | 의미 |
|---|---|
| P(A) | 전체에서 A가 발생할 확률 |
| P(A given B) | B가 발생한 집단 안에서 A가 발생할 확률 |
| P(A and B) | A와 B가 동시에 발생할 확률 |

조건부확률에서 자주 하는 실수는 P(A given B)와 P(B given A)를 같은 것으로 착각하는 것이다. 두 값은 일반적으로 다르다.

## 4.5 조건부확률 문제를 푸는 방법

조건부확률 문제는 두 가지 방식으로 풀 수 있다.

첫 번째는 공식을 이용하는 방식이다.

P(A given B) = P(A and B) / P(B)

두 번째는 임의의 전체 수를 잡고 표로 푸는 방식이다.

예를 들어 전체를 1,000명으로 가정하고, 조건에 해당하는 사람 수와 사건에 해당하는 사람 수를 직접 채워 넣으면 직관적으로 이해하기 쉽다.

## 4.6 독립 사건(Independent Events)

두 사건 A와 B가 서로 영향을 주지 않으면 독립이라고 한다.

독립이면 다음 관계가 성립한다.

P(A and B) = P(A) × P(B)

또한 B가 일어났다는 정보가 A의 확률을 바꾸지 않는다.

P(A given B) = P(A)

## 4.7 상호배반(Mutually Exclusive)

상호배반(Mutually Exclusive)은 두 사건이 동시에 발생할 수 없는 경우이다.

A와 B가 상호배반이면 다음 관계가 성립한다.

P(A and B) = 0

주의할 점은 상호배반과 독립은 다른 개념이라는 것이다. 두 사건이 상호배반이고 두 사건의 확률이 0이 아니라면 일반적으로 독립이 아니다. 한 사건이 발생하면 다른 사건은 절대 발생할 수 없기 때문이다.

## 4.8 확률변수(Random Variable)

확률변수(Random Variable)는 확률적 실험의 결과를 숫자로 표현한 변수이다.

| 확률변수 종류 | 의미 | 예시 |
|---|---|---|
| 이산확률변수(Discrete Random Variable) | 셀 수 있는 값을 가짐 | 불량 개수, 성공 횟수, 주사위 눈금 |
| 연속확률변수(Continuous Random Variable) | 연속적인 값을 가짐 | 키, 온도, 시간, 전압 |

## 4.9 이산분포(Discrete Distribution)

이산분포(Discrete Distribution)는 확률변수가 셀 수 있는 값을 가지는 분포이다.

| 분포 | 사용 상황 |
|---|---|
| 베르누이 분포(Bernoulli Distribution) | 성공과 실패처럼 결과가 2개인 경우 |
| 이항분포(Binomial Distribution) | 독립 시행을 여러 번 반복했을 때 성공 횟수 |
| 포아송분포(Poisson Distribution) | 일정 시간 또는 공간에서 발생 횟수 |

## 4.10 연속분포(Continuous Distribution)

연속분포(Continuous Distribution)는 확률변수가 연속적인 값을 가지는 분포이다.

| 분포 | 사용 상황 |
|---|---|
| 정규분포(Normal Distribution) | 측정 오차, 시험 점수, 자연 현상 |
| 균등분포(Uniform Distribution) | 특정 구간에서 모든 값이 같은 가능성 |
| 지수분포(Exponential Distribution) | 사건 발생까지 걸리는 시간 |
| t분포(T Distribution) | 표본 수가 작고 모집단 분산을 모를 때 평균 검정 |
| 카이제곱분포(Chi-square Distribution) | 분산 검정, 독립성 검정 |
| F분포(F Distribution) | 분산분석, 회귀모형 비교 |

연속분포에서는 특정 한 점의 확률은 0으로 본다. 대신 구간의 확률을 면적으로 계산한다.

# 5. PMF, PDF, CDF

## 5.1 PMF(Probability Mass Function, 확률질량함수)

PMF(Probability Mass Function)는 이산확률변수에서 특정 값이 나올 확률을 나타내는 함수이다.

예를 들어 주사위를 한 번 던질 때 X가 나오는 눈금이라면, P(X = 3)은 3이 나올 확률이다.

PMF의 특징은 다음과 같다.

| 특징 | 설명 |
|---|---|
| 대상 | 이산확률변수 |
| 특정 값 확률 | 직접 계산 가능 |
| 전체 확률 합 | 모든 가능한 값의 확률 합은 1 |
| 예시 | 주사위 눈금, 불량 개수, 성공 횟수 |

## 5.2 PDF(Probability Density Function, 확률밀도함수)

PDF(Probability Density Function)는 연속확률변수에서 확률의 밀도를 나타내는 함수이다.

연속확률변수에서는 특정 값 하나가 나올 확률이 0이다. 예를 들어 키가 정확히 170.000000cm일 확률은 0에 가깝게 본다. 대신 169cm에서 171cm 사이처럼 구간 확률을 계산한다.

PDF에서 확률은 곡선 아래의 면적이다.

| 특징 | 설명 |
|---|---|
| 대상 | 연속확률변수 |
| 특정 값 확률 | 0으로 봄 |
| 구간 확률 | 곡선 아래 면적 |
| 전체 면적 | 전체 구간의 면적은 1 |
| 예시 | 키, 온도, 시간, 전압 |

## 5.3 CDF(Cumulative Distribution Function, 누적분포함수)

CDF(Cumulative Distribution Function)는 확률변수가 특정 값 이하일 확률을 나타낸다.

CDF는 이산형과 연속형 모두에서 사용할 수 있다.

| 특징 | 설명 |
|---|---|
| 의미 | X가 특정 값 이하일 확률 |
| 값 범위 | 0에서 1 사이 |
| 방향 | x가 커질수록 CDF는 감소하지 않음 |
| 마지막 값 | 전체 확률이므로 1에 가까워짐 |

CDF는 누적 확률을 보여주므로, 특정 기준 이하의 비율을 알고 싶을 때 유용하다.

## 5.4 PMF, PDF, CDF 비교

| 구분 | PMF | PDF | CDF |
|---|---|---|---|
| 대상 | 이산확률변수 | 연속확률변수 | 이산형과 연속형 모두 |
| 의미 | 특정 값의 확률 | 확률 밀도 | 특정 값 이하의 누적확률 |
| 확률 계산 | 값을 직접 더함 | 면적을 계산 | 누적값을 읽음 |
| 특정 값 확률 | 가능 | 0 | 특정 값 이하 확률 |
| 예시 | 불량 개수 | 온도, 전압 | 기준 이하 확률 |

# 6. 주요 확률분포

## 6.1 베르누이 분포(Bernoulli Distribution)

베르누이 분포(Bernoulli Distribution)는 결과가 성공과 실패 두 가지뿐인 시행을 표현한다.

예시는 다음과 같다.

| 성공 | 실패 |
|---|---|
| 구매함 | 구매하지 않음 |
| 불량 | 정상 |
| 양성 | 음성 |
| 접속 성공 | 접속 실패 |

## 6.2 이항분포(Binomial Distribution)

이항분포(Binomial Distribution)는 독립적인 베르누이 시행을 여러 번 반복했을 때 성공 횟수의 분포이다.

예를 들어 불량률이 1%인 부품을 100개 검사했을 때 불량 개수가 몇 개인지 분석할 수 있다.

이항분포를 사용하려면 일반적으로 다음 조건이 필요하다.

| 조건 | 설명 |
|---|---|
| 시행 횟수 고정 | n번 시행한다 |
| 결과가 두 가지 | 성공 또는 실패 |
| 성공확률 일정 | 각 시행의 성공확률이 동일하다 |
| 시행 독립 | 각 시행이 서로 영향을 주지 않는다 |

## 6.3 포아송분포(Poisson Distribution)

포아송분포(Poisson Distribution)는 일정 시간 또는 공간에서 사건이 몇 번 발생하는지를 모델링한다.

예시는 다음과 같다.

| 상황 | 포아송분포로 볼 수 있는 값 |
|---|---|
| 1시간 동안 서버 장애 발생 횟수 | 장애 횟수 |
| 하루 동안 콜 드랍 발생 횟수 | 콜 드랍 횟수 |
| 특정 구간에서 결함 발생 횟수 | 결함 개수 |

포아송분포는 평균 발생률이 일정하고 사건들이 독립적이라는 가정이 중요하다.

## 6.4 정규분포(Normal Distribution)

정규분포(Normal Distribution)는 평균을 중심으로 좌우 대칭인 종 모양의 연속확률분포이다.

측정 오차, 시험 점수, 자연 현상, 신호 잡음처럼 여러 작은 요인의 합으로 만들어지는 값들이 정규분포에 가까운 경우가 많다.

정규분포의 핵심 특징은 다음과 같다.

| 특징 | 설명 |
|---|---|
| 좌우 대칭 | 평균을 기준으로 왼쪽과 오른쪽 모양이 같다 |
| 평균, 중앙값, 최빈값 동일 | 완전한 정규분포에서는 세 값이 같다 |
| 평균과 표준편차로 결정 | 평균은 중심, 표준편차는 폭을 결정한다 |
| 68-95-99.7 법칙 | 평균 ± 1, 2, 3 표준편차 범위에 약 68%, 95%, 99.7% 포함 |

## 6.5 표준정규분포(Standard Normal Distribution)

표준정규분포(Standard Normal Distribution)는 평균이 0이고 표준편차가 1인 정규분포이다.

정규분포 데이터를 z-score로 변환하면 표준정규분포 기준에서 위치를 해석할 수 있다.

# 7. 정규화와 표준화

## 7.1 표준화(Standardization)

표준화(Standardization)는 데이터를 평균 0, 표준편차 1이 되도록 변환하는 방법이다.

표준화는 서로 다른 단위나 범위를 가진 데이터를 비교 가능하게 만들기 위해 사용된다.

| 장점 | 설명 |
|---|---|
| 변수 단위 차이 제거 | 서로 다른 단위의 변수를 비교 가능하게 만든다 |
| 거리 기반 모델에 유리 | KNN(K-Nearest Neighbors), K-means, SVM(Support Vector Machine)에 중요하다 |
| 규제 모델에 유리 | Ridge, Lasso처럼 계수 크기를 제한하는 모델에서 필요하다 |
| 통계 해석에 유리 | z-score 기반으로 상대적 위치를 볼 수 있다 |

| 단점 | 설명 |
|---|---|
| 이상치 영향 | 평균과 표준편차를 사용하므로 이상치에 민감하다 |
| 원래 단위 해석 어려움 | 변환 후 값은 원래 물리 단위와 다르다 |

## 7.2 정규화(Normalization)

정규화(Normalization)는 데이터를 특정 범위로 변환하는 방법이다. 대표적으로 Min-Max Scaling은 값을 0에서 1 사이로 바꾼다.

| 장점 | 설명 |
|---|---|
| 범위가 명확 | 모든 값이 정해진 구간 안에 들어온다 |
| 거리 기반 알고리즘에 유용 | 변수 범위 차이가 거리 계산을 지배하는 문제를 줄인다 |
| 입력 범위 제한 모델에 유용 | Neural Network 입력 범위 조정 등에 사용할 수 있다 |

| 단점 | 설명 |
|---|---|
| 이상치에 매우 민감 | 최솟값과 최댓값이 이상치이면 대부분 값이 좁은 범위에 몰린다 |
| 새로운 데이터 처리 주의 | 학습 데이터 기준의 최솟값과 최댓값을 저장해서 적용해야 한다 |

## 7.3 정규화와 표준화 비교

| 구분 | 정규화(Normalization) | 표준화(Standardization) |
|---|---|---|
| 목적 | 값의 범위 조정 | 평균과 표준편차 기준 변환 |
| 대표 결과 | 0에서 1 범위 | 평균 0, 표준편차 1 |
| 이상치 영향 | 매우 큼 | 큼 |
| 주요 사용 | 거리 기반 알고리즘, Neural Network | 회귀, SVM, PCA, 통계 분석 |

## 7.4 정규분포화와 정규화의 차이

정규화(Normalization)는 값의 범위를 조정하는 작업이다.

정규분포화는 데이터 분포를 정규분포에 가깝게 만드는 작업이다. 로그 변환, Box-Cox 변환, Yeo-Johnson 변환 등이 사용될 수 있다.

두 용어는 이름이 비슷하지만 목적이 다르다.

## 7.5 중심극한정리(Central Limit Theorem)

중심극한정리(Central Limit Theorem)는 모집단 분포가 정규분포가 아니더라도, 표본 크기가 충분히 크면 표본평균의 분포가 정규분포에 가까워진다는 정리이다.

이 정리는 신뢰구간과 가설검정의 이론적 기반이 된다.

| 장점 | 설명 |
|---|---|
| 통계 추론의 기반 | 신뢰구간과 가설검정이 가능해진다 |
| 비정규 모집단에도 적용 가능 | 표본평균에 대해서는 정규 근사를 사용할 수 있다 |

| 단점 | 설명 |
|---|---|
| 표본 크기 조건 필요 | 표본 수가 작으면 근사가 부정확할 수 있다 |
| 표본 독립성 필요 | 관측치가 강하게 의존하면 적용이 어려울 수 있다 |
| 극단적 분포에서는 더 많은 표본 필요 | 꼬리가 두꺼운 분포에서는 수렴이 느릴 수 있다 |

# 8. 상관, 공분산, 인과

## 8.1 공분산(Covariance)

공분산(Covariance)은 두 변수가 함께 움직이는 방향을 나타내는 값이다.

| 공분산 값 | 해석 |
|---|---|
| 양수 | 두 변수가 같은 방향으로 움직이는 경향 |
| 음수 | 두 변수가 반대 방향으로 움직이는 경향 |
| 0 근처 | 선형 관계가 약하거나 없을 수 있음 |

공분산은 방향성은 보여주지만 크기 해석이 어렵다. 변수 단위에 따라 값의 크기가 달라지기 때문이다.

## 8.2 상관(Correlation)

상관(Correlation)은 두 변수 사이가 함께 변하는 방향과 강도를 나타내는 개념이다.

한 변수가 증가할 때 다른 변수도 증가하면 양의 상관, 한 변수가 증가할 때 다른 변수가 감소하면 음의 상관이라고 한다.

## 8.3 피어슨 상관계수(Pearson Correlation Coefficient)

피어슨 상관계수(Pearson Correlation Coefficient)는 두 연속형 변수 사이의 선형 관계 강도와 방향을 -1에서 1 사이 값으로 표현한다.

| r 값 | 해석 |
|---|---|
| 1 | 완전한 양의 선형 관계 |
| -1 | 완전한 음의 선형 관계 |
| 0 | 선형 관계가 거의 없음 |

피어슨 상관은 선형 관계를 보는 지표이므로, 비선형 관계가 강한 경우에는 상관이 낮게 나올 수 있다.

## 8.4 스피어만 순위상관(Spearman Rank Correlation)

스피어만 순위상관(Spearman Rank Correlation)은 실제 값 대신 순위를 이용해 관계를 측정한다.

| 장점 | 설명 |
|---|---|
| 이상치에 덜 민감 | 값 자체보다 순위를 사용한다 |
| 단조 관계 포착 | 직선이 아니어도 한 방향으로 증가 또는 감소하면 관계를 잡을 수 있다 |
| 순위형 데이터에 적합 | 등수, 만족도 등급 같은 데이터에 사용할 수 있다 |

| 단점 | 설명 |
|---|---|
| 실제 크기 차이를 잃음 | 순위만 사용하므로 값의 간격 정보가 사라진다 |
| 복잡한 비단조 관계에는 부적합 | U자형 관계 같은 패턴은 잘 잡지 못한다 |

## 8.5 켄달 타우(Kendall Tau)

켄달 타우(Kendall Tau)는 두 변수의 순위 쌍이 얼마나 일관된 방향을 가지는지 측정하는 상관계수이다.

작은 표본에서 비교적 안정적이고 순위형 데이터에 적합하다. 다만 모든 쌍 비교가 필요할 수 있어 계산량이 상대적으로 크다.

## 8.6 상관과 인과(Correlation vs Causation)

상관이 높다고 해서 인과관계(Causality)가 있다는 뜻은 아니다.

예를 들어 아이스크림 판매량과 익사 사고가 함께 증가한다고 해서 아이스크림이 익사 사고의 원인이라고 볼 수 없다. 둘 모두 여름이라는 숨은 변수의 영향을 받을 수 있다.

인과를 확인하려면 다음과 같은 접근이 필요하다.

| 방법 | 설명 |
|---|---|
| 무작위 실험 | 처치군과 대조군을 무작위로 나누어 원인 효과를 확인한다 |
| A/B Test | 실제 서비스에서 두 조건을 비교한다 |
| 통제 변수 사용 | 숨은 변수 영향을 줄이기 위해 모델에 포함한다 |
| 도메인 지식 | 통계 결과를 현실적인 원인 구조와 함께 해석한다 |

# 9. 가설검정과 검정 통계량

## 9.1 가설검정(Hypothesis Testing)

가설검정(Hypothesis Testing)은 표본 데이터를 이용해 모집단에 대한 주장이나 가정을 통계적으로 판단하는 과정이다.

기본 흐름은 다음과 같다.

| 단계 | 내용 |
|---|---|
| 1 | 귀무가설과 대립가설을 세운다 |
| 2 | 유의수준을 정한다 |
| 3 | 검정 통계량을 계산한다 |
| 4 | p-value 또는 임계값으로 판단한다 |
| 5 | 귀무가설 기각 여부를 결정한다 |

## 9.2 귀무가설(H0, Null Hypothesis)

귀무가설(Null Hypothesis)은 차이가 없거나 효과가 없다는 기본 가설이다.

| 상황 | 귀무가설 예시 |
|---|---|
| 평균 비교 | 두 집단 평균은 같다 |
| 회귀 분석 | 회귀계수는 0이다 |
| 독립성 검정 | 두 범주형 변수는 독립이다 |

## 9.3 대립가설(H1, Alternative Hypothesis)

대립가설(Alternative Hypothesis)은 차이가 있거나 효과가 있다는 가설이다. 보통 분석자가 확인하고 싶은 주장이다.

예시는 다음과 같다.

| 상황 | 대립가설 예시 |
|---|---|
| 평균 비교 | 두 집단 평균은 다르다 |
| 회귀 분석 | 회귀계수는 0이 아니다 |
| 독립성 검정 | 두 범주형 변수는 독립이 아니다 |

## 9.4 양측 검정(Two-sided Test)과 단측 검정(One-sided Test)

양측 검정(Two-sided Test)은 차이가 있는지만 확인한다.

단측 검정(One-sided Test)은 특정 방향으로 더 크거나 더 작은지를 검정한다.

| 검정 | 질문 예시 |
|---|---|
| 양측 검정 | 평균이 다른가 |
| 우측 단측 검정 | 평균이 더 큰가 |
| 좌측 단측 검정 | 평균이 더 작은가 |

## 9.5 유의수준(Significance Level)

유의수준(Significance Level)은 귀무가설이 참인데도 잘못 기각할 위험을 어디까지 허용할지 정한 기준이다.

보통 0.05를 많이 사용한다.

p-value가 유의수준보다 작으면 통계적으로 유의하다고 표현하는 경우가 많다.

## 9.6 p-value

p-value는 귀무가설이 참이라고 가정했을 때, 현재 관측된 결과만큼 또는 그보다 더 극단적인 결과가 나올 확률이다.

해석 주의점은 다음과 같다.

| 오해 | 올바른 해석 |
|---|---|
| p-value는 귀무가설이 참일 확률이다 | 아니다. 귀무가설이 참이라고 가정했을 때 데이터가 나올 확률이다 |
| p-value가 작으면 효과가 크다 | 반드시 그렇지 않다. 표본 수가 크면 작은 효과도 유의할 수 있다 |
| p-value가 크면 귀무가설이 참이다 | 아니다. 기각할 근거가 부족하다는 뜻이다 |

즉 p-value가 0.03이라고 해서 귀무가설이 3% 확률로 참이라는 뜻은 아니다.

## 9.7 1종 오류(Type I Error)

1종 오류(Type I Error)는 귀무가설이 참인데 기각하는 오류이다.

즉 실제 차이가 없는데 차이가 있다고 판단하는 경우이다.

## 9.8 2종 오류(Type II Error)

2종 오류(Type II Error)는 귀무가설이 거짓인데도 기각하지 못하는 오류이다.

즉 실제 차이가 있는데 차이를 발견하지 못하는 경우이다.

## 9.9 검정력(Power)

검정력(Power)은 실제 효과가 있을 때 귀무가설을 올바르게 기각할 확률이다.

검정력이 높으면 실제 효과를 놓칠 가능성이 낮다.

검정력은 다음 요인의 영향을 받는다.

| 요인 | 영향 |
|---|---|
| 표본 수 | 표본 수가 많을수록 검정력이 증가한다 |
| 효과 크기 | 효과가 클수록 발견하기 쉽다 |
| 데이터 변동성 | 변동성이 작을수록 검정력이 증가한다 |
| 유의수준 | 유의수준을 높이면 검정력이 증가할 수 있다 |

## 9.10 검정 통계량(Test Statistic)

검정 통계량(Test Statistic)은 표본 데이터로부터 계산되는 값으로, 귀무가설과 실제 데이터 간 차이를 수치화한 것이다.

검정 통계량은 보통 다음 구조를 가진다.

검정 통계량 = 관측된 차이 / 표준오차

즉 차이가 클수록, 표준오차가 작을수록 검정 통계량의 절댓값이 커진다.

## 9.11 검정 통계량의 종류

| 검정 통계량 | 주로 사용하는 검정 | 사용 데이터 또는 상황 | 핵심 의미 |
|---|---|---|---|
| Z 통계량 | Z-test | 표본 수가 크거나 모집단 분산을 아는 평균 검정 | 표준정규분포 기준 위치 |
| t 통계량 | T-test | 모집단 분산을 모르고 평균을 비교할 때 | t분포 기준 위치 |
| Chi-square 통계량 | Chi-square Test | 범주형 데이터, 적합도, 독립성 검정 | 관측빈도와 기대빈도 차이 |
| F 통계량 | ANOVA, 회귀모형 비교 | 여러 집단 평균 비교, 분산 비교 | 집단 간 변동과 집단 내 변동의 비율 |

## 9.12 Z 통계량

Z 통계량은 표준정규분포를 기준으로 표본 결과가 귀무가설에서 얼마나 떨어져 있는지 나타낸다.

주로 모집단 분산을 알고 있거나 표본 수가 충분히 큰 경우 사용한다.

## 9.13 t 통계량

t 통계량은 모집단 분산을 모를 때 표본 표준편차를 사용해 평균 차이를 표준화한 값이다.

표본 수가 작을수록 t분포는 정규분포보다 꼬리가 두껍다. 이는 표본 표준편차로 모집단 표준편차를 추정하는 불확실성을 반영하기 때문이다.

## 9.14 Chi-square 통계량

Chi-square 통계량은 관측빈도와 기대빈도의 차이를 측정한다.

범주형 데이터에서 적합도 검정이나 독립성 검정에 사용된다.

예를 들어 성별과 구매 여부가 독립인지 확인할 때 사용할 수 있다.

## 9.15 F 통계량

F 통계량은 두 분산의 비율 또는 집단 간 변동과 집단 내 변동의 비율을 이용한다.

ANOVA(Analysis of Variance)에서는 집단 간 차이가 집단 내 변동에 비해 충분히 큰지 확인한다.

# 10. 대표적인 검정 방법

## 10.1 z-검정(Z-test)

z-검정(Z-test)은 모집단 분산을 알거나 표본 수가 충분히 큰 경우 평균 검정에 사용한다.

| 장점 | 단점 |
|---|---|
| 큰 표본에서 계산이 단순하다 | 모집단 분산을 알아야 하는 경우가 많다 |
| 정규 근사와 연결된다 | 작은 표본에서는 부적절할 수 있다 |

## 10.2 t-검정(T-test)

t-검정(T-test)은 모집단 분산을 모를 때 평균을 비교하는 검정이다.

| 종류 | 사용 상황 |
|---|---|
| 일표본 t-검정(One-sample T-test) | 한 집단 평균이 특정 값과 다른지 확인 |
| 독립표본 t-검정(Independent-samples T-test) | 서로 독립인 두 집단 평균 비교 |
| 대응표본 t-검정(Paired T-test) | 같은 대상의 전후 차이 비교 |

| 장점 | 단점 |
|---|---|
| 작은 표본에서도 사용 가능 | 정규성 가정에 민감할 수 있다 |
| 평균 차이 검정에 직관적 | 세 집단 이상 비교에는 부적절하다 |

## 10.3 카이제곱 검정(Chi-square Test)

카이제곱 검정(Chi-square Test)은 범주형 데이터의 독립성 또는 적합도를 검정할 때 사용한다.

| 장점 | 단점 |
|---|---|
| 범주형 데이터 분석에 적합 | 기대빈도가 너무 작으면 부정확할 수 있다 |
| 독립성 검정에 자주 사용 | 관계의 강도나 방향을 직접 설명하지는 않는다 |

## 10.4 분산분석(ANOVA, Analysis of Variance)

분산분석(ANOVA, Analysis of Variance)은 세 집단 이상 평균 차이를 비교할 때 사용한다.

| 장점 | 단점 |
|---|---|
| 여러 집단 평균을 한 번에 비교 가능 | 어떤 집단끼리 다른지는 사후검정이 필요하다 |
| 1종 오류 증가를 줄임 | 정규성, 등분산성 가정이 필요하다 |

## 10.5 비모수 검정(Non-parametric Test)

비모수 검정(Non-parametric Test)은 정규성 가정이 어렵거나 순위형 데이터일 때 사용하는 검정이다.

| 검정 | 대응되는 상황 |
|---|---|
| Mann-Whitney U Test | 독립된 두 집단 비교 |
| Wilcoxon Signed-rank Test | 대응표본 비교 |
| Kruskal-Wallis Test | 세 집단 이상 비교 |

| 장점 | 단점 |
|---|---|
| 정규성 가정이 약하다 | 평균 차이보다는 순위 차이를 본다 |
| 이상치에 비교적 강하다 | 모수 검정보다 검정력이 낮을 수 있다 |

## 10.6 신뢰구간(Confidence Interval)

신뢰구간(Confidence Interval)은 모집단 모수가 들어 있을 것으로 기대되는 범위를 표본 기반으로 제시하는 방법이다.

95% 신뢰구간은 같은 방식으로 표본 추출과 구간 계산을 반복했을 때, 그 구간들 중 약 95%가 참 모수를 포함한다는 의미이다.

| 장점 | 단점 |
|---|---|
| 효과 크기와 불확실성 확인 가능 | 특정 계산된 구간에 참값이 있을 확률이 95%라는 뜻은 아니다 |
| 실무 해석에 유용 | 표본 독립성, 분포 가정 등에 영향을 받는다 |

# 11. 회귀(Regression)

## 11.1 회귀의 개념

회귀(Regression)는 하나 이상의 독립변수(Independent Variable)를 사용해 종속변수(Dependent Variable)를 설명하거나 예측하는 방법이다.

종속변수가 연속형이면 일반적으로 회귀 문제라고 한다.

회귀의 목적은 다음과 같다.

| 목적 | 설명 |
|---|---|
| 관계 해석 | 독립변수가 종속변수에 어떤 방향으로 관련되는지 본다 |
| 예측 | 새로운 입력에 대한 결과값을 예측한다 |
| 영향력 추정 | 다른 변수를 고정했을 때 특정 변수의 효과를 추정한다 |

## 11.2 독립변수(Independent Variable)

독립변수(Independent Variable)는 결과를 설명하거나 예측하는 데 사용하는 변수이다.

예를 들어 공부 시간으로 시험 점수를 예측한다면 공부 시간이 독립변수이다.

## 11.3 종속변수(Dependent Variable)

종속변수(Dependent Variable)는 예측하거나 설명하려는 결과 변수이다.

예를 들어 공부 시간으로 시험 점수를 예측한다면 시험 점수가 종속변수이다.

## 11.4 단순선형회귀(Simple Linear Regression)

단순선형회귀(Simple Linear Regression)는 독립변수 1개와 연속형 종속변수 1개 사이의 관계를 직선으로 모델링한다.

| 독립변수 | 종속변수 |
|---|---|
| 공부 시간 | 시험 점수 |
| 광고비 | 매출 |
| RSRP(Reference Signal Received Power) | Throughput |

| 장점 | 단점 |
|---|---|
| 해석이 쉽다 | 선형 관계만 표현한다 |
| 계산이 빠르다 | 이상치에 민감하다 |
| 기준 모델로 좋다 | 설명변수 1개만 사용한다 |

## 11.5 다중선형회귀(Multiple Linear Regression)

다중선형회귀(Multiple Linear Regression)는 여러 독립변수를 사용해 하나의 연속형 종속변수를 예측한다.

각 회귀계수는 다른 변수들을 고정했을 때 특정 독립변수가 1단위 증가하면 종속변수가 평균적으로 얼마나 변하는지를 나타낸다.

| 장점 | 단점 |
|---|---|
| 여러 요인 반영 가능 | 다중공선성 문제가 생길 수 있다 |
| 변수별 영향 해석 가능 | 선형성 가정이 필요하다 |
| 통계적 검정 가능 | 이상치와 영향점에 민감하다 |

## 11.6 회귀의 기본 가정

| 가정 | 의미 | 위반 시 문제 |
|---|---|---|
| 선형성(Linearity) | 독립변수와 종속변수 관계가 선형 | 예측 편향 발생 |
| 독립성(Independence) | 관측치 또는 오차가 서로 독립 | 표준오차와 검정 왜곡 |
| 등분산성(Homoscedasticity) | 오차 분산이 일정 | 신뢰구간과 p-value 왜곡 |
| 정규성(Normality) | 오차가 정규분포에 가까움 | 작은 표본에서 검정 부정확 |
| 다중공선성 약함 | 독립변수 간 중복이 작음 | 계수 해석 불안정 |

## 11.7 등분산성(Homoscedasticity)

등분산성(Homoscedasticity)은 독립변수 값이 달라져도 오차의 분산이 일정하다는 가정이다.

예를 들어 예측값이 작을 때는 오차가 작고, 예측값이 클 때는 오차가 커진다면 등분산성이 깨진 것이다.

| 중요한 이유 | 설명 |
|---|---|
| 검정 신뢰성 | 등분산성이 깨지면 회귀계수의 표준오차가 왜곡될 수 있다 |
| 신뢰구간 정확성 | 구간 추정이 지나치게 좁거나 넓어질 수 있다 |
| 모델 진단 | 잔차 패턴을 통해 모델이 놓친 구조를 찾을 수 있다 |

## 11.8 로지스틱 회귀(Logistic Regression)

로지스틱 회귀(Logistic Regression)는 종속변수가 이진 분류(Binary Classification)일 때 사용하는 모델이다.

출력은 확률이며, 보통 0.5 같은 threshold를 기준으로 클래스를 결정한다.

| 문제 | 종속변수 |
|---|---|
| 스팸 분류 | 스팸 또는 정상 |
| 질병 예측 | 질병 있음 또는 없음 |
| 구매 예측 | 구매 또는 비구매 |

| 장점 | 단점 |
|---|---|
| 결과를 0에서 1 사이 확률로 해석할 수 있다 | 복잡한 비선형 분류에는 한계가 있다 |
| Odds Ratio를 통해 변수 영향력을 설명할 수 있다 | 다중공선성이 있으면 계수 해석이 어렵다 |
| 빠르고 안정적이다 | 비선형 관계는 Feature Engineering이 필요할 수 있다 |

## 11.9 Odds와 Logit

Odds는 어떤 사건이 일어날 확률과 일어나지 않을 확률의 비율이다.

Odds = p / (1 - p)

Logit은 Odds에 로그를 취한 값이다.

Logit = log(p / (1 - p))

로지스틱 회귀에서는 이 Logit 값을 독립변수들의 선형 결합으로 모델링한다.

## 11.10 다항 회귀(Polynomial Regression)

다항 회귀(Polynomial Regression)는 입력 변수를 제곱, 세제곱 등으로 확장해 곡선 관계를 모델링한다.

| 장점 | 단점 |
|---|---|
| 비선형 패턴 표현 가능 | 차수를 높이면 과적합 위험이 커진다 |
| 선형회귀 틀 유지 | 관측 범위 밖 예측에 취약하다 |
| 단순 직선으로 어려운 관계 표현 | 고차항이 많아지면 해석이 복잡하다 |

## 11.11 Ridge Regression

Ridge Regression은 L2 Regularization을 사용하는 회귀이다. 계수 크기를 전반적으로 줄여 과적합을 완화한다.

| 장점 | 단점 |
|---|---|
| 다중공선성 완화 | 계수를 0으로 만들지는 않는다 |
| 과적합 감소 | 모든 변수가 남아 해석이 복잡할 수 있다 |
| 모든 변수를 유지 | 스케일링이 필요하다 |

## 11.12 Lasso Regression

Lasso Regression은 L1 Regularization을 사용하는 회귀이다. 중요하지 않은 변수의 계수를 0으로 만들 수 있다.

| 장점 | 단점 |
|---|---|
| 변수 선택 가능 | 상관된 변수 중 하나만 선택할 수 있다 |
| 해석성 향상 | 너무 강한 규제는 중요한 변수까지 제거할 수 있다 |
| 고차원 데이터에 유용 | 스케일링이 필요하다 |

## 11.13 Elastic Net

Elastic Net은 L1과 L2 Regularization을 함께 사용하는 회귀이다.

Lasso와 Ridge의 장점을 절충한 형태로, 변수 수가 많고 서로 상관된 변수가 많은 경우 유용하다.

| 장점 | 단점 |
|---|---|
| 변수 선택과 계수 안정화를 함께 기대 | 하이퍼파라미터가 증가한다 |
| 상관 변수에 Lasso보다 강함 | 단순 Lasso나 Ridge보다 설정이 복잡하다 |
| 고차원 데이터에 적합 | 해석이 더 복잡할 수 있다 |

## 11.14 포아송 회귀(Poisson Regression)

포아송 회귀(Poisson Regression)는 종속변수가 개수 데이터일 때 사용하는 GLM(Generalized Linear Model) 계열 모델이다.

예시는 방문자 수, 결함 개수, 사고 횟수, 특정 이벤트 발생 횟수이다.

| 장점 | 단점 |
|---|---|
| 음수가 될 수 없는 count 값을 모델링한다 | 평균과 분산이 같다는 가정이 필요하다 |
| 발생률 분석 가능 | 0이 많은 데이터에는 약할 수 있다 |
| 변수 변화에 따른 발생률 변화를 볼 수 있다 | 사건 간 의존성이 있으면 모델이 왜곡될 수 있다 |

## 11.15 GLM(Generalized Linear Model, 일반화선형모형)

GLM(Generalized Linear Model)은 선형회귀를 확장한 모델이다. 종속변수가 정규분포가 아니어도 적절한 분포와 링크 함수를 선택해 모델링할 수 있다.

| 구성요소 | 의미 |
|---|---|
| 확률 성분(Random Component) | 종속변수가 따르는 분포 |
| 체계 성분(Systematic Component) | 독립변수들의 선형 결합 |
| 링크 함수(Link Function) | 종속변수 평균과 선형 결합을 연결하는 함수 |

| 모델 | 종속변수 분포 | 링크 함수 |
|---|---|---|
| 선형회귀 | 정규분포 | Identity Link |
| 로지스틱 회귀 | 베르누이 분포 | Logit Link |
| 포아송 회귀 | 포아송분포 | Log Link |

## 11.16 잔차(Residual)

잔차(Residual)는 실제 관측값과 모델 예측값의 차이이다.

잔차가 작을수록 예측이 잘 맞는다. 잔차 패턴을 보면 모델 가정 위반 여부를 점검할 수 있다.

잔차가 예측값에 따라 점점 커지는 패턴을 보이면 등분산성 위반을 의심할 수 있다.

## 11.17 결정계수(R-squared)

결정계수(R-squared)는 종속변수 변동 중 모델이 설명하는 비율을 의미한다.

| 값 | 해석 |
|---|---|
| 1에 가까움 | 모델 설명력이 높다 |
| 0에 가까움 | 모델 설명력이 낮다 |

단, R-squared가 높다고 해서 반드시 좋은 예측 모델이라는 뜻은 아니다. 과적합 모델도 R-squared가 높을 수 있다.

## 11.18 Adjusted R-squared

Adjusted R-squared는 변수 수를 고려해 보정한 결정계수이다.

| R-squared | Adjusted R-squared |
|---|---|
| 변수를 추가하면 보통 증가하거나 유지된다 | 불필요한 변수를 넣으면 감소할 수 있다 |
| 설명변수 수가 다른 모델 비교에 부적절할 수 있다 | 설명변수 수가 다른 회귀 모델 비교에 더 적절하다 |

## 11.19 다중공선성(Multicollinearity)

다중공선성(Multicollinearity)은 독립변수들 사이에 강한 선형 관계가 존재하는 현상이다.

예를 들어 키와 팔 길이를 동시에 넣어 몸무게를 예측하면 두 변수는 서로 강하게 관련될 수 있다.

| 문제 | 설명 |
|---|---|
| 계수 불안정 | 데이터가 조금만 바뀌어도 회귀계수가 크게 변할 수 있다 |
| 부호 왜곡 | 실제 기대와 반대 방향의 계수가 나올 수 있다 |
| 표준오차 증가 | 유의하지 않은 변수처럼 보일 수 있다 |
| 해석 어려움 | 어떤 변수가 실제 영향을 주는지 분리하기 어렵다 |

## 11.20 VIF(Variance Inflation Factor, 분산팽창계수)

VIF(Variance Inflation Factor)는 다중공선성 때문에 회귀계수 분산이 얼마나 커졌는지 보는 지표이다.

| VIF | 일반적 해석 |
|---|---|
| 1 | 공선성 거의 없음 |
| 5 이상 | 공선성 의심 |
| 10 이상 | 강한 공선성 가능성 |

## 11.21 다중공선성 완화 방법

| 방법 | 설명 | 장점 | 단점 |
|---|---|---|---|
| 변수 제거 | 중복 변수를 제거 | 단순하고 해석 쉬움 | 정보 손실 가능 |
| 변수 결합 | 비슷한 변수를 평균이나 합성 지표로 결합 | 의미 있는 지표 생성 가능 | 결합 기준이 필요 |
| PCA 사용 | 상관된 변수를 주성분으로 축소 | 공선성 완화 효과 큼 | 원래 변수 해석 어려움 |
| Ridge Regression 사용 | 계수 크기를 줄여 안정화 | 예측 안정성 향상 | 변수 선택은 하지 않음 |
| Lasso Regression 사용 | 일부 계수를 0으로 만듦 | 변수 선택 가능 | 상관 변수 중 임의 선택 가능 |

# 12. 머신러닝 학습 방식

## 12.1 지도학습(Supervised Learning)

지도학습(Supervised Learning)은 정답 Label이 있는 데이터를 이용해 입력과 출력의 관계를 학습하는 방식이다.

| 대표 문제 | 설명 | 예시 |
|---|---|---|
| 분류(Classification) | 범주를 예측 | 스팸/정상, 양성/음성 |
| 회귀(Regression) | 연속값을 예측 | 집값, 매출, Throughput |

| 장점 | 단점 |
|---|---|
| 성능 평가가 명확하다 | Label을 만드는 비용이 크다 |
| 예측 문제에 적합하다 | Label 품질에 민감하다 |
| 실무 적용 범위가 넓다 | 학습 데이터 범위 밖 패턴에는 약할 수 있다 |

## 12.2 비지도학습(Unsupervised Learning)

비지도학습(Unsupervised Learning)은 정답 Label 없이 데이터 구조나 패턴을 찾는 방식이다.

| 대표 방법 | 설명 | 예시 |
|---|---|---|
| Clustering | 비슷한 데이터끼리 묶음 | 고객 군집, 로그 패턴 군집 |
| Dimensionality Reduction | 차원을 줄임 | PCA, 시각화 |
| Association Rule | 같이 나타나는 패턴 탐색 | 장바구니 분석 |

| 장점 | 단점 |
|---|---|
| Label 없이 사용 가능 | 평가가 어렵다 |
| 숨은 구조 발견 가능 | 발견된 cluster나 pattern에 의미를 부여해야 한다 |
| 탐색 분석에 유용 | 파라미터에 따라 결과가 달라진다 |

## 12.3 준지도학습(Semi-supervised Learning)

준지도학습(Semi-supervised Learning)은 Label이 일부만 있는 데이터와 Label이 없는 데이터를 함께 사용하는 방식이다.

| 장점 | 단점 |
|---|---|
| Label 비용을 줄일 수 있다 | 구현이 복잡하다 |
| 대량의 미라벨 데이터를 활용할 수 있다 | 잘못된 pseudo label이 성능을 악화시킬 수 있다 |

## 12.4 강화학습(Reinforcement Learning)

강화학습(Reinforcement Learning)은 Agent가 환경과 상호작용하면서 보상을 최대화하는 행동을 학습하는 방식이다.

| 장점 | 단점 |
|---|---|
| 순차적 의사결정에 적합하다 | 학습 비용이 크다 |
| 장기 보상 최적화가 가능하다 | 안정성 문제가 생길 수 있다 |
| 제어 문제에 강하다 | 보상 설계가 어렵다 |

# 13. Decision Tree와 불순도

## 13.1 Decision Tree의 개념

Decision Tree는 질문을 순서대로 던지면서 데이터를 분리하는 지도학습 모델이다.

분류(Classification)와 회귀(Regression) 모두에 사용할 수 있다.

예를 들어 날씨, 습도, 바람 정보를 보고 테니스를 칠지 여부를 예측하는 문제에서 Decision Tree는 다음과 같은 질문을 만든다.

| 질문 | 의미 |
|---|---|
| 날씨가 Sunny인가 | 첫 번째 분기 기준 |
| 습도가 High인가 | 다음 분기 기준 |
| 바람이 Strong인가 | 최종 판단 기준 |

## 13.2 Decision Tree는 지도학습인가

Decision Tree는 기본적으로 지도학습에 사용한다.

학습할 때 Feature와 정답 Label이 필요하기 때문이다.

| 구분 | 예시 |
|---|---|
| Feature | 날씨, 습도, 바람 |
| Label | Play 여부 |

## 13.3 불순도(Impurity)

불순도(Impurity)는 한 노드 안에 여러 클래스가 얼마나 섞여 있는지를 나타낸다.

| 상태 | 불순도 |
|---|---|
| 한 클래스만 있음 | 낮음 |
| 여러 클래스가 반반 섞임 | 높음 |

Decision Tree는 데이터를 나눌 때 불순도가 최대한 낮아지는 방향으로 분기한다.

즉 좋은 분기란 부모 노드보다 자식 노드들이 더 순수해지는 분기이다.

## 13.4 Gini Impurity

Gini Impurity는 임의로 선택한 데이터가 잘못 분류될 확률 관점의 불순도이다.

CART(Classification And Regression Tree) 계열에서 자주 사용한다.

이진 분류에서 한 노드에 양성 50%, 음성 50%가 섞여 있으면 Gini Impurity가 높다. 한 클래스가 100%이면 Gini Impurity는 0이다.

특징은 다음과 같다.

| 특징 | 설명 |
|---|---|
| 값 범위 | 0 이상 |
| 순수 노드 | 0 |
| 계산 | Entropy보다 상대적으로 단순 |
| 자주 사용 | CART, Random Forest 등 |

## 13.5 Entropy

Entropy는 데이터가 얼마나 섞여 있는지를 측정하는 불순도 지표이다.

정보 이론에서 온 개념이며, 불확실성이 클수록 Entropy가 커진다.

클래스가 완전히 하나이면 Entropy는 0이고, 클래스가 반반 섞이면 Entropy가 커진다.

## 13.6 Information Gain

Information Gain은 어떤 Feature로 데이터를 나누었을 때 불확실성이 얼마나 줄어드는지를 나타낸다.

Information Gain = 나누기 전 Entropy - 나눈 후 Entropy의 가중 평균

Decision Tree는 보통 Information Gain이 큰 Feature를 먼저 선택한다.

## 13.7 분류오차(Classification Error)

분류오차(Classification Error)는 노드에서 가장 많은 클래스로 모두 예측한다고 했을 때 틀릴 확률이다.

Classification Error = 1 - 가장 큰 클래스 비율

분류오차는 직관적이지만 Gini Impurity나 Entropy보다 분기 선택에 덜 민감할 수 있다.

## 13.8 가중 불순도(Weighted Impurity)

분기 후 자식 노드들의 불순도를 비교할 때는 단순 평균이 아니라 각 자식 노드의 데이터 수를 반영한 가중 평균을 사용한다.

데이터가 많이 들어간 자식 노드의 불순도가 전체 판단에 더 큰 영향을 준다.

## 13.9 Gain Ratio

Gain Ratio는 Information Gain을 Split Information으로 나누어 보정한 지표이다.

Information Gain은 값 종류가 많은 Feature를 선호할 수 있다. 예를 들어 ID처럼 거의 모든 값이 다른 Feature는 데이터를 매우 잘게 나누면서 정보이득을 크게 만들 수 있지만, 실제 일반화에는 도움이 되지 않을 수 있다.

Gain Ratio는 이러한 문제를 완화하기 위해 사용된다.

## 13.10 회귀 트리에서의 불순도

회귀 트리(Regression Tree)는 클래스가 아니라 연속값을 예측한다.

따라서 Gini Impurity나 Entropy 대신 다음과 같은 기준을 사용한다.

| 기준 | 의미 |
|---|---|
| MSE(Mean Squared Error) | 노드 안 예측값과 실제값 차이의 제곱 평균 |
| MAE(Mean Absolute Error) | 노드 안 예측값과 실제값 차이의 절댓값 평균 |
| Variance Reduction | 분기 후 분산이 얼마나 줄었는지 |

회귀 트리에서는 자식 노드 안의 종속변수 값들이 서로 비슷해질수록 좋은 분기이다.

## 13.11 Entropy와 Gini 비교

| 구분 | Entropy | Gini Impurity |
|---|---|---|
| 계산 기준 | 정보 이론 기반 | 오분류 확률 기반 |
| 계산 복잡도 | 로그 계산 필요 | 상대적으로 단순 |
| 사용 알고리즘 | ID3, C4.5 | CART |
| 결과 차이 | 대체로 유사 | 대체로 유사 |
| 경향 | 순수한 분리를 조금 더 강하게 선호 | 계산이 빠르고 실무에서 많이 사용 |

## 13.12 Decision Tree의 장점

| 장점 | 설명 |
|---|---|
| 직관적 | 질문과 분기로 설명할 수 있다 |
| 전처리 부담 적음 | 스케일링이 거의 필요 없다 |
| 비선형 관계 표현 가능 | 여러 조건 분기로 복잡한 경계를 만들 수 있다 |
| Feature 중요도 확인 가능 | 어떤 변수가 분기에 많이 쓰였는지 볼 수 있다 |
| 범주형과 수치형 모두 가능 | 다양한 데이터에 적용할 수 있다 |

## 13.13 Decision Tree의 단점

| 단점 | 설명 |
|---|---|
| 과적합 위험 | 트리가 깊어지면 학습 데이터에 지나치게 맞는다 |
| 불안정성 | 데이터가 조금 바뀌어도 트리 구조가 바뀔 수 있다 |
| 회귀에서 계단형 예측 | 연속적 예측값이 구간별 평균으로 나온다 |
| 편향 가능 | 값 종류가 많은 Feature가 유리하게 선택될 수 있다 |

## 13.14 Pruning

Pruning은 트리를 가지치기해서 과적합을 줄이는 방법이다.

| 방식 | 설명 |
|---|---|
| Pre-pruning | 트리가 너무 깊어지기 전에 성장을 제한 |
| Post-pruning | 먼저 큰 트리를 만든 뒤 불필요한 가지 제거 |

| 장점 | 단점 |
|---|---|
| 과적합을 줄인다 | 너무 많이 자르면 과소적합이 생길 수 있다 |
| 해석성이 좋아진다 | max depth, min samples split 같은 파라미터 선택이 필요하다 |

## 13.15 Random Forest

Random Forest는 여러 Decision Tree를 학습한 뒤 결과를 앙상블하는 모델이다.

| 장점 | 단점 |
|---|---|
| 여러 트리를 평균내어 과적합을 줄인다 | 단일 Tree보다 해석이 어렵다 |
| 일반화 성능이 좋다 | 계산 비용이 증가한다 |
| Feature 중요도를 확인할 수 있다 | 학습 범위 밖 연속값 예측에는 한계가 있다 |

## 13.16 Gradient Boosting Tree

Gradient Boosting Tree는 이전 모델의 오류를 다음 Tree가 보완하는 방식으로 여러 Tree를 순차적으로 학습한다.

대표적으로 XGBoost, LightGBM, CatBoost가 있다.

| 장점 | 단점 |
|---|---|
| 정형 데이터에서 예측 성능이 높다 | 튜닝이 중요하다 |
| 비선형 관계와 변수 상호작용을 잘 잡는다 | 과적합 가능성이 있다 |
| 일부 구현체는 결측치 처리를 지원한다 | 단일 Tree보다 해석이 어렵다 |

# 14. Bayes 정리

## 14.1 Bayes 정리의 개념

Bayes 정리는 어떤 증거가 관측되었을 때 원인의 확률을 갱신하는 방법이다.

즉 기존 믿음에 새로운 정보를 반영해 사후확률을 계산한다.

Bayes 정리의 기본 형태는 다음과 같다.

P(A given B) = P(B given A) × P(A) / P(B)

| 용어 | 의미 |
|---|---|
| 사전확률(Prior Probability) | 증거를 보기 전 확률 |
| 가능도(Likelihood) | 원인이 참일 때 증거가 나올 확률 |
| 증거확률(Evidence) | 증거가 발생할 전체 확률 |
| 사후확률(Posterior Probability) | 증거를 본 뒤 원인이 참일 확률 |

## 14.2 Bayes 정리 예시

질병 유병률이 1%, 질병이 있을 때 양성 확률이 99%, 질병이 없을 때 양성으로 잘못 나올 확률이 5%라고 하자.

검사 결과가 양성일 때 실제 질병이 있을 확률은 단순히 99%가 아니다.

전체 양성 중에는 실제 질병이 있어서 양성인 사람과, 질병은 없지만 위양성인 사람이 함께 포함되기 때문이다.

## 14.3 Bayes 정리의 장점과 단점

| 장점 | 설명 |
|---|---|
| 확률 업데이트 가능 | 새로운 증거를 반영해 판단을 수정할 수 있다 |
| 직관적인 의사결정 | 검사, 스팸 필터, 이상 탐지에 유용하다 |
| 사전정보 활용 | 기존 도메인 지식을 모델에 반영할 수 있다 |

| 단점 | 설명 |
|---|---|
| 사전확률 설정 어려움 | Prior를 어떻게 둘지에 따라 결과가 달라진다 |
| 조건부확률 필요 | P(B given A) 같은 값을 알아야 한다 |
| 계산 복잡성 | 변수가 많아지면 계산이 복잡해진다 |

## 14.4 Naive Bayes

Naive Bayes는 Feature들이 서로 조건부 독립이라고 가정하는 분류 모델이다.

텍스트 분류, 스팸 필터, 문서 분류에 자주 사용된다.

| 장점 | 단점 |
|---|---|
| 학습과 예측 속도가 빠르다 | 독립 가정이 강하다 |
| 적은 데이터에도 동작한다 | 예측 확률 자체는 과신될 수 있다 |
| 텍스트 분류에 강하다 | Feature 간 상호작용 표현이 약하다 |

# 15. Clustering

## 15.1 Clustering의 개념

Clustering은 Label 없이 비슷한 데이터끼리 묶는 비지도학습 방법이다.

고객 세분화, 로그 패턴 분석, 이미지 그룹화, 이상 탐지 등에 사용된다.

## 15.2 K-means Clustering

K-means Clustering은 데이터를 K개의 cluster로 나누는 대표적인 알고리즘이다.

동작 순서는 다음과 같다.

| 단계 | 내용 |
|---|---|
| 1 | K개의 centroid를 초기화한다 |
| 2 | 각 데이터를 가장 가까운 centroid에 할당한다 |
| 3 | 각 cluster의 평균으로 centroid를 갱신한다 |
| 4 | 할당과 갱신을 반복한다 |
| 5 | centroid 변화가 작아지면 종료한다 |

| 장점 | 단점 |
|---|---|
| 간단하고 빠르다 | K를 미리 정해야 한다 |
| 중심점 기반으로 해석이 쉽다 | 초기값에 민감하다 |
| 대용량 데이터에도 비교적 잘 동작한다 | 구형 cluster에 적합하다 |
| 대부분 라이브러리에서 지원한다 | 이상치와 스케일 차이에 민감하다 |

## 15.3 K-means 초기화 방식

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| Random Initialization | 데이터 중 K개를 무작위로 선택 | 구현이 쉽다 | 실행할 때마다 결과가 달라질 수 있다 |
| Forgy Method | 전체 데이터에서 K개의 실제 sample을 랜덤 선택 | 단순하고 빠르다 | outlier가 선택될 수 있다 |
| Random Partition Method | 데이터를 먼저 무작위로 K개 cluster에 배정한 뒤 평균 사용 | 빈 cluster 가능성을 줄일 수 있다 | 실제 cluster 구조를 반영하지 못할 수 있다 |
| K-means++ | 기존 centroid와 멀리 떨어진 점이 선택될 확률을 높임 | 결과 안정성과 수렴 속도 향상 | 초기화 계산 비용 증가 |
| Maximin Initialization | 기존 centroid와 가장 멀리 떨어진 점을 다음 centroid로 선택 | centroid가 넓게 퍼진다 | outlier에 매우 취약하다 |
| Multiple Random Starts | 여러 초기값으로 반복 실행 후 가장 좋은 결과 선택 | 나쁜 초기값 위험 감소 | 계산 시간이 증가한다 |

## 15.4 Hierarchical Clustering

Hierarchical Clustering은 데이터 간 거리 기반으로 계층적인 cluster 구조를 만드는 방법이다.

| 방식 | 설명 |
|---|---|
| Agglomerative | 각 데이터를 하나의 cluster로 시작해 점점 합친다 |
| Divisive | 전체 데이터를 하나의 cluster로 시작해 점점 나눈다 |

| 장점 | 단점 |
|---|---|
| dendrogram을 보고 cluster 수를 선택할 수 있다 | 대용량 데이터에 느리다 |
| 계층 구조를 확인할 수 있다 | 한 번 합치면 되돌리기 어렵다 |
| 작은 데이터에 해석력이 좋다 | 거리 기준과 linkage 방식에 민감하다 |

## 15.5 DBSCAN

DBSCAN(Density-Based Spatial Clustering of Applications with Noise)은 밀도 기반 clustering 알고리즘이다.

밀도가 높은 영역을 cluster로 보고, 밀도가 낮은 점은 noise로 처리한다.

| 장점 | 단점 |
|---|---|
| K를 미리 정하지 않는다 | eps와 min samples 설정이 어렵다 |
| 이상치 탐지가 가능하다 | 밀도 차이가 큰 데이터에 약하다 |
| 복잡한 모양의 cluster도 찾을 수 있다 | 고차원 데이터에서 거리 기반 한계가 있다 |

# 16. 차원축소와 Feature Selection

## 16.1 차원축소(Dimensionality Reduction)

차원축소(Dimensionality Reduction)는 많은 변수를 더 적은 수의 변수 또는 축으로 줄이는 방법이다.

목적은 시각화, 노이즈 제거, 계산량 감소, 다중공선성 완화이다.

## 16.2 PCA(Principal Component Analysis, 주성분분석)

PCA(Principal Component Analysis)는 변수들의 분산을 최대한 보존하는 새로운 축을 찾아 데이터를 저차원으로 변환하는 방법이다.

| 장점 | 단점 |
|---|---|
| 변수 수를 줄여 계산량을 낮춘다 | 주성분은 원래 변수들의 조합이라 해석이 어렵다 |
| 다중공선성을 완화한다 | 비선형 구조에는 한계가 있다 |
| 고차원 데이터를 2D 또는 3D로 시각화할 수 있다 | 스케일링이 필요하다 |
| 작은 분산 성분을 제거해 노이즈를 줄일 수 있다 | Target과의 관련성이 아닌 분산 기준으로 축을 선택한다 |

## 16.3 t-SNE

t-SNE(t-distributed Stochastic Neighbor Embedding)는 고차원 데이터의 국소적 이웃 구조를 저차원에 시각화하는 방법이다.

| 장점 | 단점 |
|---|---|
| 복잡한 고차원 구조를 2D로 표현하기 좋다 | cluster 간 거리나 크기를 그대로 해석하면 안 된다 |
| 가까운 데이터끼리 가까이 배치하려 한다 | 계산 비용이 크다 |
| 시각적 탐색에 유용하다 | 초기값과 파라미터에 따라 결과가 달라질 수 있다 |

## 16.4 UMAP

UMAP(Uniform Manifold Approximation and Projection)은 고차원 데이터를 저차원으로 시각화하거나 임베딩하는 방법이다.

| 장점 | 단점 |
|---|---|
| t-SNE보다 대용량 데이터에 유리한 경우가 많다 | n_neighbors, min_dist에 따라 결과가 달라진다 |
| 국소 및 전역 구조를 함께 보존하려 한다 | 시각화 결과를 통계적 증거처럼 해석하면 안 된다 |
| cluster 구조를 보기 좋게 표현한다 | 재현성과 해석에 주의가 필요하다 |

## 16.5 Feature Selection

Feature Selection은 모델에 사용할 중요한 변수를 선택하는 과정이다.

Feature Selection이 중요한 이유는 다음과 같다.

| 이유 | 설명 |
|---|---|
| 과적합 감소 | 불필요한 변수를 줄이면 일반화가 좋아질 수 있다 |
| 해석성 향상 | 중요한 변수 중심으로 모델을 설명할 수 있다 |
| 계산량 감소 | 학습 속도와 예측 속도가 개선될 수 있다 |
| 데이터 품질 개선 | 노이즈성 변수를 줄일 수 있다 |

대표 방식은 다음과 같다.

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| Filter Method | 상관, 카이제곱, mutual information 등으로 사전 선택 | 빠르고 모델 독립적 | 변수 간 상호작용 반영 약함 |
| Wrapper Method | 모델 성능을 기준으로 변수 조합 선택 | 성능 중심 선택 가능 | 계산 비용 큼 |
| Embedded Method | 모델 학습 과정에서 변수 선택 | 효율적이고 성능 좋음 | 특정 모델에 종속 |

# 17. Association Rule

## 17.1 연관규칙(Association Rule)의 개념

연관규칙(Association Rule)은 데이터에서 함께 자주 등장하는 item 조합을 찾는 비지도학습 방법이다.

대표적으로 장바구니 분석에 사용된다.

규칙 형태는 다음과 같다.

A -> B

이 의미는 A가 등장했을 때 B도 함께 등장하는 경향이 있다는 뜻이다.

## 17.2 지지도(Support)

지지도(Support)는 특정 itemset이 전체 transaction 중 얼마나 자주 등장하는지 나타낸다.

Support(A -> B) = A와 B가 모두 포함된 transaction 수 / 전체 transaction 수

| 핵심 | 설명 |
|---|---|
| 방향성 | Support(A -> B)와 Support(B -> A)는 같다 |
| 기준 | 전체 transaction 수로 나눈다 |
| 의미 | 규칙이 데이터 전체에서 얼마나 흔한지 나타낸다 |

## 17.3 신뢰도(Confidence)

신뢰도(Confidence)는 A가 등장한 transaction 중 B도 등장한 비율이다.

Confidence(A -> B) = A와 B가 모두 포함된 transaction 수 / A가 포함된 transaction 수

## 17.4 향상도(Lift)

향상도(Lift)는 A와 B가 독립적으로 등장하는 경우보다 얼마나 더 강하게 함께 나타나는지 나타낸다.

Lift(A -> B) = Confidence(A -> B) / Support(B)

| Lift 값 | 해석 |
|---|---|
| 1보다 큼 | A와 B가 함께 나타나는 경향이 강함 |
| 1 | 독립에 가까움 |
| 1보다 작음 | A가 있을 때 B가 오히려 덜 나타남 |

## 17.5 Apriori Algorithm

Apriori Algorithm은 빈번한 itemset을 찾는 대표 알고리즘이다.

핵심 원리는 어떤 itemset이 빈번하려면 그 부분집합도 모두 빈번해야 한다는 것이다.

| 장점 | 단점 |
|---|---|
| 규칙 형태로 결과를 설명하기 쉽다 | item 수가 많으면 후보 itemset이 폭증한다 |
| Apriori property로 탐색 공간을 줄인다 | 희소 데이터에서는 의미 있는 규칙이 적을 수 있다 |
| 장바구니 분석에 적합하다 | 최소 지지도 기준에 따라 결과가 크게 달라진다 |

## 17.6 FP-Growth

FP-Growth(Frequent Pattern Growth)는 후보 itemset을 직접 많이 생성하지 않고 FP-Tree를 사용해 빈번 패턴을 찾는 방법이다.

| 장점 | 단점 |
|---|---|
| Apriori보다 빠른 경우가 많다 | 구현이 복잡하다 |
| 반복적인 database scan을 줄일 수 있다 | FP-Tree 구조가 커질 수 있다 |
| 대규모 transaction에 유리하다 | 너무 많은 규칙이 나올 수 있어 필터링이 필요하다 |

# 18. 모델 평가 지표

## 18.1 혼동행렬(Confusion Matrix)

혼동행렬(Confusion Matrix)은 분류 모델의 예측 결과를 실제 값과 비교해 정리한 표이다.

| 구분 | 의미 |
|---|---|
| TP(True Positive, 진양성) | 실제 양성을 양성으로 맞춘 경우 |
| TN(True Negative, 진음성) | 실제 음성을 음성으로 맞춘 경우 |
| FP(False Positive, 위양성) | 실제 음성을 양성으로 잘못 예측한 경우 |
| FN(False Negative, 위음성) | 실제 양성을 음성으로 잘못 예측한 경우 |

## 18.2 정확도(Accuracy)

정확도(Accuracy)는 전체 데이터 중 맞게 예측한 비율이다.

Accuracy = (TP + TN) / (TP + TN + FP + FN)

| 장점 | 단점 |
|---|---|
| 전체 중 얼마나 맞췄는지 직관적이다 | 불균형 데이터에 취약하다 |
| 클래스 비율이 비슷하면 해석이 쉽다 | FP와 FN의 비용 차이를 반영하지 못한다 |

## 18.3 정밀도(Precision)

정밀도(Precision)는 모델이 양성이라고 예측한 것 중 실제 양성의 비율이다.

Precision = TP / (TP + FP)

| 장점 | 단점 |
|---|---|
| 위양성 관리를 보는 데 유용하다 | 실제 양성을 얼마나 놓쳤는지는 알기 어렵다 |
| 추천, 스팸 필터에 적합하다 | 정밀도만 높이고 많은 양성을 놓칠 수 있다 |

## 18.4 재현율(Recall) 또는 민감도(Sensitivity)

재현율(Recall)은 실제 양성 중 모델이 양성으로 맞춘 비율이다.

Recall = TP / (TP + FN)

민감도(Sensitivity)도 같은 의미로 사용된다.

| 장점 | 단점 |
|---|---|
| 위음성 관리에 유용하다 | 위양성이 증가할 수 있다 |
| 의료, 불량 탐지에 적합하다 | 모든 데이터를 양성으로 예측하면 높아질 수 있다 |

## 18.5 특이도(Specificity)

특이도(Specificity)는 실제 음성 중 모델이 음성으로 맞춘 비율이다.

Specificity = TN / (TN + FP)

| 장점 | 단점 |
|---|---|
| 실제 음성을 잘 보호하는지 확인할 수 있다 | 양성 탐지 능력은 별도로 확인해야 한다 |
| 민감도와 함께 진단 성능을 균형 있게 본다 | 음성이 매우 많으면 높게 보일 수 있다 |

## 18.6 F1-score

F1-score는 정밀도와 재현율의 조화평균이다.

F1-score = 2 × Precision × Recall / (Precision + Recall)

| 장점 | 단점 |
|---|---|
| 정밀도와 재현율 균형을 본다 | TN을 직접 반영하지 않는다 |
| 불균형 데이터에 Accuracy보다 유용할 수 있다 | FP와 FN 중 어떤 오류가 더 중요한지는 별도 고려해야 한다 |

## 18.7 ROC Curve와 AUC

ROC(Receiver Operating Characteristic) Curve는 threshold 변화에 따른 TPR(True Positive Rate)과 FPR(False Positive Rate)의 관계를 나타낸다.

TPR(True Positive Rate)은 Recall 또는 Sensitivity와 같다.

FPR(False Positive Rate)은 실제 음성 중 양성으로 잘못 예측한 비율이다.

FPR = FP / (FP + TN)

ROC Curve는 threshold를 낮추거나 높일 때 모델이 양성과 음성을 얼마나 잘 구분하는지 보여준다.

AUC(Area Under the Curve)는 ROC Curve 아래 면적이다.

| AUC 값 | 해석 |
|---|---|
| 0.5 | 무작위 추측 수준 |
| 0.7 전후 | 어느 정도 구분 능력 있음 |
| 0.8 이상 | 좋은 구분 능력 |
| 1.0 | 완벽한 구분 |

| 장점 | 단점 |
|---|---|
| 특정 threshold 하나에 의존하지 않는다 | 불균형 데이터에서 과대평가될 수 있다 |
| 양성과 음성을 구분하는 능력을 본다 | 실제 운영 threshold 선택은 별도로 필요하다 |
| 여러 모델 비교에 유용하다 | 양성 예측의 정밀도는 직접 보여주지 않는다 |

## 18.8 ROC Curve와 Precision-Recall Curve의 차이

| 구분 | ROC Curve | PR Curve |
|---|---|---|
| 축 | TPR과 FPR | Precision과 Recall |
| 관심 | 양성과 음성 구분 능력 | 양성 예측 품질 |
| 불균형 데이터 | 음성이 많으면 좋아 보일 수 있음 | 희귀 양성 문제에 더 민감 |
| 사용 예 | 일반 분류 모델 비교 | 질병, fraud, 장애 탐지 |

PR Curve(Precision-Recall Curve)는 threshold 변화에 따른 Precision과 Recall의 관계를 나타낸다.

데이터 불균형이 심한 양성 탐지 문제에서는 ROC보다 PR Curve가 더 유용한 경우가 많다.

## 18.9 회귀 평가 지표

### 18.9.1 MAE(Mean Absolute Error)

MAE(Mean Absolute Error)는 실제값과 예측값 차이의 절댓값 평균이다.

| 장점 | 단점 |
|---|---|
| 원래 단위로 해석이 쉽다 | 큰 오차에 대한 패널티가 상대적으로 작다 |
| RMSE보다 이상치에 덜 민감하다 | 미분이 매끄럽지 않은 지점이 있다 |

### 18.9.2 MSE(Mean Squared Error)

MSE(Mean Squared Error)는 오차 제곱의 평균이다.

| 장점 | 단점 |
|---|---|
| 큰 오차를 강하게 벌점 준다 | 단위가 제곱이라 해석이 어렵다 |
| 최적화에 편리하다 | 이상치에 민감하다 |

### 18.9.3 RMSE(Root Mean Squared Error)

RMSE(Root Mean Squared Error)는 MSE에 제곱근을 취한 값이다.

| 장점 | 단점 |
|---|---|
| 원래 단위로 해석 가능하다 | 큰 오차에 민감하다 |
| 큰 예측 실패를 중요하게 반영한다 | 이상치가 많으면 모델 비교가 왜곡될 수 있다 |

### 18.9.4 R-squared

R-squared는 종속변수 변동 중 모델이 설명하는 비율이다.

| 장점 | 단점 |
|---|---|
| 설명력을 해석할 수 있다 | 변수를 추가하면 보통 증가한다 |
| 회귀 모델 비교에 자주 사용된다 | 예측 성능을 보장하지 않는다 |

### 18.9.5 Adjusted R-squared

Adjusted R-squared는 변수 수를 고려해 보정한 결정계수이다.

| 장점 | 단점 |
|---|---|
| 불필요한 변수 추가를 벌점 준다 | 모든 예측 문제에 적합한 지표는 아니다 |
| 변수 수가 다른 회귀 모델 비교에 유용하다 | 비선형 모델 평가에는 제한적이다 |

# 19. 데이터 전처리

## 19.1 결측치(Missing Value)

결측치(Missing Value)는 값이 비어 있는 데이터이다.

결측치 처리는 데이터 분석에서 매우 중요하다. 결측이 단순히 누락된 것인지, 특정 의미를 가지는지 먼저 확인해야 한다.

| 처리 방법 | 장점 | 단점 |
|---|---|---|
| 행 삭제 | 간단함 | 데이터 손실 큼 |
| 평균 대체 | 구현 쉬움 | 분산 감소, 이상치 영향 |
| 중앙값 대체 | 이상치에 강함 | 변수 간 관계 반영 약함 |
| 최빈값 대체 | 범주형에 사용 가능 | 데이터 다양성 감소 |
| 모델 기반 대체 | 다른 변수 정보 활용 | 구현 복잡, 누수 위험 |
| 결측 여부 Feature 추가 | 결측 자체의 의미 반영 | Feature 증가 |

## 19.2 이상치(Outlier)

이상치(Outlier)는 대부분 데이터와 크게 다른 관측값이다.

이상치는 오류일 수도 있고, 실제 중요한 희귀 현상일 수도 있다. 따라서 무조건 제거하지 말고 도메인 의미를 먼저 확인해야 한다.

| 처리 방법 | 장점 | 단점 |
|---|---|---|
| 제거 | 오류 데이터 제거 가능 | 중요한 희귀 현상 손실 가능 |
| Winsorization | 극단값 영향을 줄임 | 원본 데이터 왜곡 |
| Robust Scaling | 중앙값과 IQR 사용 | 모든 모델 문제를 해결하지는 않음 |
| 별도 분석 | 이상 탐지에 유용 | 분석 복잡도 증가 |

## 19.3 Encoding

Encoding은 범주형 변수를 숫자로 변환하는 과정이다.

| 방식 | 설명 | 장점 | 단점 |
|---|---|---|---|
| Label Encoding | 범주를 정수로 변환 | 간단함 | 순서가 없는 범주에 가짜 순서 부여 |
| One-hot Encoding | 범주마다 0 또는 1 변수 생성 | 순서 왜곡 없음 | 범주 수 많으면 차원 증가 |
| Target Encoding | 범주별 target 평균 사용 | 고카디널리티에 유용 | 데이터 누수 위험 |
| Frequency Encoding | 범주 빈도로 변환 | 간단하고 차원 증가 없음 | target과 직접 관계 반영 약함 |

## 19.4 데이터 누수(Data Leakage)

데이터 누수(Data Leakage)는 학습 시점에 알 수 없어야 하는 정보가 모델 학습에 들어가는 문제이다.

예를 들어 테스트 데이터 전체를 기준으로 스케일링한 뒤 train/test를 나누면 테스트 정보가 학습 과정에 들어간다.

| 방지 방법 | 설명 |
|---|---|
| train/test 먼저 분리 | 전처리 기준은 train에서만 학습한다 |
| Cross Validation 내부에서 전처리 | fold마다 전처리를 따로 fit한다 |
| 미래 정보 제거 | 예측 시점 이후 정보를 feature에 넣지 않는다 |
| Target Encoding 주의 | 검증 fold의 target 정보를 쓰지 않는다 |

# 20. 모델 일반화와 검증

## 20.1 과적합(Overfitting)

과적합(Overfitting)은 모델이 학습 데이터에 지나치게 맞춰져 새로운 데이터 성능이 떨어지는 상태이다.

| 원인 | 설명 |
|---|---|
| 모델이 너무 복잡 | 파라미터가 많거나 트리가 너무 깊다 |
| 데이터가 적음 | 우연한 패턴까지 학습한다 |
| 노이즈가 많음 | 잡음을 실제 패턴으로 착각한다 |

완화 방법은 다음과 같다.

| 방법 | 설명 |
|---|---|
| Regularization | 계수나 모델 복잡도 제한 |
| Cross Validation | 여러 검증 분할로 성능 확인 |
| Pruning | Tree의 불필요한 가지 제거 |
| Early Stopping | 검증 성능이 나빠지기 전에 학습 중단 |
| 데이터 증가 | 더 다양한 학습 데이터를 확보 |

## 20.2 과소적합(Underfitting)

과소적합(Underfitting)은 모델이 너무 단순해서 학습 데이터의 패턴도 충분히 설명하지 못하는 상태이다.

완화 방법은 다음과 같다.

| 방법 | 설명 |
|---|---|
| 더 복잡한 모델 사용 | 선형모델에서 Tree, Boosting 등으로 변경 |
| Feature 추가 | 중요한 설명변수를 추가 |
| 비선형 변환 | 다항항, 로그 변환, interaction 추가 |
| 규제 완화 | 너무 강한 regularization을 줄임 |

## 20.3 편향-분산 트레이드오프(Bias-Variance Tradeoff)

편향(Bias)은 모델이 실제 패턴을 단순화해서 생기는 오차이다.

분산(Variance)은 학습 데이터 변화에 모델이 민감하게 흔들리는 정도이다.

| 상태 | 특징 |
|---|---|
| 높은 Bias | 과소적합 가능성 |
| 높은 Variance | 과적합 가능성 |
| 적절한 균형 | 일반화 성능 우수 |

## 20.4 Train, Validation, Test Split

| 데이터 | 용도 |
|---|---|
| Training Data | 모델 학습 |
| Validation Data | 모델 선택, hyperparameter 조정 |
| Test Data | 최종 성능 평가 |

## 20.5 Cross Validation

Cross Validation은 데이터를 여러 fold로 나누어 학습과 검증을 반복하는 방법이다.

| 방식 | 설명 |
|---|---|
| K-fold Cross Validation | 데이터를 K개 fold로 나누어 반복 평가 |
| Stratified K-fold | 클래스 비율을 유지하며 fold 분할 |
| Time Series Split | 시간 순서를 지키며 검증 |
| Leave-One-Out | 하나만 검증 데이터로 두고 반복 |

| 장점 | 단점 |
|---|---|
| 성능 평가가 안정적이다 | 계산 비용이 증가한다 |
| 데이터를 효율적으로 사용한다 | 시간 데이터에는 랜덤 분할을 주의해야 한다 |

# 21. Q-Q Plot

## 21.1 Q-Q Plot의 개념

Q-Q Plot(Quantile-Quantile Plot)은 데이터의 분위수와 이론 분포의 분위수를 비교하는 그래프이다.

보통 데이터가 정규분포를 따르는지 확인할 때 많이 사용한다.

## 21.2 Q-Q Plot 해석

| 모양 | 해석 |
|---|---|
| 점들이 직선에 가까움 | 데이터가 비교 대상 분포에 가까움 |
| 양쪽 끝이 크게 벗어남 | 꼬리가 두껍거나 이상치 가능성 |
| S자 형태 | 분포의 왜도 또는 꼬리 차이 가능성 |
| 위아래로 휘어짐 | 비교 분포와 데이터 분포가 다름 |

Q-Q Plot은 정규성 검정을 보완하는 시각적 도구이다. 표본 수가 매우 크면 작은 차이도 정규성 검정에서 유의하게 나올 수 있으므로 그래프 해석을 함께 보는 것이 좋다.

|---|---|
| 클래스 균형 분류 | Accuracy |

| 양성을 놓치면 위험 | Recall, Sensitivity |
| 음성을 잘 보호해야 함 | Specificity |
| Precision과 Recall 균형 | F1-score |
| threshold와 무관한 구분 능력 | ROC Curve, AUC |
| 불균형 양성 탐지 | PR Curve, Average Precision |
| 회귀에서 평균 오차 직관성 | MAE |
| 큰 오차를 강하게 벌점 | RMSE |
| 회귀 설명력 | R-squared, Adjusted R-squared |

## 22.3 전처리 선택

| 문제 | 추천 처리 |
|---|---|
| 변수 단위 차이 큼 | Standardization 또는 Normalization |
| 이상치 많음 | Robust Scaling, 중앙값 대체, 이상치 분석 |
| 결측치 있음 | 결측 패턴 확인 후 대체 또는 제거 |
| 범주형 변수 있음 | One-hot Encoding, Target Encoding |
| 변수 너무 많음 | Feature Selection, PCA |
| 클래스 불균형 | class weight, resampling, threshold 조정 |

| 구분 | 의미 |
|---|---|
| P(A and B) | A와 B가 동시에 일어날 확률 |
| P(A given B) | B가 일어났다는 조건에서 A가 일어날 확률 |

조건부확률은 기준 집단이 전체에서 B가 일어난 집단으로 바뀌는 개념이다.

## 24.3 독립과 상호배반

| 구분 | 독립 | 상호배반 |
|---|---|---|
| 의미 | 서로 확률에 영향을 주지 않음 | 동시에 발생할 수 없음 |
| 핵심 관계 | P(A and B) = P(A) × P(B) | P(A and B) = 0 |
| 주의점 | 동시에 발생 가능할 수 있음 | 확률이 0이 아닌 두 사건이면 일반적으로 독립이 아님 |

## 24.4 정규화와 표준화

| 구분 | 정규화 | 표준화 |
|---|---|---|
| 목적 | 값의 범위 조정 | 평균과 표준편차 기준 변환 |
| 대표 결과 | 0에서 1 범위 | 평균 0, 표준편차 1 |
| 사용 상황 | 거리 기반 알고리즘 | 회귀, 통계 분석, 분포 비교 |

## 24.5 상관과 회귀

| 구분 | 상관 | 회귀 |

| 방향성 | 대칭적 | 독립변수와 종속변수 구분 |
| 결과 | 상관계수 | 회귀식, 회귀계수 |
| 인과 의미 | 직접 의미하지 않음 | 인과를 증명하지는 않음 |

# 25. 개념 연결 흐름

데이터 사이언스에서는 먼저 모집단과 표본을 구분하고, 평균, 분산, 표준편차로 데이터의 중심과 퍼짐을 본다.

데이터 분포가 정규분포에 가까운지 확인하면 z-score, 신뢰구간, 가설검정 같은 통계 추론을 이해하기 쉬워진다.

확률 개념에서는 사건, 조건부확률, 독립, 상호배반을 구분해야 한다. 확률변수가 이산형이면 PMF를 사용하고, 연속형이면 PDF를 사용하며, 누적 확률이 필요하면 CDF를 사용한다.

변수 사이 관계를 볼 때는 공분산과 상관계수를 사용하지만, 상관이 인과를 의미하지 않는다는 점을 주의해야 한다.

예측이 목적이면 회귀, 분류, Decision Tree 같은 지도학습 모델을 사용한다. 정답 Label이 없고 데이터 구조를 찾는 것이 목적이면 K-means, DBSCAN, PCA, Association Rule 같은 비지도학습 방법을 사용할 수 있다.

Decision Tree는 불순도를 줄이는 방향으로 데이터를 분기한다. 분류 Tree에서는 Gini Impurity, Entropy, Information Gain이 중요하고, 회귀 Tree에서는 MSE, MAE, Variance Reduction이 중요하다.

모델링 후에는 반드시 평가 지표를 문제 목적에 맞게 선택해야 한다. 양성을 놓치면 위험한 문제에서는 Recall 또는 Sensitivity가 중요하고, 잘못된 양성 경고를 줄이는 것이 중요하면 Precision 또는 Specificity가 중요하다.

회귀 문제에서는 MAE, RMSE, R-squared를 함께 보고, 과적합과 데이터 누수 여부를 항상 점검해야 한다.

# 26. 최종 정리

통계와 데이터 사이언스 개념은 따로 떨어져 있는 것이 아니라 하나의 흐름으로 연결된다.

데이터를 요약하기 위해 평균, 중앙값, 분산, 표준편차를 사용한다.

불확실성을 표현하기 위해 확률과 확률분포를 사용한다.

분포를 이해하기 위해 PMF, PDF, CDF를 구분한다.

표본으로 모집단을 판단하기 위해 신뢰구간과 가설검정을 사용한다.

변수 간 관계를 보기 위해 공분산, 상관, 회귀분석을 사용한다.

예측 모델의 성능을 보기 위해 Accuracy, Precision, Recall, Specificity, F1-score, ROC Curve, AUC 등을 사용한다.

Decision Tree 같은 머신러닝 모델도 결국 데이터의 불확실성, 분포, 변수 관계를 바탕으로 동작한다.

특히 Decision Tree에서는 Gini Impurity, Entropy, Information Gain 같은 불순도 기준을 이용해 데이터를 더 순수한 그룹으로 나눈다.

통계량은 데이터를 요약하고, 검정 통계량은 표본 결과가 귀무가설 기준에서 얼마나 극단적인지 판단하게 해준다.

따라서 통계는 데이터 분석과 머신러닝을 이해하기 위한 기본 언어이다.

# 27. 가설 검정의 종류와 자세한 설명

가설 검정(Hypothesis Testing)은 표본 데이터만 보고 모집단에 대한 주장이 통계적으로 타당한지 판단하는 절차이다. 핵심은 표본에서 관측된 차이나 관계가 우연한 표본 변동으로도 충분히 나타날 수 있는 수준인지, 아니면 우연이라고 보기 어려운 수준인지를 판단하는 것이다.

가설 검정은 보통 다음 순서로 진행한다.

| 단계 | 내용 |
|---|---|
| 1 | 귀무가설(H0, Null Hypothesis)을 세운다. |
| 2 | 대립가설(H1, Alternative Hypothesis)을 세운다. |
| 3 | 유의수준(Significance Level)을 정한다. 보통 0.05를 많이 사용한다. |
| 4 | 데이터 특성과 목적에 맞는 검정 방법을 선택한다. |
| 5 | 검정 통계량(Test Statistic)을 계산한다. |
| 6 | p-value를 계산하거나 임계값(Critical Value)과 비교한다. |
| 7 | 귀무가설을 기각할지 판단한다. |

## 27.1 z-검정(Z-test)

z-검정(Z-test)은 표본 평균이 특정 기준값과 다른지 확인할 때 사용하는 검정이다. 모집단 분산을 알고 있거나, 표본 크기가 충분히 커서 표본분산으로 모집단 분산을 근사할 수 있을 때 사용한다.

대표적으로 다음 상황에서 사용한다.

| 사용 상황 | 설명 |
|---|---|
| 단일 표본 평균 검정 | 표본 평균이 기준 평균과 다른지 확인한다. |
| 두 집단 평균 검정 | 두 집단의 평균 차이가 통계적으로 유의한지 확인한다. |
| 비율 검정 | 표본 비율이 기준 비율과 다른지 확인한다. |

단일 표본 평균에 대한 z 통계량은 다음과 같다.

$$Z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$$

여기서 $\bar{x}$는 표본평균, $\mu_0$는 귀무가설에서 가정한 모집단 평균, $\sigma$는 모집단 표준편차, $n$은 표본 크기이다.

z-검정은 정규분포를 기준으로 판단한다. 표본 평균이 귀무가설의 기준 평균에서 멀어질수록 z 통계량의 절댓값이 커지고, p-value는 작아진다.

## 27.2 t-검정(T-test)

t-검정(T-test)은 평균 차이를 검정할 때 가장 자주 쓰이는 방법이다. 모집단 분산을 모르는 경우에 사용하며, 표본 표준편차를 이용한다. 표본 크기가 작을 때도 사용할 수 있지만, 데이터가 정규성 가정을 크게 벗어나지 않는 것이 중요하다.

t-검정의 핵심은 표본 평균 차이가 표본의 변동성에 비해 충분히 큰지를 확인하는 것이다.

### 27.2.1 단일 표본 t-검정(One-sample t-test)

단일 표본 t-검정은 하나의 표본 평균이 특정 기준값과 다른지 확인할 때 사용한다.

예를 들어 어떤 시험의 기준 평균이 70점이라고 할 때, 실제로 수집한 학생들의 평균 점수가 70점과 유의하게 다른지 확인할 수 있다.

$$t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$$

여기서 $s$는 표본 표준편차이다.

### 27.2.2 독립표본 t-검정(Independent two-sample t-test)

독립표본 t-검정은 서로 다른 두 집단의 평균을 비교할 때 사용한다. 두 집단은 서로 독립이어야 한다.

예를 들어 A 교육법을 받은 학생 집단과 B 교육법을 받은 학생 집단의 평균 점수를 비교하는 경우가 해당된다.

| 조건 | 설명 |
|---|---|
| 집단 관계 | 서로 다른 두 집단이다. |
| 목적 | 두 집단 평균 차이를 검정한다. |
| 예시 | 남성 집단과 여성 집단의 평균 키 비교, A/B 테스트 평균 비교 |

등분산을 가정할 수 있으면 일반 독립표본 t-검정을 사용하고, 등분산을 가정하기 어렵다면 Welch t-검정을 사용한다.

### 27.2.3 대응표본 t-검정(Paired t-test)

대응표본 t-검정은 같은 대상에서 두 번 측정한 값의 평균 차이를 검정할 때 사용한다.

예를 들어 같은 사람들의 운동 전 체중과 운동 후 체중을 비교하는 경우가 해당된다.

| 조건 | 설명 |
|---|---|
| 집단 관계 | 같은 대상에서 반복 측정한 데이터이다. |
| 목적 | 전후 차이의 평균이 0인지 검정한다. |
| 예시 | 약 복용 전후 혈압 비교, 교육 전후 시험 점수 비교 |

대응표본 t-검정은 두 값 자체를 비교하는 것이 아니라 각 대상의 차이값을 만든 뒤, 그 차이값의 평균이 0인지 검정한다.

## 27.3 카이제곱 검정(Chi-square Test)

카이제곱 검정(Chi-square Test)은 범주형 데이터의 빈도 차이를 검정할 때 사용한다. 평균이 아니라 개수 또는 비율의 차이를 다룬다.

카이제곱 통계량은 관측빈도(Observed Frequency)와 기대빈도(Expected Frequency)의 차이를 이용한다.

$$\chi^2 = \sum \frac{(O - E)^2}{E}$$

여기서 $O$는 관측빈도, $E$는 기대빈도이다.

### 27.3.1 적합도 검정(Goodness-of-fit Test)

적합도 검정은 관측된 범주별 빈도가 기대한 분포와 일치하는지 확인한다.

예를 들어 주사위를 600번 던졌을 때 1부터 6까지의 눈이 각각 100번씩 나오는 것이 기대된다. 실제 결과가 이 기대와 유의하게 다른지 확인할 때 적합도 검정을 사용한다.

### 27.3.2 독립성 검정(Test of Independence)

독립성 검정은 두 범주형 변수가 서로 독립인지 확인한다.

예를 들어 성별과 제품 선호도가 서로 관련이 있는지 확인할 수 있다. 귀무가설은 성별과 제품 선호도가 독립이라는 것이다. p-value가 작으면 두 변수 사이에 통계적으로 유의한 관계가 있다고 판단한다.

### 27.3.3 동질성 검정(Test of Homogeneity)

동질성 검정은 여러 집단에서 범주형 변수의 분포가 같은지 확인한다.

예를 들어 세 지역에서 선호하는 통신사 비율이 같은지 비교할 수 있다. 독립성 검정과 계산 방식은 비슷하지만, 문제 설정이 다르다.

## 27.4 ANOVA(Analysis of Variance, 분산분석)

ANOVA(Analysis of Variance, 분산분석)는 세 개 이상 집단의 평균 차이를 검정할 때 사용한다. 이름은 분산분석이지만, 실제 관심사는 평균 차이이다.

예를 들어 A, B, C 세 가지 학습법의 평균 점수가 모두 같은지 검정할 때 사용한다.

귀무가설은 모든 집단의 평균이 같다는 것이다.

$$H_0: \mu_1 = \mu_2 = \mu_3 = \cdots = \mu_k$$

대립가설은 적어도 하나의 집단 평균이 다르다는 것이다.

ANOVA는 집단 간 변동(Between-group Variation)이 집단 내 변동(Within-group Variation)에 비해 충분히 큰지를 확인한다.

$$F = \frac{\text{집단 간 분산}}{\text{집단 내 분산}}$$

F 값이 크다는 것은 집단 간 평균 차이가 집단 내부의 자연스러운 변동보다 크다는 의미이다.

### 27.4.1 일원분산분석(One-way ANOVA)

일원분산분석은 하나의 요인(Factor)에 따라 세 개 이상 집단의 평균을 비교한다.

예를 들어 학습법이라는 하나의 요인이 있고, 학습법 A, B, C의 평균 점수를 비교하는 경우이다.

### 27.4.2 이원분산분석(Two-way ANOVA)

이원분산분석은 두 개의 요인이 평균에 영향을 주는지 확인한다.

예를 들어 학습법과 성별이 시험 점수에 영향을 주는지 분석할 수 있다. 이때 각 요인의 개별 효과뿐 아니라 두 요인이 함께 작용하는 상호작용 효과(Interaction Effect)도 확인할 수 있다.

## 27.5 F-검정(F-test)

F-검정(F-test)은 두 분산의 차이를 검정하거나, 회귀모형 전체가 유의한지 판단할 때 사용한다.

대표적으로 다음 상황에서 사용한다.

| 사용 상황 | 설명 |
|---|---|
| 두 집단 분산 비교 | 두 모집단 분산이 같은지 검정한다. |
| ANOVA | 세 개 이상 집단 평균 차이를 검정한다. |
| 회귀모형 전체 유의성 검정 | 독립변수들이 종속변수를 설명하는 데 유의한지 확인한다. |

회귀분석에서 F-검정의 귀무가설은 모든 회귀계수가 0이라는 것이다. 즉, 독립변수들이 종속변수 설명에 도움이 되지 않는다는 주장이다.

## 27.6 비율 검정(Proportion Test)

비율 검정은 성공과 실패처럼 결과가 두 범주로 나뉘는 데이터에서 비율이 특정 값과 다른지, 또는 두 집단의 비율이 다른지 확인한다.

예를 들어 어떤 제품의 불량률이 5퍼센트보다 높은지, A 광고와 B 광고의 클릭률이 다른지 검정할 수 있다.

| 검정 종류 | 사용 상황 |
|---|---|
| 단일 비율 검정 | 표본 비율이 기준 비율과 다른지 확인한다. |
| 두 비율 검정 | 두 집단의 비율 차이를 확인한다. |

표본 크기가 충분히 크면 정규근사를 이용한 z-검정을 사용할 수 있다.

## 27.7 정규성 검정(Normality Test)

정규성 검정은 데이터가 정규분포를 따른다고 볼 수 있는지 확인한다. t-검정, ANOVA, 선형회귀의 잔차 분석 등에서 정규성은 중요한 가정이 될 수 있다.

대표적인 정규성 검정은 다음과 같다.

| 검정 | 설명 |
|---|---|
| Shapiro-Wilk Test | 표본이 작거나 중간 크기일 때 많이 사용한다. |
| Kolmogorov-Smirnov Test | 표본분포와 기준분포의 차이를 비교한다. |
| Anderson-Darling Test | 분포의 꼬리 부분 차이에 비교적 민감하다. |
| Q-Q Plot | 검정이라기보다 시각적으로 정규성을 확인하는 방법이다. |

정규성 검정의 p-value가 작으면 정규분포를 따른다는 가정을 의심한다. 다만 표본이 매우 크면 작은 차이도 유의하게 나올 수 있으므로, 히스토그램과 Q-Q Plot을 함께 보는 것이 좋다.

## 27.8 비모수 검정(Non-parametric Test)

비모수 검정(Non-parametric Test)은 데이터가 특정 분포를 따른다는 강한 가정을 두기 어려울 때 사용하는 검정이다. 평균보다는 순위(Rank)나 중앙값 차이를 기반으로 판단하는 경우가 많다.

대표적인 비모수 검정은 다음과 같다.

| 검정 | 대응되는 모수 검정 | 사용 상황 |
|---|---|---|
| Mann-Whitney U Test | 독립표본 t-검정 | 독립된 두 집단의 분포 또는 중앙 경향 비교 |
| Wilcoxon Signed-rank Test | 대응표본 t-검정 | 같은 대상의 전후 차이 비교 |
| Kruskal-Wallis Test | 일원분산분석 | 세 개 이상 독립 집단 비교 |
| Friedman Test | 반복측정 ANOVA | 같은 대상에서 세 조건 이상 반복 측정 비교 |
| Spearman Correlation Test | Pearson Correlation Test | 순위 기반 상관 검정 |

비모수 검정은 이상치에 상대적으로 강하고, 순서형 데이터에도 사용할 수 있다는 장점이 있다. 하지만 데이터가 실제로 정규성 가정을 만족한다면 모수 검정보다 검정력이 낮을 수 있다.

## 27.9 상관 검정(Correlation Test)

상관 검정은 두 변수 사이의 상관계수가 0과 유의하게 다른지 확인한다.

대표적으로 Pearson 상관 검정은 두 연속형 변수의 선형 관계가 유의한지 판단한다. Spearman 상관 검정은 순위 기반으로 단조 관계를 검정한다.

귀무가설은 보통 두 변수의 상관계수가 0이라는 것이다.

$$H_0: \rho = 0$$

p-value가 작으면 두 변수 사이에 유의한 상관 관계가 있다고 판단한다. 단, 상관이 유의하다고 해서 인과관계가 증명되는 것은 아니다.

## 27.10 회귀계수 검정(Regression Coefficient Test)

회귀분석에서는 각 독립변수의 회귀계수가 0인지 검정한다. 회귀계수가 0이라는 것은 해당 독립변수가 다른 변수들을 통제한 상태에서 종속변수 설명에 유의한 기여를 하지 않는다는 뜻이다.

단일 회귀계수 검정에는 보통 t-통계량을 사용한다.

$$t = \frac{\hat{\beta}_j - 0}{SE(\hat{\beta}_j)}$$

여기서 $\hat{\beta}_j$는 추정된 회귀계수, $SE(\hat{\beta}_j)$는 회귀계수의 표준오차이다.

p-value가 작으면 해당 변수의 회귀계수가 0이 아니라고 판단한다. 즉, 해당 변수가 종속변수와 통계적으로 유의한 관계가 있다고 해석한다.

## 27.11 검정 방법 선택 요약

| 데이터 상황 | 비교 대상 | 추천 검정 |
|---|---|---|
| 평균과 기준값 비교 | 한 집단 평균 vs 기준 평균 | 단일 표본 t-검정 또는 z-검정 |
| 두 독립 집단 평균 비교 | A 집단 평균 vs B 집단 평균 | 독립표본 t-검정 |
| 같은 대상의 전후 평균 비교 | 전 측정값 vs 후 측정값 | 대응표본 t-검정 |
| 세 집단 이상 평균 비교 | A, B, C 집단 평균 | ANOVA |
| 범주형 빈도 비교 | 관측빈도 vs 기대빈도 | 카이제곱 적합도 검정 |
| 두 범주형 변수 관계 | 성별과 선호도 등 | 카이제곱 독립성 검정 |
| 비율 비교 | 클릭률, 불량률 등 | 비율 검정 |
| 정규성 만족 어려움 | 순위 기반 비교 | 비모수 검정 |
| 두 연속형 변수 관계 | 키와 몸무게 등 | 상관 검정 |
| 회귀모형 전체 유의성 | 여러 독립변수 전체 | F-검정 |

# 28. 상관의 종류와 자세한 설명

상관(Correlation)은 두 변수 사이의 관계 방향과 강도를 수치로 표현한 것이다. 상관계수는 보통 -1에서 1 사이의 값을 가진다.

| 상관계수 값 | 해석 |
|---|---|
| 1에 가까움 | 강한 양의 상관이다. 한 변수가 증가할 때 다른 변수도 증가하는 경향이 있다. |
| 0에 가까움 | 선형 또는 단조 관계가 약하다. |
| -1에 가까움 | 강한 음의 상관이다. 한 변수가 증가할 때 다른 변수는 감소하는 경향이 있다. |

상관은 변수 간 동시 변동을 보는 도구이다. 그러나 상관이 높다고 해서 한 변수가 다른 변수를 원인으로 변화시킨다는 뜻은 아니다.

## 28.1 Pearson Correlation Coefficient(피어슨 상관계수)

Pearson Correlation Coefficient(피어슨 상관계수)는 두 연속형 변수 사이의 선형 관계를 측정한다.

$$r = \frac{\text{Cov}(X,Y)}{\sigma_X \sigma_Y}$$

여기서 $\text{Cov}(X,Y)$는 공분산, $\sigma_X$와 $\sigma_Y$는 각 변수의 표준편차이다.

피어슨 상관계수는 다음 상황에 적합하다.

| 조건 | 설명 |
|---|---|
| 변수 형태 | 연속형 변수에 적합하다. |
| 관계 형태 | 직선 형태의 선형 관계를 잘 측정한다. |
| 이상치 영향 | 이상치에 민감하다. |
| 예시 | 공부 시간과 시험 점수의 선형 관계 |

피어슨 상관계수가 0에 가깝더라도 두 변수 사이에 관계가 전혀 없다는 뜻은 아닐 수 있다. 비선형 관계가 있으면 피어슨 상관계수는 낮게 나올 수 있다.

## 28.2 Spearman Rank Correlation(스피어만 순위상관)

Spearman Rank Correlation(스피어만 순위상관)은 실제 값이 아니라 순위를 이용해 상관을 계산한다. 두 변수 사이의 단조 관계(Monotonic Relationship)를 측정한다.

단조 관계란 한 변수가 증가할 때 다른 변수가 대체로 증가하거나, 대체로 감소하는 관계이다. 반드시 직선일 필요는 없다.

스피어만 상관은 다음 상황에 적합하다.

| 조건 | 설명 |
|---|---|
| 변수 형태 | 순서형 변수 또는 연속형 변수에 사용할 수 있다. |
| 관계 형태 | 단조 관계에 적합하다. |
| 이상치 영향 | 피어슨 상관보다 이상치에 덜 민감하다. |
| 예시 | 고객 만족도 순위와 재구매 의향 순위의 관계 |

## 28.3 Kendall Tau(켄달 타우)

Kendall Tau(켄달 타우)는 두 변수의 순위 쌍이 얼마나 일관되게 정렬되는지를 측정한다. 표본 수가 작거나 순위 데이터가 많을 때 유용하다.

켄달 타우는 두 관측치 쌍을 비교해서 같은 방향으로 정렬되면 concordant pair, 반대 방향이면 discordant pair로 본다.

| 특징 | 설명 |
|---|---|
| 장점 | 순위 일치 정도를 직관적으로 해석할 수 있다. |
| 단점 | 계산량이 많을 수 있다. |
| 적합 상황 | 순위 데이터, 표본 수가 작은 데이터 |

## 28.4 Point-biserial Correlation(점이연 상관)

Point-biserial Correlation(점이연 상관)은 하나의 변수가 연속형이고 다른 변수가 이진형일 때 사용하는 상관계수이다.

예를 들어 성별처럼 0과 1로 표현되는 변수와 시험 점수 같은 연속형 변수 사이의 관계를 볼 수 있다. 단, 이진형 변수가 임의로 코딩된 범주라면 해석에 주의해야 한다.

## 28.5 Phi Coefficient(파이 계수)

Phi Coefficient(파이 계수)는 두 변수가 모두 이진형일 때 사용하는 상관계수이다.

예를 들어 가입 여부와 구매 여부처럼 두 변수가 모두 0 또는 1로 표현되는 경우 사용할 수 있다. 2 x 2 분할표에서 두 이진 변수의 관련성을 나타낸다.

## 28.6 Partial Correlation(편상관)

Partial Correlation(편상관)은 제3의 변수 영향을 통제한 상태에서 두 변수 사이의 관계를 측정한다.

예를 들어 아이스크림 판매량과 익사 사고 수는 양의 상관을 보일 수 있다. 하지만 기온이라는 변수를 통제하면 두 변수 사이의 직접적인 관계는 약해질 수 있다. 이때 편상관을 사용하면 기온의 영향을 제거한 뒤 두 변수 관계를 확인할 수 있다.

## 28.7 Autocorrelation(자기상관)

Autocorrelation(자기상관)은 시계열 데이터에서 현재 값과 과거 값 사이의 상관을 의미한다.

예를 들어 오늘의 기온은 어제의 기온과 관련이 있을 수 있다. 주가, 트래픽, 센서 데이터, RF 로그 시간축 데이터처럼 시간 순서가 있는 데이터에서 중요하다.

자기상관이 강하면 일반적인 독립성 가정이 깨질 수 있다. 회귀분석에서는 잔차의 자기상관을 확인해야 하며, 자기상관이 강하면 시계열 모델을 고려해야 한다.

## 28.8 상관계수 선택 요약

| 데이터 형태 | 관계 형태 | 추천 상관계수 |
|---|---|---|
| 연속형 + 연속형 | 선형 관계 | Pearson Correlation |
| 순서형 + 순서형 | 단조 관계 | Spearman Correlation 또는 Kendall Tau |
| 연속형 + 이진형 | 평균 차이 기반 관계 | Point-biserial Correlation |
| 이진형 + 이진형 | 2 x 2 관계 | Phi Coefficient |
| 제3 변수 통제 필요 | 통제 후 관계 | Partial Correlation |
| 시계열 데이터 | 현재와 과거 관계 | Autocorrelation |

# 29. 회귀의 종류와 자세한 설명

회귀(Regression)는 독립변수(Independent Variable)를 이용해 종속변수(Dependent Variable)를 설명하거나 예측하는 방법이다. 회귀는 단순히 예측만 하는 도구가 아니라, 어떤 변수가 결과에 얼마나 영향을 주는지 해석하는 도구로도 사용된다.

회귀분석에서 가장 중요한 개념은 다음과 같다.

| 개념 | 설명 |
|---|---|
| 독립변수 | 원인 또는 설명 변수로 사용하는 변수이다. |
| 종속변수 | 예측하거나 설명하려는 결과 변수이다. |
| 회귀계수 | 독립변수가 1 증가할 때 종속변수가 얼마나 변하는지 나타낸다. |
| 절편 | 모든 독립변수가 0일 때의 예측값이다. |
| 잔차 | 실제값과 예측값의 차이이다. |

## 29.1 단순선형회귀(Simple Linear Regression)

단순선형회귀는 하나의 독립변수로 하나의 연속형 종속변수를 설명하는 회귀이다.

$$Y = \beta_0 + \beta_1 X + \epsilon$$

예를 들어 공부 시간으로 시험 점수를 예측하는 경우이다.

| 항목 | 의미 |
|---|---|
| $Y$ | 종속변수이다. 예를 들어 시험 점수이다. |
| $X$ | 독립변수이다. 예를 들어 공부 시간이다. |
| $\beta_0$ | 절편이다. |
| $\beta_1$ | 기울기 또는 회귀계수이다. |
| $\epsilon$ | 오차항이다. |

$\beta_1$이 3이라면 공부 시간이 1시간 증가할 때 시험 점수가 평균적으로 3점 증가한다고 해석한다.

## 29.2 다중선형회귀(Multiple Linear Regression)

다중선형회귀는 여러 개의 독립변수를 이용해 하나의 연속형 종속변수를 설명한다.

$$Y = \beta_0 + \beta_1 X_1 + \beta_2 X_2 + \cdots + \beta_p X_p + \epsilon$$

예를 들어 공부 시간, 수면 시간, 출석률을 이용해 시험 점수를 예측하는 경우이다.

다중회귀에서 회귀계수는 다른 변수들을 고정했을 때 해당 변수만 1 증가하면 종속변수가 얼마나 변하는지를 의미한다. 이 부분이 단순회귀와 가장 큰 해석 차이이다.

## 29.3 다항 회귀(Polynomial Regression)

다항 회귀는 독립변수의 제곱항, 세제곱항 등을 추가해서 곡선 관계를 표현하는 방법이다.

$$Y = \beta_0 + \beta_1 X + \beta_2 X^2 + \epsilon$$

예를 들어 광고비가 증가할수록 매출이 증가하지만, 어느 순간 증가폭이 줄어드는 관계를 표현할 수 있다.

다항 회귀는 비선형 관계를 표현할 수 있지만, 차수를 너무 높이면 과적합이 발생하기 쉽다.

## 29.4 로지스틱 회귀(Logistic Regression)

로지스틱 회귀(Logistic Regression)는 이름은 회귀이지만 주로 분류 문제에 사용한다. 종속변수가 0 또는 1처럼 이진형일 때 사용한다.

예를 들어 고객이 이탈할지 여부, 환자가 질병을 가졌는지 여부, 이메일이 스팸인지 여부를 예측할 수 있다.

로지스틱 회귀는 확률을 예측한다.

$$P(Y=1) = \frac{1}{1 + e^{-z}}$$

여기서 $z$는 독립변수들의 선형 결합이다.

$$z = \beta_0 + \beta_1 X_1 + \cdots + \beta_p X_p$$

로지스틱 회귀의 계수는 확률 자체의 변화량으로 바로 해석하지 않고, Odds 또는 Logit 관점에서 해석한다.

## 29.5 다항 로지스틱 회귀(Multinomial Logistic Regression)

다항 로지스틱 회귀는 종속변수가 세 개 이상 범주를 가질 때 사용한다. 예를 들어 고객 등급이 Bronze, Silver, Gold 중 하나로 분류되는 경우이다.

범주 사이에 순서가 없다면 다항 로지스틱 회귀를 사용할 수 있다. 범주 사이에 순서가 있다면 순서형 로지스틱 회귀를 고려한다.

## 29.6 순서형 로지스틱 회귀(Ordinal Logistic Regression)

순서형 로지스틱 회귀는 종속변수가 순서가 있는 범주형일 때 사용한다.

예를 들어 만족도가 낮음, 보통, 높음으로 나뉘는 경우이다. 이 경우 범주 사이에 순서가 있기 때문에 단순한 다항 로지스틱 회귀보다 순서형 로지스틱 회귀가 더 적합할 수 있다.

## 29.7 포아송 회귀(Poisson Regression)

포아송 회귀(Poisson Regression)는 종속변수가 사건 발생 횟수처럼 0 이상의 정수일 때 사용한다.

예를 들어 하루 고객 문의 수, 한 시간 동안 발생한 네트워크 에러 수, 특정 구간에서 발생한 이벤트 횟수를 예측할 수 있다.

포아송 회귀는 평균과 분산이 같다는 가정을 가진다. 실제 데이터에서 분산이 평균보다 훨씬 크면 과산포(Overdispersion)가 발생하므로 음이항 회귀를 고려할 수 있다.

## 29.8 음이항 회귀(Negative Binomial Regression)

음이항 회귀는 count 데이터에서 과산포가 있을 때 사용한다. 포아송 회귀보다 분산을 더 유연하게 모델링할 수 있다.

예를 들어 고객별 문의 횟수에서 일부 고객이 매우 많은 문의를 보내는 경우 포아송 회귀보다 음이항 회귀가 더 적합할 수 있다.

## 29.9 Ridge Regression

Ridge Regression은 선형회귀에 L2 규제를 추가한 방법이다. 회귀계수가 너무 커지는 것을 막아서 과적합을 줄인다.

Ridge는 다중공선성이 있을 때 유용하다. 서로 강하게 상관된 독립변수들이 있을 때 회귀계수가 불안정해질 수 있는데, Ridge는 계수를 작게 눌러 안정성을 높인다.

단, Ridge는 계수를 정확히 0으로 만들지는 않는다. 따라서 변수 선택보다는 계수 안정화에 가깝다.

## 29.10 Lasso Regression

Lasso Regression은 선형회귀에 L1 규제를 추가한 방법이다. 일부 회귀계수를 정확히 0으로 만들 수 있기 때문에 변수 선택 효과가 있다.

변수가 매우 많고 그중 일부만 중요할 것으로 예상될 때 유용하다. 하지만 서로 강하게 상관된 변수들이 많으면 그중 하나만 선택하고 나머지를 제거하는 식으로 불안정한 선택이 발생할 수 있다.

## 29.11 Elastic Net

Elastic Net은 Ridge의 L2 규제와 Lasso의 L1 규제를 함께 사용하는 방법이다. 변수 선택 효과와 계수 안정화 효과를 동시에 얻고자 할 때 사용한다.

상관된 독립변수가 많고 변수 수도 많은 데이터에서 유용하다.

## 29.12 Quantile Regression(분위수 회귀)

Quantile Regression(분위수 회귀)은 평균이 아니라 특정 분위수를 예측한다. 일반 선형회귀는 조건부 평균을 예측하지만, 분위수 회귀는 중앙값 또는 상위 90퍼센트 지점 같은 분위수를 예측할 수 있다.

예를 들어 통신 지연시간(Latency)의 평균뿐 아니라 상위 95퍼센트 지연시간을 분석해야 할 때 분위수 회귀가 유용할 수 있다.

## 29.13 Robust Regression(강건 회귀)

Robust Regression(강건 회귀)은 이상치의 영향을 줄이기 위한 회귀 방법이다. 일반적인 최소제곱법은 큰 잔차에 매우 민감하기 때문에 이상치가 있으면 회귀선이 크게 흔들릴 수 있다.

강건 회귀는 이상치가 많은 데이터에서 더 안정적인 관계를 추정하는 데 사용한다.

## 29.14 회귀 가정 정리

선형회귀를 해석 목적으로 사용할 때는 다음 가정이 중요하다.

| 가정 | 설명 | 깨졌을 때 문제 |
|---|---|---|
| 선형성 | 독립변수와 종속변수 관계가 선형이다. | 모델이 관계를 제대로 설명하지 못한다. |
| 독립성 | 관측치 또는 잔차가 서로 독립이다. | 표준오차와 p-value가 왜곡될 수 있다. |
| 등분산성 | 잔차의 분산이 일정하다. | 회귀계수 검정이 부정확해질 수 있다. |
| 정규성 | 잔차가 정규분포를 따른다. | 소표본에서 신뢰구간과 검정이 불안정해질 수 있다. |
| 다중공선성 없음 | 독립변수끼리 과도하게 상관되지 않는다. | 회귀계수가 불안정해지고 해석이 어려워진다. |

예측 목적이라면 가정 위반보다 예측 성능이 더 중요할 수 있다. 하지만 회귀계수의 의미를 해석하고 p-value를 판단하려면 가정을 반드시 점검해야 한다.

## 29.15 회귀 종류 선택 요약

| 종속변수 형태 | 목적 | 추천 회귀 |
|---|---|---|
| 연속형 | 평균 예측 | 단순선형회귀, 다중선형회귀 |
| 연속형 비선형 관계 | 곡선 관계 표현 | 다항 회귀, 비선형 회귀 |
| 이진형 | 0 또는 1 분류 확률 예측 | 로지스틱 회귀 |
| 세 개 이상 범주형 | 범주 분류 | 다항 로지스틱 회귀 |
| 순서 있는 범주형 | 등급, 만족도 예측 | 순서형 로지스틱 회귀 |
| Count 데이터 | 사건 발생 횟수 예측 | 포아송 회귀 |
| 과산포 Count 데이터 | 분산이 평균보다 큼 | 음이항 회귀 |
| 변수 많음, 과적합 우려 | 계수 축소 | Ridge Regression |
| 변수 선택 필요 | 일부 계수 0 처리 | Lasso Regression |
| 상관된 변수 많음 | 변수 선택과 안정화 | Elastic Net |
| 이상치 많음 | 이상치 영향 완화 | Robust Regression |
| 특정 분위수 예측 | 중앙값, 상위 분위수 | Quantile Regression |

# 30. 확률분포의 종류와 자세한 설명

확률분포(Probability Distribution)는 확률변수가 어떤 값을 가질 가능성이 얼마나 되는지를 나타낸 것이다. 확률분포는 크게 이산확률분포와 연속확률분포로 나뉜다.

| 구분 | 설명 | 사용하는 함수 |
|---|---|---|
| 이산확률분포 | 확률변수가 셀 수 있는 값을 가진다. | PMF(Probability Mass Function, 확률질량함수) |
| 연속확률분포 | 확률변수가 연속적인 값을 가진다. | PDF(Probability Density Function, 확률밀도함수) |

## 30.1 베르누이 분포(Bernoulli Distribution)

베르누이 분포는 결과가 성공 또는 실패처럼 두 가지뿐인 시행을 나타낸다.

예를 들어 동전 던지기에서 앞면이 나오면 성공, 뒷면이 나오면 실패로 볼 수 있다.

| 항목 | 내용 |
|---|---|
| 확률변수 | 0 또는 1 |
| 모수 | 성공확률 $p$ |
| 평균 | $p$ |
| 분산 | $p(1-p)$ |
| 예시 | 클릭 여부, 구매 여부, 불량 여부 |

## 30.2 이항분포(Binomial Distribution)

이항분포는 베르누이 시행을 독립적으로 여러 번 반복했을 때 성공 횟수의 분포이다.

$$P(X=k) = {n \choose k}p^k(1-p)^{n-k}$$

| 항목 | 내용 |
|---|---|
| 확률변수 | n번 시행 중 성공 횟수 |
| 모수 | 시행 횟수 $n$, 성공확률 $p$ |
| 평균 | $np$ |
| 분산 | $np(1-p)$ |
| 예시 | 10명 중 구매한 사람 수, 100개 중 불량품 수 |

이항분포는 각 시행이 독립이고 성공확률이 일정해야 한다.

## 30.3 기하분포(Geometric Distribution)

기하분포는 첫 번째 성공이 나올 때까지 필요한 시행 횟수의 분포이다.

예를 들어 불량품을 찾을 때 첫 번째 불량품이 몇 번째 검사에서 나오는지 나타낼 수 있다.

| 항목 | 내용 |
|---|---|
| 확률변수 | 첫 성공까지의 시행 횟수 |
| 모수 | 성공확률 $p$ |
| 평균 | $1/p$ |
| 예시 | 첫 구매 고객이 나올 때까지 필요한 방문자 수 |

## 30.4 음이항분포(Negative Binomial Distribution)

음이항분포는 정해진 성공 횟수에 도달할 때까지 필요한 시행 횟수의 분포이다.

기하분포가 첫 번째 성공까지를 다룬다면, 음이항분포는 r번째 성공까지를 다룬다.

예를 들어 5번째 불량품이 나올 때까지 검사해야 하는 제품 수를 모델링할 수 있다.

## 30.5 초기하분포(Hypergeometric Distribution)

초기하분포는 비복원 추출에서 성공 개수를 나타내는 분포이다.

이항분포는 매 시행의 성공확률이 일정한 복원 또는 독립 시행에 적합하다. 반면 초기하분포는 한 번 뽑은 대상을 다시 넣지 않기 때문에 시행마다 성공확률이 변한다.

예를 들어 100개 제품 중 불량품이 10개 있을 때, 20개를 비복원으로 뽑아 그중 불량품 개수를 구하는 문제에 사용할 수 있다.

## 30.6 포아송분포(Poisson Distribution)

포아송분포는 일정 시간 또는 공간에서 사건이 발생하는 횟수를 나타낸다.

$$P(X=k) = \frac{e^{-\lambda}\lambda^k}{k!}$$

| 항목 | 내용 |
|---|---|
| 확률변수 | 일정 구간 내 사건 발생 횟수 |
| 모수 | 평균 발생률 $\lambda$ |
| 평균 | $\lambda$ |
| 분산 | $\lambda$ |
| 예시 | 1시간 동안 콜센터 문의 수, 1초 동안 패킷 에러 수, 하루 교통사고 수 |

포아송분포는 사건이 독립적으로 발생하고, 평균 발생률이 일정하다는 가정을 가진다.

## 30.7 균등분포(Uniform Distribution)

균등분포는 가능한 값들이 동일한 가능성을 갖는 분포이다.

이산 균등분포는 주사위처럼 각 값이 같은 확률을 가진다. 연속 균등분포는 특정 구간 안의 모든 값이 같은 밀도를 가진다.

예를 들어 0과 1 사이에서 무작위 숫자를 하나 뽑는 상황은 연속 균등분포로 볼 수 있다.

## 30.8 정규분포(Normal Distribution)

정규분포는 평균을 중심으로 좌우 대칭인 종 모양 분포이다. 자연 현상, 측정 오차, 표본 평균의 분포 등에서 자주 나타난다.

$$X \sim N(\mu, \sigma^2)$$

| 항목 | 내용 |
|---|---|
| 중심 | 평균 $\mu$ |
| 퍼짐 | 분산 $\sigma^2$, 표준편차 $\sigma$ |
| 모양 | 평균을 기준으로 좌우 대칭 |
| 예시 | 키, 시험 점수, 측정 오차 |

정규분포는 평균과 표준편차로 모양이 결정된다. 평균은 분포의 중심을 결정하고, 표준편차는 분포가 얼마나 넓게 퍼지는지를 결정한다.

## 30.9 표준정규분포(Standard Normal Distribution)

표준정규분포는 평균이 0이고 표준편차가 1인 정규분포이다.

$$Z \sim N(0,1)$$

일반 정규분포 값을 표준화하면 표준정규분포로 변환할 수 있다.

$$Z = \frac{X - \mu}{\sigma}$$

z-value는 어떤 값이 평균에서 표준편차 몇 개만큼 떨어져 있는지를 나타낸다.

## 30.10 지수분포(Exponential Distribution)

지수분포는 어떤 사건이 발생할 때까지의 대기시간을 나타낸다.

예를 들어 다음 고객이 도착할 때까지의 시간, 다음 패킷 에러가 발생할 때까지의 시간, 장비 고장까지의 시간을 모델링할 수 있다.

포아송분포가 일정 시간 동안 사건 발생 횟수를 다룬다면, 지수분포는 다음 사건까지 걸리는 시간을 다룬다.

## 30.11 감마분포(Gamma Distribution)

감마분포는 여러 개의 사건이 발생할 때까지의 대기시간을 나타내는 데 사용할 수 있다. 지수분포가 첫 사건까지의 대기시간이라면, 감마분포는 k번째 사건까지의 대기시간으로 볼 수 있다.

신뢰성 분석, 대기시간 분석, 베이지안 통계 등에서 자주 사용된다.

## 30.12 베타분포(Beta Distribution)

베타분포는 0과 1 사이의 확률값을 모델링하는 데 적합하다.

예를 들어 전환율, 클릭률, 불량률처럼 0과 1 사이의 비율을 표현할 수 있다. 베이지안 통계에서는 베르누이 또는 이항분포의 성공확률에 대한 사전분포로 자주 사용한다.

## 30.13 카이제곱분포(Chi-square Distribution)

카이제곱분포는 표준정규분포를 따르는 변수들을 제곱해서 더한 분포이다.

$$\chi^2 = Z_1^2 + Z_2^2 + \cdots + Z_k^2$$

분산 검정, 카이제곱 검정, 회귀분석의 잔차제곱합 분석 등에서 사용된다.

## 30.14 t-분포(t Distribution)

t-분포는 모집단 분산을 모를 때 평균을 추론하는 데 사용한다. 정규분포와 비슷하게 좌우 대칭이지만 꼬리가 더 두껍다.

표본 크기가 작을수록 꼬리가 두껍고, 표본 크기가 커지면 표준정규분포에 가까워진다.

t-검정과 회귀계수 검정에서 사용된다.

## 30.15 F-분포(F Distribution)

F-분포는 두 카이제곱분포를 각각 자유도로 나눈 값의 비율로 만들어지는 분포이다.

ANOVA, 회귀모형 전체 유의성 검정, 분산 비교 검정에서 사용된다.

F-분포는 0 이상의 값만 가지며 오른쪽으로 긴 꼬리를 가진다.

## 30.16 로그정규분포(Log-normal Distribution)

로그정규분포는 어떤 변수의 로그값이 정규분포를 따를 때 원래 변수가 따르는 분포이다.

소득, 주가, 파일 크기, 트래픽량처럼 음수가 될 수 없고 오른쪽 꼬리가 긴 데이터에서 나타날 수 있다.

## 30.17 확률분포 선택 요약

|---|---|

# 31. 조건부확률의 개념, 공식, 예제

조건부확률(Conditional Probability)은 어떤 사건이 이미 발생했다는 조건 아래에서 다른 사건이 발생할 확률이다.

일반 확률은 전체 표본공간을 기준으로 하지만, 조건부확률은 조건이 되는 사건으로 표본공간을 좁힌 뒤 확률을 계산한다.

## 31.1 조건부확률 공식

사건 B가 발생했다는 조건에서 사건 A가 발생할 확률은 다음과 같다.

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

단, $P(B) > 0$이어야 한다.

여기서 각 기호의 의미는 다음과 같다.

| 기호 | 의미 |
|---|---|
| $P(A|B)$ | B가 발생했다는 조건에서 A가 발생할 확률 |
| $P(A \cap B)$ | A와 B가 동시에 발생할 확률 |
| $P(B)$ | 조건으로 주어진 사건 B의 확률 |

핵심은 분모가 전체가 아니라 조건 사건 B라는 점이다. 즉, B가 발생한 경우만 남겨 놓고 그 안에서 A도 발생한 비율을 구한다.

## 31.2 조건부확률에서 곱셈 공식

조건부확률 공식은 다음과 같이 바꿀 수 있다.

$$P(A \cap B) = P(A|B)P(B)$$

또는 다음처럼 쓸 수도 있다.

$$P(A \cap B) = P(B|A)P(A)$$

이 공식은 두 사건이 동시에 발생할 확률을 구할 때 사용한다.

예를 들어 어떤 고객이 광고를 클릭하고 구매할 확률은 다음처럼 표현할 수 있다.

$$P(Click \cap Buy) = P(Buy|Click)P(Click)$$

즉, 클릭할 확률과 클릭한 사람 중 구매할 확률을 곱하면 클릭과 구매가 동시에 발생할 확률이 된다.

## 31.3 독립 사건과 조건부확률

A와 B가 독립이면 B가 발생했다는 정보가 A의 확률을 바꾸지 않는다.

$$P(A|B) = P(A)$$

독립일 때는 다음도 성립한다.

$$P(A \cap B) = P(A)P(B)$$

하지만 두 사건이 상호배반이면 동시에 발생할 수 없으므로 다음이 성립한다.

$$P(A \cap B) = 0$$

이때 $P(A)$와 $P(B)$가 둘 다 0보다 크다면 상호배반 사건은 독립이 아니다. 왜냐하면 B가 발생했다는 사실은 A가 발생할 확률을 0으로 만들어 버리기 때문이다.

## 31.4 Bayes 정리와 조건부확률

Bayes 정리는 조건부확률의 방향을 바꾸는 공식이다.

$$P(A|B) = \frac{P(B|A)P(A)}{P(B)}$$

여기서 $P(B)$는 전체확률법칙으로 계산할 수 있다.

$$P(B) = P(B|A)P(A) + P(B|A^c)P(A^c)$$

Bayes 정리는 검사 양성 결과가 나왔을 때 실제 질병일 확률, 모델이 양성으로 예측했을 때 실제 양성일 확률처럼 원인과 결과의 방향을 뒤집어 해석할 때 중요하다.

## 31.5 예제 1: 조건부확률 기본 문제

문제는 다음과 같다.

어떤 반에 학생 100명이 있다. 그중 60명은 통계 과목을 수강했고, 40명은 머신러닝 과목을 수강했다. 두 과목을 모두 수강한 학생은 20명이다. 머신러닝을 수강한 학생 중 통계도 수강한 학생의 확률은 얼마인가?

사건을 다음과 같이 정의한다.

| 사건 | 의미 |
|---|---|
| A | 통계 과목을 수강한 사건 |
| B | 머신러닝 과목을 수강한 사건 |

구하려는 값은 머신러닝을 수강했다는 조건에서 통계도 수강했을 확률이다.

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

전체 학생 100명 중 두 과목을 모두 수강한 학생은 20명이므로 $P(A \cap B) = 20/100$이다.

머신러닝을 수강한 학생은 40명이므로 $P(B) = 40/100$이다.

따라서 다음과 같다.

$$P(A|B) = \frac{20/100}{40/100} = \frac{20}{40} = 0.5$$

정답은 0.5, 즉 50퍼센트이다.

이 문제에서 중요한 점은 전체 100명 중 20명을 바로 답으로 보면 안 된다는 것이다. 조건이 머신러닝을 수강한 학생 중에서이므로 분모는 100명이 아니라 40명이다.

## 31.6 예제 2: 조건부확률을 표로 푸는 문제

문제는 다음과 같다.

어떤 분류 모델의 예측 결과가 아래와 같다.

| 구분 | 실제 양성 | 실제 음성 | 합계 |
|---|---:|---:|---:|
| 예측 양성 | 80 | 20 | 100 |
| 예측 음성 | 10 | 90 | 100 |
| 합계 | 90 | 110 | 200 |

예측이 양성인 경우 실제로 양성일 확률은 얼마인가?

이 문제는 Precision(정밀도)을 묻는 문제이다. 조건은 예측 양성이고, 관심 사건은 실제 양성이다.

$$P(실제 양성|예측 양성) = \frac{P(실제 양성 \cap 예측 양성)}{P(예측 양성)}$$

예측 양성은 총 100건이고, 그중 실제 양성은 80건이다.

$$P(실제 양성|예측 양성) = \frac{80}{100} = 0.8$$

정답은 0.8, 즉 80퍼센트이다.

반대로 실제 양성인 경우 모델이 양성으로 예측할 확률은 Recall(재현율)이다.

$$P(예측 양성|실제 양성) = \frac{80}{90} = 0.8889$$

이처럼 조건의 방향이 바뀌면 답도 바뀐다.

## 31.7 예제 3: Bayes 정리 검사 문제

문제는 다음과 같다.

어떤 질병의 유병률은 1퍼센트이다. 질병이 있는 사람이 검사를 받으면 양성이 나올 확률은 99퍼센트이다. 질병이 없는 사람이 검사를 받았을 때도 양성이 잘못 나올 확률은 5퍼센트이다. 검사 결과가 양성일 때 실제로 질병이 있을 확률은 얼마인가?

사건을 다음과 같이 정의한다.

| 사건 | 의미 |
|---|---|
| D | 질병이 있음 |
| Positive | 검사 결과 양성 |

주어진 값은 다음과 같다.

| 확률 | 값 | 의미 |
|---|---:|---|
| $P(D)$ | 0.01 | 유병률 |
| $P(D^c)$ | 0.99 | 질병이 없음 |
| $P(Positive|D)$ | 0.99 | 민감도(Sensitivity) |
| $P(Positive|D^c)$ | 0.05 | 위양성률(False Positive Rate) |

구하려는 값은 다음이다.

$$P(D|Positive)$$

Bayes 정리를 적용한다.

$$P(D|Positive) = \frac{P(Positive|D)P(D)}{P(Positive)}$$

전체 양성 확률은 질병이 있어서 양성인 경우와 질병이 없는데 양성인 경우를 더한다.

$$P(Positive) = P(Positive|D)P(D) + P(Positive|D^c)P(D^c)$$

값을 대입하면 다음과 같다.

$$P(Positive) = 0.99 \times 0.01 + 0.05 \times 0.99$$

$$P(Positive) = 0.0099 + 0.0495 = 0.0594$$

따라서 다음과 같다.

$$P(D|Positive) = \frac{0.99 \times 0.01}{0.0594} = \frac{0.0099}{0.0594} \approx 0.1667$$

정답은 약 16.67퍼센트이다.

검사 정확도가 매우 높아 보이더라도, 질병이 매우 드물면 양성 판정 중 상당수가 위양성일 수 있다. 이것이 조건부확률과 Bayes 정리가 중요한 이유이다.

## 31.8 예제 4: 독립 여부 판단 문제

문제는 다음과 같다.

$P(A) = 0.4$, $P(B) = 0.5$, $P(A \cap B) = 0.2$일 때 A와 B는 독립인가?

독립이면 다음이 성립해야 한다.

$$P(A \cap B) = P(A)P(B)$$

오른쪽을 계산하면 다음과 같다.

$$P(A)P(B) = 0.4 \times 0.5 = 0.2$$

문제에서 $P(A \cap B) = 0.2$이므로 두 값이 같다. 따라서 A와 B는 독립이다.

조건부확률로 확인해도 된다.

$$P(A|B) = \frac{P(A \cap B)}{P(B)} = \frac{0.2}{0.5} = 0.4$$

$P(A|B) = P(A)$이므로 B가 발생했다는 정보가 A의 확률을 바꾸지 않는다. 따라서 독립이다.

## 31.9 예제 5: 상호배반과 독립 구분 문제

문제는 다음과 같다.

$P(A) = 0.3$, $P(B) = 0.4$, $P(A \cap B) = 0$일 때 A와 B는 상호배반인가? 독립인가?

먼저 $P(A \cap B) = 0$이므로 A와 B는 동시에 발생하지 않는다. 따라서 상호배반이다.

그러나 독립인지 확인하려면 다음을 계산해야 한다.

$$P(A)P(B) = 0.3 \times 0.4 = 0.12$$

독립이라면 $P(A \cap B)$가 0.12여야 한다. 하지만 실제 $P(A \cap B)$는 0이다. 따라서 독립이 아니다.

결론은 다음과 같다.

| 판단 | 결과 | 이유 |
|---|---|---|
| 상호배반 | 맞다 | 교집합 확률이 0이다. |
| 독립 | 아니다 | $P(A \cap B) \neq P(A)P(B)$이다. |

## 31.10 조건부확률 문제 풀이 요령

조건부확률 문제는 먼저 분모를 정확히 잡는 것이 중요하다.

| 문제 표현 | 분모가 되는 조건 |
|---|---|
| B 중에서 A일 확률 | B |
| B가 주어졌을 때 A일 확률 | B |
| B라고 할 때 A일 확률 | B |
| 예측 양성 중 실제 양성 | 예측 양성 |
| 실제 양성 중 예측 양성 | 실제 양성 |

조건부확률 문제를 풀 때는 다음 순서를 따르면 된다.

| 순서 | 방법 |
|---|---|
| 1 | 조건에 해당하는 사건을 찾는다. |
| 2 | 조건 사건을 분모로 둔다. |
| 3 | 조건 사건과 관심 사건이 동시에 발생한 경우를 분자로 둔다. |
| 4 | 분자와 분모가 전체 기준인지, 조건 기준인지 확인한다. |
| 5 | 조건 방향이 바뀌면 답이 달라지는지 확인한다. |

# 32. 추가 예제 문제

## 32.1 가설 검정 예제

문제는 다음과 같다.

어떤 공장의 부품 평균 길이는 50mm라고 알려져 있다. 새 공정에서 생산한 부품 25개의 평균 길이는 51.2mm이고, 표본 표준편차는 3mm이다. 새 공정의 평균 길이가 50mm와 다르다고 볼 수 있는지 검정하려고 한다. 어떤 검정을 사용하는 것이 적절한가?

풀이이다.

모집단 표준편차를 모르고 표본 크기는 25이다. 평균이 특정 기준값과 다른지 확인하는 문제이므로 단일 표본 t-검정을 사용한다.

귀무가설과 대립가설은 다음과 같다.

| 가설 | 내용 |
|---|---|
| H0 | 평균 길이는 50mm이다. |
| H1 | 평균 길이는 50mm가 아니다. |

평균이 더 큰지만 보는 것이 아니라 다른지를 보는 문제이므로 양측 검정이다.

정답은 단일 표본 t-검정이다.

## 32.2 상관 예제

문제는 다음과 같다.

고객 만족도는 1점부터 5점까지의 순서형 변수이고, 재구매 의향도 1점부터 5점까지의 순서형 변수이다. 두 변수의 관계를 보고 싶다면 어떤 상관계수를 사용하는 것이 적절한가?

풀이이다.

두 변수가 모두 순서형 변수이다. 실제 값의 간격이 완전히 동일하다고 보기 어렵고, 순위 기반 관계를 보는 것이 적절하다. 따라서 Spearman Rank Correlation 또는 Kendall Tau를 사용할 수 있다.

정답은 Spearman Rank Correlation 또는 Kendall Tau이다.

## 32.3 회귀 예제

문제는 다음과 같다.

하루 동안 발생한 네트워크 에러 횟수를 트래픽량, 장비 온도, 시간대 변수로 예측하려고 한다. 종속변수는 0 이상의 정수 형태이다. 어떤 회귀가 적절한가?

풀이이다.

종속변수가 사건 발생 횟수이므로 Count 데이터이다. 기본적으로 포아송 회귀를 고려할 수 있다. 다만 실제 데이터에서 분산이 평균보다 훨씬 크면 과산포가 있으므로 음이항 회귀가 더 적절할 수 있다.

정답은 포아송 회귀이고, 과산포가 있으면 음이항 회귀이다.

## 32.4 확률분포 예제

문제는 다음과 같다.

어떤 웹사이트의 방문자가 구매할 확률은 0.1이다. 방문자 20명 중 정확히 3명이 구매할 확률을 모델링하려면 어떤 분포를 사용하는 것이 적절한가?

풀이이다.

각 방문자는 구매 또는 미구매라는 두 결과를 가진다. 방문자 수는 20명으로 고정되어 있고, 관심 대상은 구매한 사람 수이다. 따라서 이항분포를 사용한다.

정답은 Binomial Distribution(이항분포)이다.

## 32.5 조건부확률 예제

문제는 다음과 같다.

전체 고객 1,000명 중 300명이 앱 알림을 클릭했고, 120명이 구매했다. 알림을 클릭한 고객 중 구매한 고객은 90명이다. 알림을 클릭한 고객이 구매할 확률은 얼마인가?

풀이이다.

사건을 다음과 같이 둔다.

| 사건 | 의미 |
|---|---|
| A | 구매한 사건 |
| B | 앱 알림을 클릭한 사건 |

구하려는 값은 클릭했다는 조건에서 구매할 확률이다.

$$P(A|B) = \frac{P(A \cap B)}{P(B)}$$

클릭한 고객은 300명이고, 클릭하고 구매한 고객은 90명이다.

$$P(A|B) = \frac{90}{300} = 0.3$$

정답은 0.3, 즉 30퍼센트이다.
