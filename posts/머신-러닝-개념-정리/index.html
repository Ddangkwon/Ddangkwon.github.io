1. Decision Tree와 Supervised Learning

Decision Tree는 Supervised Learning인가?

Decision Tree는 기본적으로 Supervised Learning에 사용하는 알고리즘이다.

Supervised Learning은 학습 데이터에 정답 label이 포함되어 있는 학습 방식이다.

예를 들어 다음과 같은 데이터가 있다고 하자.

WeatherHumidityWindPlay
SunnyHighWeakNo
SunnyNormalWeakYes
RainyHighStrongNo
CloudyHighWeakYes

여기서 구분은 다음과 같다.

구분예시의미
Feature, 독립변수Weather, Humidity, Wind예측에 사용하는 입력값
Label, Target, 종속변수Play맞춰야 하는 정답

Decision Tree는 Feature를 기준으로 데이터를 나누면서 Label을 잘 예측하는 규칙을 학습한다.

Decision Tree가 사용되는 문제 유형

Decision Tree는 크게 두 가지 문제에 사용할 수 있다.

문제 유형설명예시

2. Entropy와 Information Gain

Entropy 개념

Entropy는 데이터가 얼마나 섞여 있는지를 나타내는 불순도 지표이다.

Decision Tree에서는 특정 노드 안에 여러 class가 얼마나 섞여 있는지 계산할 때 사용한다.

[ Entropy(S) = - \sum_{i=1}^{k} p_i \log_2(p_i) ]

기호의미
(k)class 개수
(p_i)i번째 class가 차지하는 비율
(\log_2)밑이 2인 로그
(Entropy(S))데이터가 섞여 있는 정도

이진 분류에서는 다음처럼 쓸 수 있다.

[ Entropy(S) = -p_+ \log_2(p_+) - p_- \log_2(p_-) ]

데이터 상태Entropy의미
한 class만 존재0완전히 순수함
class가 반반 섞임최대가장 많이 섞임
한쪽 class가 더 많음중간일부 섞임

Entropy 계산 예시

전체 데이터 10개 중 Yes가 8개, No가 2개라고 하자.

Class개수비율
Yes80.8
No20.2

[ Entropy(S) = -0.8\log_2(0.8)-0.2\log_2(0.2) ]

[ Entropy(S) \approx 0.722 ]

Yes와 No가 5개씩 반반이면 Entropy는 1이고, 한쪽 class만 있으면 Entropy는 0이다.

Information Gain 개념

Information Gain은 Decision Tree에서 어떤 Feature로 데이터를 나누었을 때 불확실성 또는 impurity가 얼마나 줄어드는지를 나타내는 값이다.

즉, 어떤 Feature로 나누면 데이터가 더 깔끔하게 분리되는지를 수치로 표현한 것이다.

Decision Tree는 보통 Information Gain이 큰 Feature를 먼저 선택한다.

Information Gain 공식

[ Information\ Gain = Entropy(parent) - Entropy(after\ split) ]

더 자세히 쓰면 다음과 같다.

[ IG(S,A) = Entropy(S) - \sum_{v \in Values(A)} \frac{|S_v|}{|S|}Entropy(S_v) ]

기호의미  
(S)분리 전 전체 데이터  
(A)분리에 사용할 Feature  
(v)Feature (A)가 가질 수 있는 값  
(S_v)Feature 값이 (v)인 데이터 그룹  
(S)전체 데이터 개수
(S_v)분리된 그룹의 데이터 개수

말로 풀면 다음과 같다.

Information Gain = 나누기 전 불순도 - 나눈 후 불순도

특정 Feature의 Information Gain 계산 순서

순서계산 내용
1전체 데이터의 Entropy를 계산한다
2특정 Feature 값 기준으로 데이터를 나눈다
3나눠진 각 그룹의 Entropy를 계산한다
4각 그룹 Entropy에 데이터 비율을 곱한다
5그룹별 가중 Entropy를 모두 더한다
6전체 Entropy에서 분리 후 가중 Entropy를 뺀다

Information Gain 계산 예시

목표는 구매 여부를 예측하는 문제라고 하자.

번호날씨구매 여부
1맑음구매
2맑음구매
3맑음미구매
4흐림구매
5흐림구매
6비미구매
7비미구매
8비구매

전체 데이터는 8개이고, 구매 5개, 미구매 3개이다.

[ Entropy(S) = -\frac{5}{8}\log_2\left(\frac{5}{8}\right) - \frac{3}{8}\log_2\left(\frac{3}{8}\right) ]

[ Entropy(S) \approx 0.954 ]

날씨 Feature로 나누면 다음과 같다.

날씨데이터 개수구매미구매Entropy
맑음3210.918
흐림2200
비3120.918

분리 후 가중 Entropy는 다음과 같다.

[ Entropy(after\ split) = \frac{3}{8}(0.918) + \frac{2}{8}(0) + \frac{3}{8}(0.918) ]

[ Entropy(after\ split) \approx 0.689 ]

따라서 Information Gain은 다음과 같다.

[ Information\ Gain = 0.954 - 0.689 = 0.265 ]

즉, 날씨 Feature로 분리했을 때 Information Gain은 약 0.265이다.

3. Gain Ratio

Gain Ratio 개념

Gain Ratio는 Decision Tree에서 분할 기준을 정할 때 사용하는 지표이다.

특히 C4.5 알고리즘에서 사용한다.

핵심은 다음이다.

Information Gain이 너무 많은 값을 가진 Feature를 과도하게 선호하는 문제를 보정한 지표이다.

예를 들어 고객 ID, 전화번호, 제품 Serial Number 같은 Feature는 거의 모든 값이 고유하다. 이런 Feature로 나누면 각 그룹이 아주 작아지고, 훈련 데이터에서는 Entropy가 크게 줄어든 것처럼 보인다.

하지만 이런 분할은 일반화에 도움이 되지 않는다.

Gain Ratio 공식

[ Gain\ Ratio = \frac{Information\ Gain}{Split\ Information} ]

여기서 Split Information은 Feature가 데이터를 얼마나 잘게 쪼개는지를 나타낸다.

[ Split\ Information = - \sum_{i=1}^{k} \frac{n_i}{n} \log_2\left(\frac{n_i}{n}\right) ]

기호의미
(n)전체 데이터 개수
(n_i)i번째 분할 그룹의 데이터 개수
(k)분할된 그룹 개수

장점계산이 직관적고유값 많은 Feature 편향을 줄임
단점고유값 많은 Feature를 선호Split Information이 너무 작은 경우 불안정 가능

정리하면 Gain Ratio는 다음 질문에 답한다.

4. K-means Clustering

K-means Clustering 개념

K-means Clustering은 데이터를 K개의 cluster로 나누는 Unsupervised Learning 알고리즘이다.

정답 label 없이 데이터의 위치, 거리, 유사도만 보고 비슷한 것끼리 묶는다.

K-means에서 K의 의미

K-means의 K는 만들고 싶은 cluster 개수이다.

K 값의미
K = 2데이터를 2개 그룹으로 나눔
K = 3데이터를 3개 그룹으로 나눔
K = 5데이터를 5개 그룹으로 나눔

K-means 동작 과정

순서과정
1K개의 centroid를 초기화한다
2각 데이터를 가장 가까운 centroid에 할당한다
3각 cluster에 속한 데이터들의 평균으로 centroid를 갱신한다
4데이터 할당과 centroid 갱신을 반복한다
5centroid 변화가 작아지면 종료한다

K-means 목적 함수

K-means는 각 데이터가 자기 cluster 중심점에서 최대한 가깝도록 cluster를 만든다.

[ J = \sum_{i=1}^{K} \sum_{x \in C_i} ||x-\mu_i||^2 ]

기호의미
(K)cluster 개수
(C_i)i번째 cluster
(x)데이터 포인트
(\mu_i)i번째 cluster의 centroid

즉, K-means는 cluster 내부 거리는 작게, cluster 간 거리는 크게 만드는 것을 목표로 한다.

K-means 거리 계산

가장 많이 쓰는 거리는 Euclidean Distance이다.

[ d(x,y)=\sqrt{(x_1-y_1)^2+(x_2-y_2)^2} ]

예를 들어 A(1, 1), B(4, 5)의 거리는 다음과 같다.

[ d(A,B)=\sqrt{(4-1)^2+(5-1)^2}=5 ]

K-means 초기화 방식

K-means에서 중요한 것은 초기 centroid를 어디에 두는가이다.

초기값이 좋지 않으면 local optimum에 빠지거나 수렴이 느려질 수 있다.

초기화 방식핵심 아이디어장점단점
Forgy Method데이터 중 K개를 랜덤 선택단순하고 빠름초기값에 민감
Random Partition데이터를 랜덤 cluster에 배정 후 평균 계산구현 쉬움실제 구조 반영 약함
K-means++멀리 떨어진 점을 확률적으로 선택안정적이고 수렴 빠름초기화 비용 증가
Maximin가장 멀리 떨어진 점 선택centroid 분산 좋음outlier에 취약
PCA 기반 초기화주성분 방향에 centroid 배치분산 구조 반영비선형 구조에 약함
Multiple Random Starts여러 번 실행 후 최선 선택안정성 높음계산 비용 증가

실무에서는 보통 K-means++와 Multiple Random Starts 조합을 많이 사용한다.

K-means 장점과 단점

구분내용
장점계산이 빠르고 이해하기 쉽다
장점구현이 단순하고 대용량 데이터에 사용 가능하다
단점K를 미리 정해야 한다
단점초기 centroid에 민감하다
단점이상치에 약하다
단점Feature scale에 민감하다
단점복잡한 모양의 cluster를 잘 못 잡을 수 있다

K를 정하는 방법

Elbow Method

K를 바꿔가며 WCSS(Within-Cluster Sum of Squares)를 계산한다. K가 증가하면 WCSS는 감소하지만, 어느 순간부터 감소 폭이 작아진다. 그 꺾이는 지점을 elbow point라고 한다.

Silhouette Score

Silhouette Score는 cluster가 얼마나 잘 나뉘었는지 평가하는 지표이다.

값해석
1에 가까움cluster가 잘 분리됨
0 근처cluster 경계가 애매함
음수잘못된 cluster에 배정되었을 가능성 있음

5. K-NN

K-NN 개념

K-NN(K-Nearest Neighbors)은 새로운 데이터가 들어왔을 때 주변의 가장 가까운 K개 데이터를 보고 예측하는 알고리즘이다.

K-NN은 기본적으로 Supervised Learning이다. 즉, 학습 데이터에 정답 label이 있어야 한다.

K-NN에서 K의 의미

K-NN의 K는 몇 개의 가까운 이웃을 볼 것인가이다.

K 값의미
K = 1가장 가까운 1개 데이터만 보고 판단
K = 3가장 가까운 3개 데이터를 보고 다수결
K = 5가장 가까운 5개 데이터를 보고 다수결

K-NN Classification

K-NN을 classification에 쓰면 가까운 K개 이웃의 다수결로 class를 정한다.

예를 들어 K = 5일 때 가까운 이웃이 다음과 같다고 하자.

이웃label
1스팸
2스팸
3정상
4스팸

스팸 3개, 정상 2개이므로 새 이메일은 스팸으로 분류된다.

K-NN Regression

K-NN은 regression에도 사용할 수 있다.

이 경우 가까운 K개 데이터의 평균값을 예측값으로 사용한다.

[ 예측값 = \frac{5+5.5+6}{3}=5.5 ]

따라서 새 집의 예측 가격은 5.5억이다.

6. Bayes’ Theorem

Bayes’ Theorem 개념

Bayes’ Theorem은 어떤 증거가 관측되었을 때 원인이 무엇일 가능성이 높은지를 계산하는 방법이다.

쉽게 말하면 새로운 증거를 보고 기존 확률을 업데이트하는 공식이다.

Bayes’ Theorem 공식

[ P(A|B)=\frac{P(B|A)P(A)}{P(B)} ]

각 항의 의미는 다음과 같다.

기호의미 
(P(A))A가 원래 일어날 확률, Prior Probability 
(P(B))B가 일어날 전체 확률, Evidence 
(P(AB))B가 일어났을 때 A가 일어날 확률, Posterior Probability
(P(BA))A가 일어났을 때 B가 일어날 확률, Likelihood

즉, Bayes’ Theorem은 다음 구조로 이해할 수 있다.

[ Posterior = \frac{Likelihood \times Prior}{Evidence} ]

질병 검사 예제

어떤 질병 검사에 대해 다음 정보가 있다고 하자.

항목값
질병 보유 확률1%
질병이 있을 때 양성 확률99%
질병이 없을 때 양성으로 잘못 나올 확률5%

검사 결과가 양성일 때 실제로 질병이 있을 확률을 구하라.

[ P(D|+) = \frac{P(+|D)P(D)}{P(+)} ]

전체 양성 확률은 다음과 같다.

[ P(+)=P(+|D)P(D)+P(+|\neg D)P(\neg D) ]

[ P(+)=0.99 \times 0.01 + 0.05 \times 0.99 = 0.0594 ]

따라서

[ P(D|+)=\frac{0.99 \times 0.01}{0.0594}=0.1667 ]

정답은 약 16.67%이다.

P(A|B)와 P(B|A)의 차이

확률의미 
(P(양성질병))질병이 있을 때 검사 결과가 양성일 확률
(P(질병양성))검사 결과가 양성일 때 실제로 질병이 있을 확률
검사 정확도가 높아 보여도 질병 자체가 드물면 (P(질병양성))은 생각보다 낮을 수 있다. 이를 Base Rate Problem이라고 한다.

7. Association Rule

Association Rule 개념

Association Rule은 item 간의 동시 등장 관계를 찾는 방법이다.

대표적인 형태는 다음과 같다.

[ A \rightarrow B ]

이 의미는 A를 가진 transaction에서 B도 같이 나타나는 경향이 있다는 뜻이다.

예를 들어 우유를 산 사람이 빵도 같이 사는 경향이 있는지 분석할 수 있다.

Support 개념

Support는 어떤 itemset이 전체 transaction 중에서 얼마나 자주 등장하는지를 나타낸다.

규칙 A → B의 Support는 A와 B가 동시에 등장한 transaction 비율이다.

[ Support(A \rightarrow B)=Support(A \cup B) ]

[ Support(A \rightarrow B)=\frac{A와\ B를\ 모두\ 포함한\ transaction\ 수}{전체\ transaction\ 수} ]

Support는 A만 등장한 비율도 아니고, B만 등장한 비율도 아니다. 반드시 A와 B가 동시에 등장한 비율이다.

8. Logistic Regression과 Cross Entropy

Logistic Regression 개념

Logistic Regression은 분류 문제에서 class에 속할 확률을 예측하는 모델이다.

먼저 선형식을 만든다.

[ z=w_1x_1+w_2x_2+\cdots+w_kx_k+b ]

벡터 형태로 쓰면 다음과 같다.

[ z=w^Tx+b ]

그리고 이 값을 Sigmoid Function에 넣어서 확률로 변환한다.

[ \hat{p}=\frac{1}{1+e^{-z}} ]

여기서 (\hat{p})는 class 1일 예측 확률이다.

Odds와 Log Odds

확률 (p)가 있을 때 Odds는 다음과 같다.

[ Odds=\frac{p}{1-p} ]

예를 들어 (p=0.8)이면

[ Odds=\frac{0.8}{1-0.8}=\frac{0.8}{0.2}=4 ]

즉, 성공할 가능성이 실패할 가능성보다 4배 크다는 뜻이다.

Logistic Regression은 Log Odds를 선형식으로 둔다.

[ \log\left(\frac{p}{1-p}\right)=w^Tx+b ]

Cross Entropy Loss

이진 분류에서 Cross Entropy Loss는 다음과 같다.

[ Loss=-[y\log(\hat{p})+(1-y)\log(1-\hat{p})] ]

전체 데이터에 대해서는 평균을 낸다.

[ J(w,b)=-\frac{1}{n}\sum_{i=1}^{n}[y_i\log(\hat{p_i})+(1-y_i)\log(1-\hat{p_i})] ]

Cross Entropy는 정답 class에 낮은 확률을 주거나 오답 class에 높은 확률을 주면 큰 벌점을 준다.

경계면 Decision Boundary

보통 threshold를 0.5로 둔다.

조건예측 class
(\hat{p} \ge 0.5)class 1
(\hat{p} < 0.5)class 0

Sigmoid Function에서 (\hat{p}=0.5)가 되는 지점은 (z=0)이다.

따라서 Logistic Regression의 decision boundary는 다음과 같다.

[ w^Tx+b=0 ]

정확히 표현하면 다음과 같다.

Logistic Regression은 Cross Entropy Loss를 최소화하도록 (w), (b)를 학습하고, 학습된 (w), (b)에 의해 (w^Tx+b=0)인 decision boundary가 정해진다.

11. 분산 계산 공식

데이터 개수, 합, 제곱합으로 모집단 분산 계산

데이터 개수 (n), (\sum x), (\sum x^2)를 알고 있으면 분산을 빠르게 계산할 수 있다.

모집단 분산은 다음과 같다.

[ \sigma^2=\frac{\sum x^2}{n}-\left(\frac{\sum x}{n}\right)^2 ]

즉,

[ 분산 = x^2의\ 평균 - x평균의\ 제곱 ]

표본 분산 공식

전체 모집단이 아니라 일부 표본 데이터라면 표본 분산을 사용한다.

[ s^2=\frac{\sum x^2-\frac{(\sum x)^2}{n}}{n-1} ]

표본 분산은 (n)이 아니라 (n-1)로 나눈다.

예시

데이터가 2, 4, 6, 8이라고 하자.

항목값
(n)4
(\sum x)20
(\sum x^2)120

모집단 분산은 다음과 같다.

[ \sigma^2=\frac{120}{4}-\left(\frac{20}{4}\right)^2 ]

[ \sigma^2=30-25=5 ]

표본 분산은 다음과 같다.

[ s^2=\frac{120-\frac{20^2}{4}}{4-1} ]

[ s^2=\frac{120-100}{3}=\frac{20}{3}=6.67 ]

주의할 점

[ \sum x^2 ]

와

[ (\sum x)^2 ]

는 다르다.

예를 들어 데이터가 2, 4, 6, 8이면

[ \sum x^2=2^2+4^2+6^2+8^2=120 ]

하지만

[ (\sum x)^2=(2+4+6+8)^2=20^2=400 ]

이다.

13. t분포

t분포 개념

t분포(t-distribution)는 표본의 크기가 작고, 모집단의 표준편차를 모를 때 평균 검정에 사용하는 확률분포이다.

모집단 표준편차 (\sigma)를 모르고 표본 표준편차 (s)만 가지고 평균을 검정해야 할 때 사용한다.

t통계량 공식

단일 표본 평균 검정에서 t통계량은 다음과 같다.

[ t=\frac{\bar{x}-\mu_0}{s/\sqrt{n}} ]

기호의미
(\bar{x})표본 평균
(\mu_0)귀무가설에서 주장하는 모집단 평균
(s)표본 표준편차
(n)표본 개수
(s/\sqrt{n})표준오차

t분포의 모양

t분포는 정규분포와 비슷하게 가운데가 높고 좌우 대칭이다. 하지만 정규분포보다 꼬리가 두껍다.

자유도

단일 표본 t검정에서는 자유도가 다음과 같다.

[ df=n-1 ]

자유도가 작으면 t분포의 꼬리가 더 두껍고, 자유도가 커질수록 t분포는 표준정규분포에 가까워진다.

정규분포와 카이제곱분포로 정의하는 t분포

t분포는 표준정규분포와 카이제곱분포로 정의할 수 있다.

[ T=\frac{Z}{\sqrt{V/\nu}}\sim t_\nu ]

조건은 다음과 같다.

기호의미

(Z \sim N(0,1))평균 0, 분산 1인 정규분포
(V)카이제곱분포를 따르는 확률변수
(V \sim \chi^2_\nu)자유도 (\nu)인 카이제곱분포
(\nu)자유도
(Z)와 (V)서로 독립이어야 함

즉, 분자는 표준정규분포이고, 분모는 자유도로 나눈 카이제곱분포의 제곱근이다.

표본평균 t통계량과의 연결

모집단이 정규분포라고 하자.

[ X_1,X_2,\cdots,X_n \sim N(\mu,\sigma^2) ]

그러면

[ Z=\frac{\bar{X}-\mu}{\sigma/\sqrt{n}}\sim N(0,1) ]

그리고

[ V=\frac{(n-1)S^2}{\sigma^2}\sim \chi^2_{n-1} ]

따라서

[ \frac{\bar{X}-\mu}{S/\sqrt{n}}\sim t_{n-1} ]

이 된다.

[ df=n-1 ]

같은 대상에서 전후 차이를 비교할 때 사용한다.

각 쌍의 차이값을 만든다.

[ d_i=x_{after,i}-x_{before,i} ]

자유도는 차이값 개수 기준으로 계산한다.

[ df=n_d-1 ]

서로 독립인 두 집단의 평균 차이를 검정할 때 사용한다. 두 집단의 분산이 같다고 가정한다.

[ df=n_1+n_2-2 ]

Welch t검정, 등분산 가정 안 함

두 집단 평균을 비교하지만 두 집단의 분산이 같다고 보기 어려울 때 사용한다.

[ df= \frac{ \left(\frac{s_1^2}{n_1}+\frac{s_2^2}{n_2}\right)^2 }{ \frac{\left(\frac{s_1^2}{n_1}\right)^2}{n_1-1} + \frac{\left(\frac{s_2^2}{n_2}\right)^2}{n_2-1} } ]

Welch 자유도는 보통 정수가 아닌 소수로 나온다.

상관계수 (r)이 0과 유의하게 다른지 검정할 때도 t검정을 사용한다.

[ t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}} ]

[ df=n-2 ]

[ df=n-2 ]

[ df=n-k-1 ]

15. ANOVA 변동과 자유도

ANOVA 변동의 구성

ANOVA(Analysis of Variance, 분산분석)에서 변동은 크게 3개로 나눈다.

변동영어의미
전체 변동Total Variation전체 데이터가 전체 평균에서 얼마나 흩어져 있는가
그룹간 변동Between-group Variation각 그룹 평균들이 전체 평균에서 얼마나 떨어져 있는가
그룹내 변동Within-group Variation각 데이터가 자기 그룹 평균에서 얼마나 떨어져 있는가

핵심 관계는 다음이다.

[ SST=SSB+SSW ]

기호의미
SST(Sum of Squares Total)전체 제곱합
SSB(Sum of Squares Between)그룹간 제곱합
SSW(Sum of Squares Within)그룹내 제곱합

자유도 공식

그룹 개수를 (k), 전체 데이터 개수를 (N)이라고 하면 다음과 같다.

구분제곱합자유도
그룹간 변동SSB(k-1)
그룹내 변동SSW(N-k)
전체 변동SST(N-1)

즉,

[ df_{between}=k-1 ]

[ df_{within}=N-k ]

[ df_{total}=N-1 ]

자유도도 다음 관계를 가진다.

[ df_{total}=df_{between}+df_{within} ]

[ N-1=(k-1)+(N-k) ]

전체 변동

전체 변동은 모든 데이터가 전체 평균에서 얼마나 떨어져 있는지를 본다.

[ SST=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(x_{ij}-\bar{x})^2 ]

전체 평균 (\bar{x}) 하나를 계산했기 때문에 자유도는 (N-1)이다.

그룹간 변동

그룹간 변동은 각 그룹 평균이 전체 평균에서 얼마나 떨어져 있는지를 본다.

[ SSB=\sum_{i=1}^{k}n_i(\bar{x_i}-\bar{x})^2 ]

그룹 평균은 (k)개 있지만 전체 평균이 정해지면 마지막 하나는 독립적으로 마음대로 변할 수 없다. 그래서 자유도는 (k-1)이다.

그룹내 변동

그룹내 변동은 각 데이터가 자기 그룹 평균에서 얼마나 떨어져 있는지를 본다.

[ SSW=\sum_{i=1}^{k}\sum_{j=1}^{n_i}(x_{ij}-\bar{x_i})^2 ]

각 그룹마다 그룹 평균을 하나씩 계산하므로 전체 데이터 개수 (N)에서 그룹 개수 (k)를 뺀다.

[ df_{within}=N-k ]

또는 각 그룹별 자유도를 더해도 된다.

[ df_{within}=(n_1-1)+(n_2-1)+\cdots+(n_k-1) ]

평균제곱과 F 통계량

ANOVA에서는 제곱합을 자유도로 나눠서 평균제곱을 만든다.

[ MSB=\frac{SSB}{k-1} ]

[ MSW=\frac{SSW}{N-k} ]

F 통계량은 다음이다.

[ F=\frac{MSB}{MSW} ]

즉,

[ F=\frac{SSB/(k-1)}{SSW/(N-k)} ]

ANOVA 표

SourceSum of SquaresdfMean SquareF
Between GroupsSSB(k-1)(MSB=\frac{SSB}{k-1})(\frac{MSB}{MSW})
Within GroupsSSW(N-k)(MSW=\frac{SSW}{N-k}) 
TotalSST(N-1)  

16. 왜도, 첨도, 분위수

왜도 Skewness

왜도(Skewness)는 데이터 분포가 좌우 대칭에서 얼마나 벗어났는지를 나타내는 값이다.

[ Skewness=\frac{E[(X-\mu)^3]}{\sigma^3} ]

왜도 값분포 모양해석
0 근처좌우 대칭평균 주변으로 균형 잡힌 분포
양수오른쪽 꼬리가 김큰 값 쪽으로 일부 데이터가 길게 퍼짐
음수왼쪽 꼬리가 김작은 값 쪽으로 일부 데이터가 길게 퍼짐

양의 왜도에서는 보통 다음 관계가 자주 나타난다.

[ 평균 > 중앙값 > 최빈값 ]

음의 왜도에서는 보통 다음 관계가 자주 나타난다.

[ 평균 < 중앙값 < 최빈값 ]

첨도 Kurtosis

첨도(Kurtosis)는 분포의 꼬리가 얼마나 두껍고 극단값이 얼마나 자주 나타나는지를 설명하는 지표이다.

[ Kurtosis=\frac{E[(X-\mu)^4]}{\sigma^4} ]

정규분포의 첨도는 보통 3이다.

실제 분석에서는 Excess Kurtosis를 더 자주 사용한다.

[ Excess\ Kurtosis=Kurtosis-3 ]

구분KurtosisExcess Kurtosis해석
Mesokurtic30정규분포와 비슷한 꼬리
Leptokurtic3보다 큼양수꼬리가 두껍고 극단값이 많음
Platykurtic3보다 작음음수꼬리가 얇고 극단값이 적음

첨도는 단순히 봉우리가 뾰족한 정도가 아니라 극단값 발생 가능성과 관련이 깊다.

분위수 Quantile

분위수(Quantile)는 데이터를 작은 값부터 큰 값까지 정렬했을 때 특정 비율 위치에 있는 값을 말한다.

위치의미
하위 25% 지점제1사분위수 Q1
하위 50% 지점중앙값 Median, Q2
하위 75% 지점제3사분위수 Q3
하위 90% 지점90th Percentile

사분위수 Quartile

분위수영어의미
Q1First Quartile하위 25% 지점
Q2Second Quartile, Median하위 50% 지점, 중앙값
Q3Third Quartile하위 75% 지점

IQR

IQR(Interquartile Range, 사분위 범위)은 다음과 같다.

[ IQR=Q3-Q1 ]

IQR은 가운데 50% 데이터가 퍼져 있는 범위를 의미한다.

IQR과 이상치

보통 다음 범위를 벗어나면 이상치 후보로 본다.

[ Lower\ Bound=Q1-1.5 \times IQR ]

[ Upper\ Bound=Q3+1.5 \times IQR ]

통신 데이터에서 분위수 활용

통신/RF 데이터에서는 평균만 보는 것보다 분위수를 같이 보는 것이 중요하다.

예를 들어 평균 Throughput이 높아도 5th percentile Throughput이 낮으면 하위 사용자 체감 품질은 나쁠 수 있다.

지표평균만 볼 때 문제
Throughput일부 고속 사용자 때문에 평균이 높게 보일 수 있음
RSRP(Reference Signal Received Power)음영지역 사용자 품질을 놓칠 수 있음
SINR(Signal to Interference plus Noise Ratio)간섭이 심한 하위 구간을 놓칠 수 있음
Latency평균 지연은 양호해도 tail latency가 나쁠 수 있음

17. 점추정

점추정 개념

점추정(Point Estimation)은 모집단의 모수(Parameter)를 하나의 값으로 추정하는 방법이다.

즉, 모집단 전체를 다 조사할 수 없으니 표본 데이터를 이용해서 모집단의 평균, 분산, 비율 같은 값을 하나의 숫자로 추정하는 것이다.

모수, 추정량, 추정값

개념의미예시
모수 Parameter모집단의 실제 값모집단 평균 (\mu)
추정량 Estimator모수를 추정하기 위한 공식표본평균 (\bar{x})
추정값 Estimate실제 표본으로 계산된 숫자(\bar{x}=172.5)

모집단 평균의 점추정

[ \hat{\mu}=\bar{x} ]

[ \bar{x}=\frac{x_1+x_2+\cdots+x_n}{n} ]

모집단 비율의 점추정

[ \hat{p}=\frac{x}{n} ]

기호의미
(p)모집단 비율
(\hat{p})표본비율
(x)특정 특성을 가진 표본 개수
(n)전체 표본 개수

모집단 분산의 점추정

모집단 분산 (\sigma^2)은 보통 표본분산 (s^2)로 추정한다.

[ s^2=\frac{\sum(x_i-\bar{x})^2}{n-1} ]

점추정과 구간추정

구분점추정구간추정
의미하나의 값으로 추정범위로 추정

조건영어의미

층화추출은 모집단을 성격이 비슷한 여러 층으로 나눈 뒤, 각 층에서 표본을 뽑는 방법이다.

층화추출에서는 모든 층에서 표본을 뽑는다.

모집단 안에 중요한 하위집단이 있을 때, 그 하위집단이 표본에서 빠지지 않도록 하는 방법이다.

19. 시계열분석의 4가지 특성

시계열 데이터의 대표적인 특성은 다음 4가지이다.

구분영어 표현의미
1Trend장기적인 증가 또는 감소 방향
2Seasonality일정한 주기로 반복되는 패턴
3Cycle불규칙하지만 장기적으로 반복되는 경기적 흐름
4Irregular 또는 Random예측하기 어려운 우연한 변동

Trend

Trend는 시간이 지남에 따라 데이터가 장기적으로 증가하거나 감소하는 방향이다.

예를 들어 매년 스마트폰 사용량이 증가하거나, 오래된 제품의 판매량이 감소하는 경우이다.

Seasonality

Seasonality는 일정한 시간 주기로 반복되는 패턴이다.

계절이라는 말이 꼭 봄, 여름, 가을, 겨울만 의미하는 것은 아니다. 일, 주, 월, 분기, 연 단위로 반복되는 패턴도 포함한다.

주기예시
하루 단위출근 시간대 트래픽 증가
주 단위주말 쇼핑몰 방문자 증가
월 단위월급날 이후 소비 증가
분기 단위분기말 실적 정산
연 단위여름철 에어컨 판매 증가

RF나 통신 데이터로 보면 특정 시간대마다 데이터 트래픽이 반복적으로 증가하는 것도 계절성으로 볼 수 있다.

Cycle

Cycle은 일정한 고정 주기는 아니지만, 장기적으로 상승과 하락이 반복되는 흐름이다.

구분SeasonalityCycle
반복 주기비교적 일정함일정하지 않음
원인계절, 요일, 시간대 등경기 변동, 산업 흐름, 수요 변화
예측성상대적으로 높음상대적으로 낮음

예를 들어 반도체 시장은 몇 년 단위로 호황과 불황을 반복할 수 있지만, 주기가 정확히 고정되어 있지는 않다.

Irregular 또는 Random

Irregular component는 Trend, Seasonality, Cycle로 설명되지 않는 예측하기 어려운 변동이다.

예시설명
갑작스러운 장애통신망 트래픽 급감 또는 급증
자연재해물류, 매출, 수요 변화
이벤트성 이슈특정 뉴스로 인한 검색량 급증
장비 이상센서 데이터의 비정상 튐
측정 노이즈실제 패턴과 무관한 작은 변동

시계열 데이터 표현

시계열 데이터는 다음 네 요소가 합쳐진 것으로 볼 수 있다.

[ Y_t=Trend_t+Seasonality_t+Cycle_t+Irregular_t ]

또는 곱셈 형태로도 표현한다.

[ Y_t=Trend_t \times Seasonality_t \times Cycle_t \times Irregular_t ]

방식의미사용 상황
Additive Model요소들이 더해져서 전체 값을 만듦변동 폭이 비교적 일정할 때
Multiplicative Model요소들이 곱해져서 전체 값을 만듦값이 커질수록 변동 폭도 커질 때
